# SimHuman

纯 2D 单机文明演化模拟游戏：玩家经营一个社群，从原始生存一直发展到工业与太空阶段。

## 当前状态

设计阶段。Cocos 工程已建立但 `assets/` 为空，尚无运行时代码。

## 技术选型

- Cocos Creator 3.8，纯 2D，单机离线，不做联网与服务端
- TypeScript
- 数据驱动：数值、内容与规则参数全部走 JSON 配置表
- 模拟核心与表现层物理隔离：核心持有唯一权威状态并推进 tick，表现层只渲染、只派发命令
