# 市场系统 · 待调研与待设计

**定位：** 记录市场系统的**设计意图与边界**，供后续调研与细化。
**状态：** ⚠️ **待调研、待设计。本文不是设计结论，是一份待办说明。**

**边界：** 只写"这个系统打算做什么、框架有多大、哪些依赖它"。**不含任何数值、不含解锁序列、不含文献依据**——那些都要等调研。

---

## 1. 它现在处于什么状态

**市场是一个需要独立调研的新机制。**

**它的框架很大**——库存、物价、货币、区域间贸易、税收、金融，每一项展开都是一套系统，而且横跨后续多个时代。

**所以本阶段只登记它的存在与边界，不设计它。** 留到后续的贸易时代，连同货币与信用一起补全。

**本文不是设计结论。** 它的数值、解锁序列、代价，以及它和其他系统怎么咬合，**都还没有**。

---

## 2. 打算做什么（框架，未细化）

**市场是通过交换。**

| 要素 | 说明 |
| --- | --- |
| **地区库存** | 每个区块（或每个地区）持有库存 |
| **物价** | 各种产品各有物价 |
| **区域间贸易** | **根据物价，自动生成区域之间的贸易**——交换物品、流动资金 |
| **国家的两种动作** | **收税**；以及**用钱购买物资**——尤其是**买稀缺的军事产品** |

**框架很大。** 上面每一行展开都是一套系统，所以它单独成一个待调研项，不在本阶段落地。

---

## 3. 本系统的边界

### 3.1 它管「买」，不管「造」

**军事装备有两个来源：自己造，和买。这两件事必须分开。**

**本系统只承担「买」的那一半**——兵器**也是一种商品**，可以贸易；国家可以**用钱买到稀缺的军事产品**。

**「自己造」的那一半不在本系统内。** 自己研发技术、自己打造装备有它自己的科技、工匠与产能，**不需要市场也能成立**。

> ⚠️ **这个区分要保留：市场能让一个国家拿到它造不出来的东西，但拿不到它没掌握的技术。**

### 3.2 它管交换，不管产出

**实物产出不在这里。** 一块地被开发出多少东西，由资源与建筑决定，**不经市场**。

**市场管的是产出来之后的流通**——库存、物价、贸易、税收。

### 3.3 后续会挂进来的

货币、信用、金融、远洋贸易。**本阶段不展开。**

---

## 4. 落文档前必须先做的事

- **一轮独立调研。** 市场、物价、货币、区域间贸易各自都有文献，且互相牵扯。
- **确定它的空间单位。** 市场是长在区块上的，还是需要一个新的空间概念？这决定它属于空间系统还是独立系统。
- **确定它的解锁序列与代价。** 它和已定的几条线怎么咬合——尤其是它会不会和「征兵」抢人、和「拓展统治」抢粮。

> ⚠️ **在以上三件做完之前，本文不进设计结论。**
