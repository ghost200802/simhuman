# 市场系统 · 依据与推导

**定位：** 记录市场系统的历史材料、研究结论、争议和设计取舍依据。
**边界：** 本文不定义玩家操作、数值、接口或结算规则；游戏规则另存于《市场系统 · 游戏设计》。

## 一、证据使用原则

本项目模拟的是人类社会发展机制，不复刻某一地区或某一文明的固定历史路线。

历史材料用于回答：

- 某种生产、储存或交换机制是否存在历史先例；
- 机制出现需要哪些物质与组织条件；
- 哪些机制不应被写成全球同时出现的必然阶段；
- 哪些设计取值属于游戏抽象，而不是史实结论。

历史材料不用于规定玩家必须按现实历史顺序发展。

## 二、生产、消费与剩余

### 2.1 生产剩余不是自动等于长期财富

食物产出只有在满足保存、容器、设施、看守和组织条件后，才会形成可跨期使用的库存。

早期定居社会的考古研究显示，定居、储存和农业之间并非严格同步；在完整农业体系形成前，已经存在较稳定的定居与储存实践。Natufian 研究常被用于说明农业前定居与储存的关系。[Kuijt & Finlayson, 2009](https://doi.org/10.1073/pnas.0812764106)

因此可以区分：

- 当期产出；
- 当期消费；
- 可保存剩余；
- 跨期库存。

但“没有储存技术时多余食物直接损耗”是游戏抽象，并非所有历史社会的完整描述。自然干燥、地下储藏、季节性迁移和社会共享都可能形成不同的保存方式。

### 2.2 农业提高产量，也提高系统暴露面

农业与定居可能提高总产出和人口承载力，但也会增加劳动投入、疾病暴露、歉收风险和不平等结构。Bowles 等人的研究讨论了农业转型中生产、健康和劳动负担之间的张力。[Bowles et al., 2011](https://doi.org/10.1073/pnas.1010733108)

市场系统只负责把这些结果表现为库存、缺口和流通压力；农业本身的产量与人口后果由生产和人口系统解释。

## 三、储存与再分配

### 3.1 储存技术具有物质前提

储存效果取决于容器、建筑、干燥、防虫、防潮、看守和组织能力。陶器、坑窖、仓房、粮仓和冷藏设施并非同一种技术，也不应共享同一个固定容量或损耗率。

历史上的大型储存设施经常与权力和再分配组织相连。早期文字和计量记录的重要用途之一，就是记录粮食、牲畜、劳役和配给等物资关系。古代近东楔形文字材料可通过 [Cuneiform Digital Library Initiative](https://cdli.ucla.edu/) 查阅。

### 3.2 再分配不等于市场

中央仓库、贡赋、配给和行政发放可以在没有货币价格的情况下运行。Karl Polanyi 对古代经济中的互惠、再分配和交换作过区分；Finley 对古代经济中的市场关系和现代市场概念差异也有系统讨论。

因此，历史上存在：

- 没有统一货币价格的实物分配；
- 有计量单位但没有现代市场的行政记录；
- 有交换但没有自由价格形成；
- 有局部价格但缺乏统一市场。

## 四、交换、贸易与货币

### 4.1 交换早于统一货币，但形式并不单一

跨群体物品流动可以通过礼物、互惠、婚姻关系、贡赋、掠夺、契约和市场交易实现。把这些行为全部称为“贸易”会掩盖其制度差异。

因此，历史上不能把“没有铸币”直接等同于“没有任何交换”，也不能把有交换直接等同于“存在自由市场”。

### 4.2 计价单位与货币不是同一件事

古代社会可以先出现重量、数量、银或粮食等计量单位，再出现更稳定的支付工具、债务记录和货币制度。价格记录、结算单位、实物支付和铸币流通之间存在时间差。

因此，“价格在贸易机制之后出现”属于本项目为了让阶段差异清晰而采用的设计简化，不是全球历史通则。

### 4.3 贸易需要运输与信息条件

商品的跨区块流动受距离、道路、河流、海运、风险、季节、政治关系和信息速度约束。历史上的远距离贸易通常不是所有地点之间同时开放的自由流动，而是沿少数路线、节点和中介展开。

市场系统应把运输和路线作为贸易成立的物质条件，而不是只比较两个地点的商品数量。

## 五、价格与市场形成

价格形成需要至少具备若干条件：

- 商品可被比较和计量；
- 交易双方认可某种结算方式；
- 存在重复交换或债务记录；
- 信息能够传播；
- 运输成本可以被估算；
- 交易关系具有一定稳定性。

这些条件不会在全球同一时间满足。不同社会可以同时存在实物分配、贡赋、固定兑换、地方价格和货币市场。

本项目把“无价格生产消费”“市场持续运输”“贸易价格自动形成”拆成连续机制，主要是为了表现经济制度的逐步扩展；这不是对人类历史唯一顺序的断言。

## 六、工具与商品技术的连续变化

### 6.1 石器、青铜器和铁器不是整齐替换

考古材料显示，石器、铜器、青铜器和铁器之间存在长期重叠。早期铁器也不必然在所有用途上优于高质量青铜器；矿源、燃料、冶炼技术、加工工艺和维修条件都会改变其实际价值。

关于铁与青铜在工具和武器中的性能、成本关系，可参考 [Iron versus bronze for edge tools and weapons](https://doi.org/10.1007/BF03222302)。

### 6.2 技术传播不是全局瞬时解锁

生产方法的可用性取决于原料、知识传承、工匠、设施、燃料和维护。技术可以局部出现、长期不普及、失传后重新出现，也可以在不同地区形成不同生产路径。

因此，商品目录应允许：

- 同一商品存在多种生产方法；
- 新工具提高旧生产方法效率；
- 旧方法在���技术出现后继续存在；
- 生产方法因条件缺失而停用；
- 商品在不同地区不同步出现。

### 6.3 工具不是只有“解锁或未解锁”

工具还涉及质量、耐久、维护和适用生产方法。人类技术史中，材料性能、加工工艺与组织能力共同决定工具的实际效果，不存在一条只由材料名称决定的永久升级序列。

## 七、从工业到太空

工业化之后，商品关系从少量基本物资扩展到多级供应链：燃料、机器、化学品、金属、能源、运输设备和维护品相互依赖。

现代与太空阶段的商品将更多依赖：

- 复杂中间品；
- 高纯度材料；
- 能源密度；
- 精密设备；
- 维护和替换部件；
- 跨区块与跨国家供应链。

这些阶段缺少对应的历史经验，具体商品、生产方法和价格机制属于未来设计推导，不应伪装成历史事实。

## 八、史实与设计取值对照

| 设计取值 | 历史依据 | 取值性质 |
| --- | --- | --- |
| 无储存能力时剩余产出损耗 | 保存需要容器、设施和组织；不同社会保存方式差异很大 | 游戏抽象 |
| 早期没有价格和货币 | 实物分配和再分配先于部分货币市场；但交换与计量可能更早出现 | 阶段化设计，不是全球史实断言 |
| 无贸易时由玩家手动调配 | 运输与分配需要具体组织；早期制度差异很大 | 玩家操作抽象 |
| 市场阶段先有持续运输、后有自动贸易 | 市场、运输、价格和货币并非同一时刻出现 | 机制拆分设计 |
| 贸易产生价格 | 重复交换和计量有助于价格形成，但价格也可能先于成熟贸易制度 | 简化设计 |
| 石器、青铜器、铁器形成生产方法差异 | 技术长期并存，性能和成本随材料与工艺变化 | 历史约束下的机制抽象 |
| 商品随知识、原料、设施和维护条件出现 | 技术传播和生产能力具有地区差异与路径依赖 | 机制依据 |

## 九、仍需独立调研的项目

以下内容不在本版给出游戏规则：

- 储存设施的历史类型与损耗范围；
- 古代粮食、盐、金属和纺织品的计量方式；
- 无货币交换、贡赋和行政配给的案例库；
- 早期价格记录与货币形成；
- 古代道路、河运和海运的运输能力；
- 青铜、铁和钢的生产链与地区差异；
- 工业和太空阶段商品的历史外推边界。
