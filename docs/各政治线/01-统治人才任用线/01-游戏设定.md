# 政治线 01 · 统治人才任用线 · 游戏设定

**定位：** 定义这条线上玩家看到什么、能做什么、会发生什么。
**边界：** 不含历史依据、不含数值取值、不含界面方案。文献依据另存。
**不绑定时代。** 这条线按自己的经验与依赖推进，任何时代都可以继续往深处走，任何时代也不要求它走到哪一步。

**一句话：** 你的官位有限，而"谁有资格做官"每换一次，就换一批人受益——也换一批人变成敌人。

---

## 1. 这条线管什么

**谁有资格做官、怎么被选上来。**

它不管中央与地方的结构关系——那是另一条线。两条线各走各的，可以任意组合。

---

## 2. 玩家看到的读数

**五个，全部可见。没有隐藏值。**

| 读数 | 位置 | 值域 | 含义 | 删掉它，核心体验会损失什么 |
| --- | --- | --- | --- | --- |
| **本线经验** | 全局一条 | 累积值，不清零 | 随时间涨；**叛乱与负面事件让它涨得多** | 这条线没有推进机制，解锁变成凭时间自动发生 |
| **官位** | 每区块一个数 | 整数 | 该区块需要几个人管 | 分母消失，占据度与待选者都算不出来 |
| **候选人池** | 每区块一个数 | 整数 | 当前资格标准下，该区块有资格的人数 | 玩家看不出"换了标准之后谁受益"，改标准变成盲操作 |
| **家族占据度** | 每区块，0–100% | 百分比 | 该区块的官位有多少比例被**同一个人丁最旺的家族**占据 | 俘获过程不可见，玩家不知道问题出在哪一块 |
| **待选者** | 全局一个数 | 整数，可为负 | 候选人池总数 − 官位总数 | 精英过剩不可见，叛乱值上涨显得无来由 |

### 三个读数的算法

```
官位       = 该区块的人口规模换算出来的管理岗位数
候选人池   = 该区块内在当前资格标准下够格的人数
家族占据度 = max(单一家族占据的官位数) / 官位总数 × 100%
待选者     = Σ 候选人池 − Σ 官位
```

**官位不由玩家自由增加**——它跟着网络规模走。玩家想多要官位，只能去扩张。

---

## 3. 玩家能做的操作

| 操作 | 粒度 | 立即效果 | 长期效果 |
| --- | --- | --- | --- |
| **换人** | 每个官位 | 该区块村落凝聚力**一次性小降** | 可换的人受**当前资格标准**限制 |
| **改资格标准** | 全局一条 | 候选人池**立刻重算**；**同时立刻产生一批被排除者** | 家族占据度按新标准**从零重新累积** |
| **推动改制** | 一批官位 | 消耗资源与期数 | 已改制的官位适用新标准；**未改制的继续按旧标准运行** |
| **开新官位** | 全局 | 官位总数上升，**待选者下降** | 扩张网络才会带来 |
| **收窄门槛** | 全局一条 | 候选人池变小，**待选者下降** | 被排除者按"离官位有多近"转化为**叛乱压力** |

**五个操作全部是手动。** 没有自动替换、没有自动改制。

---

## 4. 解锁条目

**每条的条件 = 本线经验达到阈值 + 附加依赖（可为空）。** 任一不满足则不可解锁。

| 序 | 条目 | 本线经验 | 附加依赖 | 资格标准 | 玩家多了一样什么能力 | 它的代价 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | **氏族家长** | 低 | 无 | 出身 | 该区块第一次出现**一个常设位置**。玩家指定谁占据它 | 这个人决定该区块的**凝聚恢复速度**；换人的候选范围很小 |
| 2 | **推举** | 中 | 无 | 出身 + 资格池 | **可以设「资格池」**——池内的人才有资格被推举 | 池子**窄**→ 凝聚力稳（无人被排除），但**那几家一出事，整个网络没有替补** |
| 3 | **世卿世禄** | 中 | 无 | 血缘 | 该区块凝聚力获得**加成** | **可换的人极少**——换谁都是那几家 |
| 4 | **军功爵** | 高 | 有战果产生 | 战果 | 资格第一次**可累加、可兑换、可传给子嗣** | 和平期没有战果可算 → **资格断供**；资格**可以被卖掉** → 通胀 |
| 5 | **察举** | 高 | 无 | 声誉 | **岁举名额**：按该区块人口换算出的推荐名额 | 不举荐 → 该区块凝聚力受罚；**声誉的生产需要资源，富裕家族产出快** |
| 6 | **九品中正** | 高 | 无 | 中正品状 | 评议权**收归中央**——不再由地方产出 | **评审人即受益人**；占据度**涨得更快** |
| 7 | **科举** | 很高 | 科技条件 | 卷面 | 该标准下**占据度上涨速度显著压低** | 改制成本高；备考需要**脱产时间**，教育值越高门槛越高 |
| 8 | **现代教育** | 很高 | 科技条件 + 全局 flag | 文凭 | 候选人池**大幅扩大** | **门槛随教育值自己往上爬**——正反馈，没有出口 |

### 两条不进解锁序列的东西

**① 收窄门槛** —— 不是解锁条目，是**随时可做的操作**（见第 3 节）。

**② 门阀** —— 不是解锁条目，是**家族占据度涨到 100% 时自动出现的被动形态**。

| 门阀形态下 | 表现 |
| --- | --- |
| 换人 | 只能在世族内进行 |
| 改革选项 | **被锁死**（见 5.5） |
| 玩家看到 | 该区块占据度读数满格，且**换人按钮变灰**，提示"当前无人可换" |

**门阀的出口是换资格标准**——只要已解锁的标准里有一个不依赖门第，改革按钮就重新可用。

---

## 5. 机制清单

以下机制服务于第 6 节的张力。每个都写成三件套。

### 5.1 资格标准的更替

| | |
| --- | --- |
| **玩家看到** | 一条全局的资格标准选择条。切换时弹窗显示：受影响的候选人数、**被排除者数**、预计叛乱压力增量 |
| **玩家做什么** | 在已解锁的标准里选一个生效 |
| **会发生什么** | 候选人池立刻重算；被排除者**按"离官位有多近"的比例**转化为叛乱压力；家族占据度**从零重新累积** |

**这是这条线唯一能重置占据度的手段。**

### 5.2 家族占据度

| | |
| --- | --- |
| **玩家看到** | 每区块一个 0–100% 读数，随时间上涨。**上涨速度 = 「生产该证明所需的资源」在该区块的集中度** |
| **玩家做什么** | 换人、改资格标准、推动改制 |
| **会发生什么** | 占据度越高 → 该区块**可换的人越少** → 村落凝聚力**掉得越快** → 叛乱值上涨 |

**占据度是这条线接进风险轴的地方：它与"任期越长掉得越快"并列，是村落凝聚力下降的第二个来源。**

### 5.3 待选者（精英过剩）

| | |
| --- | --- |
| **玩家看到** | 全局一个数。为正时显红，并显示"叛乱压力 +X" |
| **玩家做什么** | 开新官位（扩张）、或收窄门槛（缩小池子）、或改标准 |
| **会发生什么** | 待选者为正 → **叛乱值上涨加速**；同时**本线经验涨得快**（失败教你统治） |

> **这是这条线唯一一个"玩家希望它变大、但它一直在制造麻烦"的数。** 候选人池要靠教育值养大——而池子越大，待选者越多。

### 5.4 换人与可换性

| | |
| --- | --- |
| **玩家看到** | 每个官位上有一个"可换人选"计数。占据度高时这个数很小 |
| **玩家做什么** | 点换人 |
| **会发生什么** | 凝聚力一次性小降；可换人选的**范围由当前资格标准决定** |

**关键：占据度不禁止玩家换人，它只是让可换的人越来越少。** 玩家始终能换，只是换无可换。

### 5.5 改革锁

| | |
| --- | --- |
| **玩家看到** | 改标准的按钮**变灰**，提示"当前无人可换" |
| **玩家做什么** | 无法操作——除非已解锁的标准里有一个**不依赖当前占据资源**的 |
| **会发生什么** | 锁**自动解除**。玩家不需要额外操作 |

**这是"看得见的问题、改不动的制度"。** 封锁本身不是惩罚，是提示：**需要下一段制度才能解开上一段。**

### 5.6 改标准的代价

| | |
| --- | --- |
| **玩家看到** | 切换弹窗里的"预计叛乱压力 +X" |
| **玩家做什么** | 确认或取消 |
| **会发生什么** | 被排除者**分批**转化为叛乱压力——**推动改制时按已改制的官位比例分批产生**，不是一次全来 |

**换制度不是免费的按钮。** 这是这条线最主要的叛乱加速来源之一。

### 5.7 资格通胀

| | |
| --- | --- |
| **玩家看到** | 战果类资格（军功爵）下，资格总数持续上升，而**每个资格能换到的东西持续下降** |
| **玩家做什么** | 用资格兑换资源、免罪、或传给子嗣 |
| **会发生什么** | 资格**从身份变成商品**：可以卖 → 供给无限 → 价格取代价值 → 激励失效 |

**这是游戏里第一次出现"资格本身会贬值"。** 玩家能看到资格越来越多、越来越不值钱，而官员越来越不称职。

---

## 6. 核心张力

> **每一段制度都是为了打破上一段的俘获而设计的，而每一段制度自己也会被俘获——因为每一段要求的「证明」，都需要一种只有既得利益者有富余去生产的资源。**

两侧都是具体的、看得见的：

| | 收益 | 代价 |
| --- | --- | --- |
| **换资格标准** | 占据度**从零重新累积**；改革锁解除 | **立刻产生一批被排除者**，按"离官位有多近"转化为叛乱压力 |
| **不换** | 没人被排除，凝聚力稳 | 占据度**一路涨到 100%**；可换的人越来越少；凝聚力掉得越来越快 |

**并且这个张力没有出口：** 每一段要求的资源都是当时既得利益者恰好富余的东西——所以新制度总是**从低占据度开始，然后重新爬上去**。

---

## 7. 解不掉的压力

**待选者永远为正。** 玩家能靠扩张开新官位、靠收窄门槛缩小池子，但**教育值在涨 → 候选人池在涨 → 官位跟不上**。

玩家能做的只有在本线经验上往前推，用下一段制度把上一段的占据度重置——**而下一段马上开始新的累积。**

---

## 8. 这个时代不该有的

**本线的禁令：**

- **不得让占据度自动回落。** 它只能被"换资格标准"重置，不能被时间冲淡。
- **不得让换人免费。** 换人一定有一次性代价。
- **不得让改革锁由玩家花资源硬解。** 它只能被"已解锁的另一套资格标准"解开。
- **不得让资格标准每条区块各设一套。** 全局一条——**标准是全局的，后果是分区块的**。
- **不得禁止玩家用低级的资格标准。** 解锁是扩菜单，不是替换。
- **不得让待选者自动消失。** 它只能被开新官位或收窄门槛消除，且两者都有代价。

---

## 9. 验收要点

1. 玩家能**看见**每个区块的家族占据度在涨，并且能指出是哪种资源在起作用。
2. 玩家能感受到**占据度真的会卡死自己**——门阀形态下换人按钮变灰。
3. 玩家能观察到**改资格标准立刻产生敌人**——弹窗上的"预计叛乱压力"是真的。
4. 玩家能感知**推动改制是一条要爬的曲线**，不是一次点击。
5. 玩家能经历**资格通胀**——资格越来越多、越来越不值钱。
6. 玩家在本线上**始终有解不掉的压力**——待选者永远为正。
7. 玩家能亲手把**门阀形态解开**——靠解锁下一段制度。
