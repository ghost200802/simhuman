# 政治线 02 · 中央与地方关系线 · 游戏设定

**定位：** 定义这条线上玩家看到什么、能做什么、会发生什么。
**边界：** 不含历史依据、不含数值取值、不含界面方案。文献依据另存。
**不绑定时代。** 这条线按自己的经验与依赖推进，任何时代都可以继续往深处走，任何时代也不要求它走到哪一步。

**一句话：** 权力第一次能超出你走得到的范围——但它得靠别人的手来执行，而别人的手会越来越难松开。

---

## 1. 这条线管什么

**中央怎么管地方**——权力以什么形式铺到每一个区块上。

它不管"谁来做官"——那是另一条线。两条线各走各的，可以任意组合。

---

## 2. 玩家看到的读数

| 读数 | 位置 | 值域 | 含义 | 删掉它，核心体验会损失什么 |
| --- | --- | --- | --- | --- |
| **本线经验** | 全局一条 | 累积值，不清零 | 随时间涨；**叛乱与负面事件让它涨得多** | 这条线没有推进机制 |
| **统治方式** | 每个区块一个 | 已解锁的方式之一 | 该区块由谁管、怎么管 | 玩家无法分辨"哪块直辖、哪块委派"，多区块管理变成一团糊 |
| **委派任期** | 每个受委派的区块一个 | 期数 | 当前代理人已经管了多少期 | 玩家看不出"问题正在积累"，只觉得凝聚力莫名其妙在掉 |
| **上缴量** | 每个受委派/分封的区块一个 | 数值 | 该区块每期向主区块上缴的资源 | 正反馈（远处的产出养中央）不可见 |
| **村落凝聚力** | 每区块一条 | 已有计量 | 沿用 | — |
| **叛乱值** | 每区块一条 | 已有计量 | 沿用 | — |

**五个读数全部可见。** "哪个区块由谁管"在地图上直接可读。

---

## 3. 玩家能做的操作

| 操作 | 粒度 | 立即效果 | 长期效果 |
| --- | --- | --- | --- |
| **设统治方式** | 每个区块 | **该区块村落凝聚力一次性下降** | 决定该区块的管法与上缴方式 |
| **设任期长度** | 每个受委派的区块 | 无 | 决定代理人的更换频率 |
| **换代理人** | 每个受委派的区块 | 该区块凝聚力**一次性消耗** | **"随任期累积的那部分惩罚"归零重新计数** |
| **粮食收买** | 每个区块 | 消耗粮食，凝聚力回升 | 前期的主要手段 |
| **派驻军队** | 每个区块 | 压制叛乱值 | **本线只留占位**，具体规则不在本文 |

**五个操作全部手动。** 但**代理人的更换是自动的**——玩家只需要设任期长度，不需要逐个点。

---

## 4. 解锁条目

**每条的条件 = 本线经验达到阈值 + 附加依赖（可为空）。**

| 序 | 条目 | 本线经验 | 附加依赖 | 形态 | 玩家多了一样什么能力 | 它的代价 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | **直辖** | 起手即无（默认形态） | 无 | 方式 | 区块由玩家直接管理。**这是起手唯一的形态** | 铺不出临近度撑得住的范围 |
| 2 | **委派** | 低 | 无 | 方式 | **派人去管。权力第一次越过邻近度那面墙** | 该区块凝聚力**随任期持续下降**；迟早跌破 0 |
| 3 | **任期制度** | 中 | 无 | **开关** | 解锁后**才能选任期长度** | 更换时该区块凝聚力**一次性消耗** |
| 4 | **分封** | 高 | 无 | 方式 | 更进一步的下放 | 下放得越深，收回来越难 |
| 5 | **郡县** | 高 | 科技条件 | 方式 | 收回来的形态——**直辖可以铺到更远了** | 只在临近度撑得住的地方可用 |

### 关于第 3 条，这是本线最重要的一处设计

**任期制度解锁之前，委派是永久的。**

这不是"被规则禁止"，是**玩家还没有办法**——代理人自动更换，但换谁都在累积任期惩罚，而玩家不能选择让他们多久换一次。

**这是这条线的开局压力：你已经能把权力伸出去，但还没有办法不让它坐大，只能靠粮食硬扛。**

---

## 5. 机制清单

### 5.1 邻近度的墙

| | |
| --- | --- |
| **玩家看到** | 地图上每个区块有一个**邻近度**读数（已有计量）。邻近度低到一定程度后，该区块的凝聚力**仅靠社会节点已经拉不回来** |
| **玩家做什么** | 修路（提高邻近度）、或改用委派 |
| **会发生什么** | 委派能越过这面墙拿到远处的资源；不委派则边界就停在走得到的地方 |

**关键：这面墙不是一条硬规则。** 它是**算出来的**——基础距离、地形、道路、科技共同决定邻近度的 cost。玩家可以强行维系远处，只是贵。

### 5.2 委派任期

| | |
| --- | --- |
| **玩家看到** | 每个受委派区块的**任期**读数在涨；同时该区块的村落凝聚力**持续往下走** |
| **玩家做什么** | 任期制度解锁前：只能靠粮食收买硬扛。解锁后：设任期长度 |
| **会发生什么** | **同一个人管得越久，每单位时间掉得越多**——不是线性，是加速 |

**更换代理人时：** 该区块凝聚力**一次性消耗**，而"随任期累积的那部分惩罚"**归零重新计数**。

### 5.3 上缴与再分配

| | |
| --- | --- |
| **玩家看到** | 每个受委派/分封区块的上缴量；以及叛乱值上涨时它**同步打折** |
| **玩家做什么** | 决定哪些区块值得救（粮食收买）、哪些放弃 |
| **会发生什么** | 凝聚力高、叛乱值低时上缴多；叛乱值上涨期间，**该区块全部产出按叛乱值等比打折** |

**这是这条线的正反馈来源：多管一块地 → 更多上缴 → 养更多人口 → 能管更远。**

### 5.4 干预手段

| 手段 | 玩家看到 | 代价 |
| --- | --- | --- |
| **粮食收买人心** | 凝聚力读数回升 | 消耗粮食。**前期的主要手段** |
| **派驻军队镇压** | 叛乱值被压住 | **本线只留占位**，军事系统不在本文 |

**两者都是手动操作**，用在玩家判断"这一块值得救"的时候。

### 5.5 与任用线的咬合

**这条线与任用线在"代理人换不掉"这一点上直接咬合：**

| | 造成的后果 |
| --- | --- |
| **任期越长**（本线） | 凝聚力掉得越快 |
| **可换的人越少**（任用线的家族占据度） | 凝聚力掉得越快 |

**两者叠加时，玩家会同时面对"这个人管太久了"和"换谁都是那几家"。** 两条线可以任意组合使用，但组合起来会更难。

---

## 6. 核心张力

> **委派能让权力超出邻近度撑得住的范围，但代理人会坐大——同一个人管得越久，那个区块的村落凝聚力掉得越快；不委派，你的边界就停在走得到的地方。**

两侧都是具体的、看得见的：

| | 收益 | 代价 |
| --- | --- | --- |
| **委派** | 权力越过邻近度的墙；拿到远处的资源 | 该区块凝聚力**随任期持续下降**，迟早跌破 0、叛乱值开始涨 |
| **不委派** | 凝聚力稳，不用付出维护 | 边界停在走得到的地方 |

**形式化：** 控制每单位面积的总成本随半径增长。

### 出口是软的，而且要靠积攒才能打开

**本线经验**随时间涨，**但叛乱与负面事件让它涨得多得多**——**失败教你统治**。

```
直辖（起手）
  → 委派              ← 派人去管
  → 任期制度          ← 解锁后，委派才能选任期长度
  → 分封
  → 郡县
```

---

## 7. 解不掉的压力

**委派的收益与代理人坐大是同一件事。** 玩家能平衡它们，不能取消它们。

**并且任期制度解锁之前的那一段时间，玩家只能靠粮食硬扛**——这是这条线唯一一段"知道问题在哪、但手上没有工具"的时期。

---

## 8. 本线的禁令

- **不得让委派免费。** 凝聚力随任期下降是这条线张力的支点。
- **不得让代理人永远忠诚。** 忠诚要用资源买，而且会衰减。
- **不得让"远处成本大于收益"由一条规则设定。** 它必须**由邻近度、任期和上缴算出来**——玩家可以强行维系，只是贵。
- **不得禁止玩家用低级的统治方式。** 解锁是扩菜单，不是替换。
- **不得让切换统治方式没有代价。** 切换一定有一次性凝聚力下降。
- **不得把任期惩罚做成线性的。** 它必须**加速**，否则"同一个人管得越久"这层意思就没了。

---

## 9. 验收要点

1. 玩家能感受到**权力第一次越过了邻近度那面墙**——远处的东西不用亲自去拿。
2. 玩家能感受到**代理人真的会坐大**——同一个区块管得越久，凝聚力掉得越快。
3. 玩家能观察到**每个区块的统治方式**，并且可以随时重画这张图。
4. 玩家能感知**本线经验是被麻烦推上去的**——叛乱之后，能解锁的东西明显多了一截。
5. 玩家在**任期制度解锁前**有一段只能硬扛的时期，并且能感觉到那是"没有工具"而不是"被禁止"。
6. 玩家在本线上**始终有解不掉的压力**。
7. 玩家能亲手把**快独立的区块拉回来**——这在没有这条线的时候做不到。
