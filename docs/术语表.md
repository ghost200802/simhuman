# SimHuman 术语表

**定位：** 全项目关键名词的权威定义。任何文档里的名词，含义以本表为准。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

## 一、空间

| 术语 | 定义 | 引入 |
| --- | --- | --- |
| **区块** | 全局唯一的核心空间单位。**一个人一天来回的区域**（约 10 km），相当于现代一个村的腹地。内部无坐标、无地形网格、无移动。地图由区块与区块之间的相邻关系构成。**区块是整局游戏唯一不会变动的空间概念。** | era 01 |
| **主区块** | 玩家最初定居、并始终作为网络中心的那个区块。**临近度从这里起算。** | era 04 |
| **非主区块** | 属于玩家、但不是主区块的区块。**只有非主区块会独立。** | era 04 |
| **相邻区块** | 与某区块直接相连的区块。新聚落只能建在相邻区块上。 | era 02 |
| **临近度** | **一个区块到主区块的通达程度，0–100。主区块恒为 100。** 沿**最省路径**（不是最短路径）传播，每跳扣掉该跳的 cost。**cost 由基础距离、地形、道路、科技共同决定**——所以临近度不等于距离。它是可被玩家投资改善的量。 | era 04 |
| **基础距离** | 两个相邻区块之间的一跳。是临近度 cost 的**基准项**，本身不随游戏推进变化。 | era 04 |
| **建筑格** | **区块内可被建筑占用的等价格位。** 完全等价、没有空间位置与地形差异，仅作为可占用进行生产的抽象格。**它只是区块上的两个计数：容量与已解锁数**——不需要记录"占的是哪一格"。**不是实体。** | 架构层 |
| **聚落** | 一个**已开发的区块**。人口居住与建筑占用都归属于所在聚落。**不是实体**，由该区块上的建筑与人口表达。 | 架构层 |
| **区块探索度** | 区块级计量。随停留与实际使用上升，随时间缓慢回落，**不因迁移重置**。 | era 01 |

## 二、资源与生产

**一个区块的自然资源禀赋，由「资源配额 + 资源品味」两项表达。探索揭示的就是这两项。**

| 术语 | 定义 |
| --- | --- |
| **资源格** | 区块上**一格某类资源**的可开发位。**建一座资源设施，要同时占用一个建筑格、消耗一个对应的资源格。** |
| **资源配额** | 每个区块对**每一种资源**的资源格数量上限。由区块的地貌与属性决定，**开局随机生成**。 |
| **资源品味** | 每一格资源的基础产出水平——耕地的**肥沃度**、铁矿的**品位**等。设施产出 = **资源品味 × 当前生产效率**。 |

**三条要分清：**

- **配额 = 有多少格，品味 = 每格多好。** 两项独立，都随区块走。
- **探索揭示的是配额与品味**（以及有没有这种资源）；**科技揭示的是此前未被认识的资源种类**。两者相互独立——某区块的建筑格全解锁了，它的资源仍可能没探明。
- **图鉴记录的是"你认不认识"，配额与品味记录的是"这里有多少、多好"。** 认识一种资源不等于知道你脚下有多少。

## 三、时代计量

### era 01 起

| 术语 | 定义 |
| --- | --- |
| **人口** | 分**成年 / 未成年**分别计数。只有成年执行任务；任务损失只扣成年人口。 |
| **可投入劳动人口** | 当下能派出去执行任务的那部分成年人口。 |
| **成年率** | 成年人口占总人口的比例。 |
| **成年存活率** | **era 01 的时代主线计量。** 决定科技节点的**流失**速度。 |
| **营养 / 体力 / 脑力** | 营养由食物产出转化；体力提高狩猎产出；脑力提高所有科技节点的研发。 |
| **教育值** | 知识在人口中铺开的程度。决定同样的人口损失会掉多少科技。 |
| **科技节点进度** | 见第三节。 |

### era 03 起

| 术语 | 定义 |
| --- | --- |
| **村落凝聚力** | **era 03 引入、era 04 扩展的时代主线计量。每个区块一条，各自结算。** 下降来源：本区块人口、分工深度、**临近度**。上升来源：**社会节点**。 |
| **可耕地上限** | 区块属性，固定值，**科技不改变它**。占满后人口继续涨即产生缺口。 |
| **单位面积产量 / 选育进度 / 抗性** | 见第三节。 |
| **储粮容量 / 地力** | 区块与设施的属性。 |

### era 04 起

| 术语 | 定义 |
| --- | --- |
| **独立倒计时** | **非主区块**的村落凝聚力跌破 0 后启动的进度条。凝聚力回到 0 以上则**停下并回落**；走完则该区块脱离控制。 |
| **网络总人口** | 玩家所有区块的人口之和。 |
| **主区块饥荒** | 主区块的村落凝聚力跌破 0 时的表现——人口损失与产出下降。**主区块不会独立。** |

## 四、节点与系统

### 三类节点

| 术语 | 定义 |
| --- | --- |
| **科技节点** | 进度 0–100。**研发**从任务经验中涨；**流失**每期自动掉；损失人口时按各节点自己的**影响系数**额外**掉落**。**100 解锁，已解锁跌破 50 失效，失效后要重新爬满 100 才能再用。状态只有 0 / 1。** |
| **图鉴** | 材料 / 动物 / 植物。条目等级逐物种不同，**升级制**，**永久保留**。推进条件是在区块内**停留并实际使用**该资源。 |
| **社会节点** | 三类节点之一。era 01 引入（主动教学），era 04 起是**提高村落凝聚力的唯一手段**。 |

| 术语 | 定义 |
| --- | --- |
| **影响系数** | 每个科技节点自带的值，含义是"这项技能有多依赖特定的人"。系数高掉得多，系数低掉得少。 |
| **文明 flag** | 文明级状态，**不占科技节点位**。例：稳定火源。用于门控科技节点与图鉴阶段。 |

### 操作与设施

| 术语 | 定义 |
| --- | --- |
| **任务** | era 01 引入的**唯一操作面**：狩猎 / 采集 / 打制 / 探索。占用可投入劳动人口与期数，有损失概率。 |
| **建筑** | era 02 引入。era 01 一座都没有。无工人时只是不产出；**迁移时进入废除状态**。 |
| **道路** | era 04 引入。修在相邻区块之间，**降低该跳的临近度 cost**。 |
| **灾害** | 损失人口与储存，**同时提升抗性**——这是抗性的唯一来源。 |

## 五、时代机制

| 术语 | 定义 |
| --- | --- |
| **叠加原则** | **时代推进是叠加，不是替换。** 本时代 = 已有能力的全集 + 一条新增的成长线。旧能力一直可用，上限不变。 |
| **失传** | 倒退的形式。**时代标签从不回退**；崩溃表现为人口崩塌、储存丢失、部分技能与匠人失传。玩家仍在同一时代。 |
| **裂变** | era 04 新增。派出一部分人口与物资到**相邻区块**建立新聚落。**母聚落不废弃**——这是与 era 02 整体搬迁的分界。 |
| **独立** | era 04 新增。非主区块凝聚力跌破 0 并走完倒计时后**脱离控制，成为中立聚落**。时代标签不退、图鉴不丢、科技节点不掉，丢的是那块地与上面的产能。征讨与收服不在 era 04。 |
| **时代主线计量** | 每个时代用于承载核心张力的那个计量：era 01 成年存活率、era 03 起村落凝聚力。**只涨不跌的进度条不构成主线计量。** |

## 六、命名规则

1. **同一概念全文只有一个名字。** 不得出现同义词并存。
2. **不得使用 P / s / L 这类代码符号**，一律用中文表述（进度、研发、流失）。
3. **本表是唯一权威源。** 某份文档需要一个本表没有的名词时，**先加到本表**，再在文档里使用。
4. 本表按**概念族**分组（空间 / 资源与生产 / 时代计量 / 节点与系统 / 时代机制），组内按**引入时代**排列；不按文档归属分组。
