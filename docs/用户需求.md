# 社群文明演化模拟：用户需求

**文档性质：** 用户直接提出的概念整理  
**执行级别：** 本文全部内容均为必须执行的产品需求  
**整理方式：** 按概念主题归纳，不按对话轮次或提出先后排列

本文只记录用户提出的目标、体验和必须表现的内容；具体的时代数量、数值公式、科技节点名称、界面方案和程序结构均属于后续设计范围。

## 一、产品定位与玩法形态

### 1.1 游戏主体

- 游戏模拟的对象是人类社会从原始生存发展到现代科技和太空社会的全过程。
- 游戏的主要操控主体是社群整体，而不是单个英雄或单个长期成长角色。
- 游戏整体采用 2D 形式表现。

### 1.2 玩法参考

- 玩法参考必须落实到"参考某款游戏的哪一个方面"，不把任何一款游戏当作整体模板照搬；每款被点名借鉴的游戏都需说明其被借鉴的方面与必须修正之处。
- 参考《孢子》的分阶段成长体验（将历程分成阶段、不同阶段侧重点不同），但游戏主体必须是社群整体而非单个个体。
- 参考《维多利亚 3》的随时间持续推进、生产与消耗持续结算的流程，及其抽象化、非空间拼图式的建筑与区块表达。
- 参考《群星》用分层区块承载资源与建筑的思路，但世界必须连续铺展，不采用星图式离散跳点结构。
- 不同阶段必须拥有不同的主要目标、可用能力和关注重点。
- 游戏需要支持多次重开，每次重开都应成为一次新的社群发展历程。
- 游戏理论上应支持社群持续发展和长期游玩，而不是只围绕一次性通关设计。

## 二、现实历史与时代逻辑

### 2.1 现实一致性

- 游戏内容必须尽量符合现实历史、物理规律、生态条件、技术条件和社会运行逻辑。
- 游戏应达到类似历史教科书的可信程度，同时对历史中存在争议的内容保留审慎表达。

### 2.2 时代划分

- 游戏应覆盖远古、旧石器、新石器、早期国家、工业革命、电气、AI 和太空等发展阶段。
- “奴隶时代”“封建时代”等名称可以根据历史准确性调整，不应被强行当作唯一的技术阶段。
- 每个时代必须由该阶段的主要能力、物理限制、技术限制和社会特征共同定义。
- 每个时代必须回答社群为什么能够进入下一时代以及进入前需要哪些积累。
- 每个时代必须回答人类为什么可能长期停留在该阶段。
- 每个时代必须允许社群因环境、战争、人口、资源、制度或知识问题而退回较低复杂度。
- 时代转换不能被设计成研究固定科技清单后自动发生的单线升级。
- 某些时代转换必须允许由外部刺激、环境变化、竞争压力或重大危机触发。

### 2.3 地理与政体

- 地理条件必须影响资源分布、交通成本、灾害风险、人口密度、政治边界和技术收益。
- 封建、地方分权和中央集权应作为相近技术水平下的不同治理方案。
- 当交通、道路、运河和信息能力不足时，地方分权或封建关系应具有现实优势。
- 当道路、运河、行政和通信能力提高后，中央集权应能够变得更可行。
- 洪水治理等具体环境压力应能够推动更强的组织能力和中央权力形成。
- 缺少相应环境压力时，社群应可能继续停留在较低复杂度的组织形态。
- 中央集权与地方分权必须能够在历史条件变化后互相转换。

## 三、社群发展、反馈与计量

### 3.1 发展对象

- 游戏必须同时表现身体状况、智力或认知、技术积累、社会组织形态和表达方式的发展。
- 身体、营养、认知、技术、人口、组织和语言之间必须形成相互促进的长期反馈关系。
- 社会复杂程度、个体脑容量或认知能力、社会最高可获得温度等应成为重要计量方向。

### 3.2 计量规则

- 不同阶段必须使用不同的关键计量值，早期与后期的指标权重不能完全相同。
- 计量值必须能够作为技术节点或时代转换的前置条件。
- 技术必须能够反过来改变相关计量值，形成技术与社会状态的双向作用。
- 某些计量值必须通过持续执行对应操作逐步推进，而不能靠一次研究瞬间获得。
- 早期的身体和认知成长应与长期营养、蛋白质供给和社会复杂度相关联。
- 持续选育种子应逐渐改变作物产量、抗异常能力等可遗传性状。

### 3.3 科技内容规模

- 每个时代都应拆分出许多小型科技或发展节点，并按农耕、社会、工艺等类别组织。
- 每个时代最终应规划至少 50 种可区分的科技或发展节点。
- 科技节点必须与资源、计量值、社会组织、时代约束和后续发展发生联系。

## 四、必须表现的历史进程与事件

### 4.1 发展进程示例

- 游戏必须表现从野果采集、石器制作、动物狩猎、蛋白质增加到人口、社群组织、语言和认知共同发展的过程。
- 游戏必须表现从木材燃烧、木炭生产、可获得温度提高到冶炼和金属材料扩展的过程。
- 游戏必须表现农业选种通过多代持续积累改变产量、抗灾性和社群稳定性的过程。
- 游戏必须表现技术进步带来新生产能力的同时，也带来更高的组织、运输、维护和冲突成本。

### 4.2 事件类型

- 游戏必须包含天气、气候和其他自然环境事件。
- 游戏必须包含社会思潮、价值变化、社会运动和内部冲突事件。
- 游戏必须包含外国社群、邻近势力、迁徙群体和外部侵略事件。
- 事件应当以随机或半随机方式出现，并根据时代、地理和社群准备程度产生不同结果。
- 早期天气事件应对社群产生巨大影响，而堤坝、防洪、防汛、储存和预警建设完成后，同类事件的直接生存影响应当降低。
- 同一事件在不同时代必须表现出不同的后果类型，而不是始终使用同一套固定惩罚。

## 五、多次重开、局外成长与难度

### 5.1 局外成长

- 每个时代应提供许多可以选择的时代特性，并为当前时代提供对应加成。
- 玩家应通过多次游戏积累点数购买时代特性。
- 局外点数采用成就点数式的获取体系：每进入一个新的时代结算一次，文明终局再结算一次；过程中完成的任务与小成就可以带来部分点数。
- 局外点数是相对珍贵的长期资源，用于局外成长（如购买时代特性），不在单局内的常规决策中随手消耗。
- 当一局进展不顺时，玩家可以用已积累的局外点数解锁更多局外加成，然后开始新的档案重新游玩，以获得更好的开局体验。
- 游戏应通过成就解锁跨时代加成，使后续重开能够继承长期经验或文明遗产。
- 局外加成应提高起点、选项或容错，同时保留本局资源积累和决策的重要性。

### 5.2 难度与失败

- 游戏整体难度不应过高，玩家不应被要求以追求最高难度作为主要目标。
- 游戏应提供不同难度档位，并通过事件影响、资源波动和恢复空间体现差异。
- 难度越高，各类随机事件的影响应越大。
- 高难度下缺少初始加成时，社群可能在早期直接失败。
- 常规难度必须提供足够的修复空间，使玩家能够一路体验社群发展过程。
- 失败应产生新的局外积累和解锁动力，而不是让每次失败都失去全部长期进展。

## 六、世界、地图、探索、定居与资源生产

### 6.1 世界与地图形态

- 世界由许多具空间范围与相邻连接关系的区块连片构成，区块是地图上唯一具有空间与邻接意义的结构。
- 区块只在玩家能够抵达之处按需生成，世界不设固定总边界。
- 区块内部不设空间网格，其可开发内容仅以数量表达，内部不存在坐标或移动。
- 每个区块包含按配置确定数量的等价建筑格；建筑格完全等价、没有空间位置与地形差异，仅作为可占用进行生产的抽象格。
- 每个区块可开发的建筑格总量与玩家起始区块的初始可开发建筑格数量均按配置确定。
- 地图布局与各区块的资源在开局时随机生成。
- 每个区块具有环境或地貌属性（沿海、沿河、山地、平原、气候带等），决定该区可出现的资源种类、宜居程度与运输难度，并与现实地理和时代条件相符。
- 每个已开发的区块即为一个聚落（定居点）；人口居住与建筑占用建筑格都归属于所在聚落。

### 6.2 探索

- 文明早期可探索与扩散的范围小，只有玩家主动对已触及的区块下令投入探索，才能逐步扩展可开发区域。
- 探索采用轻量、持续的投入方式，占用一小部分人力并随时间推进。
- 被下令探索的区块，其已解锁建筑格数随时间自动、按随机概率逐步上涨，直至该区块的容量上限。
- 建筑格解锁与资源发现相互独立：即使某区块建筑格已全部解锁，其资源仍可能尚未探明。
- 探索过程会逐步揭示区块的资源；科技发展也能揭示已开发区块中此前未被认识的资源。
- 当某区块的探索度达到可配置阈值（不必探满）时，即可开始探索其相邻的周边区块，并可向多个方向扇形成片推进。
- 扩张只能沿已探明或已定居的边界连片推进，不允许远程跳区建立飞地；远程跨区能力留待后续交通与航海能力解锁。

### 6.3 定居与补给

- 被探索的新区块需先建立定居点：从已有聚落永久迁入一批人口并耗时完成后，才可继续在此区块建设其他建筑。
- 建立定居点与维持定居点人口生存，需要从既有区域运送粮食与建材等物资。
- 运输属于持续消耗并占用运输资源，运输供给能力构成文明扩张的现实约束。

### 6.4 资源与生产

- 每种资源在每个区块以「该区块可建该类资源设施的上限（**资源配额**）与**资源品味**」表示。
- 食物、采集、渔猎、木材、矿产等各类生产资源统一采用配额加品味的同一模型。
- 资源设施（含采矿、农牧渔猎等）占用一个建筑格并消耗一个对应资源格，其产出取决于资源品味与当前生产效率，并消耗人工。
- 生产、建造与探索均在一套随时间持续推进（类似维多利亚 3）的流程中进行，形成持续的产出与消耗。
- 人口按照由生存状况决定的出生率自动增长，人口是各生产设施所需人工的来源。

### 6.5 外来社群与异族政权

- 远方尚未接触的其他文明，其初次接触可由事件引入（迁徙、劫掠、交往等）；一旦接触或发生领土交接，其人口与政权即以地图实体形式存在并互动。
- 外来社群的大规模迁徙或由此引发的动乱，可能形成实际占据地图区块的政权；这类政权由系统治理，并可长期与玩家政权并存。

## 七、文明延续、政权更替与乱世

- 早期国家形成之前，社群的发展表现为部落兴衰、迁徙与重组；进入早期国家之后，玩家经营的对象是持续存在的文明，文明之下会反复出现并更替多个政权（朝代、国家），政权更替不等于本局结束。
- 文明、政权与政体必须分层对待：文明是能延续数千年并在政权更替中存续的底层；政权（朝代、国家）会生灭更替；政体是治理方案，可在相近技术条件下调整。
- 只有文明整体灭绝（核心人口、技术与组织基础消失）时，本局才结束并进行结算。
- 政权具有兴衰周期；政权更替由长期累积的压力（人口压力、土地集中、财政失衡、统治集团腐化、灾害与外患等）配合相应事件触发；玩家的治理手段决定压力累积速度、危机出现时机与政权更替形态。
- 政权更替伴随继承与重置：技术开发能力被文明继承；人口因战乱、饥荒与瘟疫下降后回升，属于马尔萨斯式承载力周期的一部分；土地与资源所有权被重新分配；一部分长期累积的负面效果（旧特权、旧债务、土地高度集中等）被清除。
- 乱世中文明会分裂为多个政权，各政权拥有各自可调整的政策与割据范围；分裂本身不损坏建筑，只有战争实际发生在其内的区块或持续的动乱（粮荒、灾害等）才会损坏相应区域的基础设施与建筑。
- 分裂出的多政权在再次统一之前可以长期并存；玩家只领导并经营所选定的一个政权，其余政权由系统治理，彼此关系可通过战争、外交与同化改变。
- 玩家可从分裂出的政权中选择一个继续经营，并在选定该政权时花费局内积累的系统币，直接替换或调整其部分政策；系统币在局内可相对大量积累，与更珍贵的局外点数是两种不同资源。
- 分裂各政权大多延续原文明的语言文化；若动乱源于大规模异族迁徙，可能形成异族建立的政权。
- 不同文化之间的好感度低，文化融合程度影响地区安定，低融合可能带来减益并导致建筑损坏。

## 八、原住民、异族与治理范围

### 8.1 世界中的其他人群

- 世界并非无人空地：超出玩家直接治理核心的区块被探索到时，普遍栖居着组织度较低的原住民部落或聚落。
- 原住民拥有自身部落级别的建筑，这些建筑占用所在区块内的建筑槽位。
- 玩家人口、原住民与异族统一以人口实体表达（类似维多利亚 3 人口体系的极度简化形态），同一区块的建筑槽位可分别被玩家建筑与原住民建筑占用。
- 人口实体以少量简单属性区分其归属、能力与文化状态，并驱动其行为与职位适合性。
- 臣服状态决定该人口能否进入玩家所属建筑工作并接受指派。
- 蛮族属性表示该人口体魄相对强壮而头脑相对简单；适合当士兵，不适合担任将领、商人或研究等职位。
- 开化状态表示该人口是否接受礼教等主流教化；开化程度影响其幸福度与对若干政策的满意度。
- 族属按地理可为与玩家同族的人口，也可为异族蛮族。
- 开化与族属彼此独立：存在"未臣服、未开化"的本族原住民，也存在开拓远方时更多遇到的"未臣服、未开化"的蛮族。
- 已臣服且已开化的蛮族仍保留其身体与文化特征，因此适合当士兵而不适合当将领、商人或从事研究。

### 8.2 纳入、开化与征服

- 文明可通过文明开化或征服把原住民与异族纳入自身治理：开化以持续的文化与治理投入渐进同化其人口，征服以军事手段接管其地域。
- 被纳入的人口进入玩家聚落体系成为劳动力；其部落建筑可被替换或升级为玩家体系的设施，也可选择保留。
- 征服或接管他人政权的区块后，需对当地人口重新完成臣服。
- 与玩家同族且已开化的人口重新臣服的速度快；异族或未开化人口的重新臣服存在相应减成。

### 8.3 直辖范围与名义控制（分封）

- 玩家能够直接有效治理的范围有限，受交通、信息与行政能力限制。
- 超出直接治理能力的区块，通过分封或殖民建立附庸领主而获得名义上的控制；附庸领主实际统治该地（包括处置当地原住民），并向中央进贡与效忠。
- 分封建立的附庸领主属于多政权体系的一员，由系统治理，可随距离、中央权威弱化与自身野心而离心甚至独立，也可被玩家重新收服。
- 直接治理范围随道路、通信与行政技术提高而扩大；中央集权只在相关能力足够时可行。
