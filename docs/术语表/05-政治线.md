# 术语表 · 政治线

**定位：** 政治线类名词的权威定义。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

**政治线是一条制度成长线。它有自己的经验值，按顺序解锁条目。**
**政治线与时代完全独立——不由时代转换触发，也不由时代门槛限制。这一族不按时代排列。**

| 术语 | 定义 |
| --- | --- |
| **政治线** | 一条制度成长线。**每条线各有自己的经验值，互不通用；玩家可以随意组合使用，互不排斥。** 科技线回答"你会做什么"，政治线回答"**你能怎么管**"。 |
| **政治线经验** | **每条政治线各有一个经验值，全局累积，不清零。** 来源：随时间涨；**发生叛乱或负面事件时涨得多**。用于解锁该线上的条目。 |
| **条目** | 政治线上可被解锁的一项。**解锁条件 = 本线经验达到阈值 + 附加依赖（可为空）。** 附加依赖可以是全局 flag、科技节点、另一条政治线的条目、或状态条件。**不得以时代为条件。** 已解锁的条目**一直可用，不得被替换**。 |
| **方式** | 条目的一类。**互斥选项，可切换，切换有一次性代价。** |
| **开关** | 条目的一类。解锁后才可调参数；**不解锁则该项行为被锁在一个默认值上**。 |
| **统治方式** | 玩家对**每一个区块单独设置**的管理方式。可随时切换，切换会让该区块的村落凝聚力**一次性下降**。**解锁是扩菜单，不是替换。** |
| **直辖** | 统治方式之一。区块由玩家直接管理。**起手的唯一形态。** |
| **委派** | 统治方式之一。派人去管该区块。**会随任期累积压低该区块的村落凝聚力。** |
| **任期制度** | 政治线条目之一，**开关型**。**解锁前，委派是永久的**——委派者的更换是自动的，但只有解锁后才能选任期长度。 |
| **分封** | 统治方式之一。 |
| **郡县** | 统治方式之一。 |
| **官位** | 一个区块上**需要几个人管**的岗位数。**本线的分母**，由该区块的人口规模换算，**不由玩家自由增加**。 |
| **候选人池** | 一个区块上，**在当前资格标准下够格的人数**。 |
| **资格标准** | 当前生效的"什么算够格"的判据。**全局一条，不是每区块一条**——标准是全局的，后果是分区块的。 |
| **家族占据度** | 一个区块上，**官位被同一个人丁最旺的家族占据的比例，0–100%**。随时间上涨；上涨速度由"生产该资格所需的资源"在该区块的集中度决定。 |
| **待选者** | 候选人池总数减去官位总数。**为正即为精英过剩**，会加速叛乱值上涨，同时加快本线经验。 |
| **改制** | 把官位逐个改为适用新资格标准的操作。**未改制的官位继续按旧标准运行。** |
| **收窄门槛** | 缩小候选人池的操作。被排除者按"离官位有多近"转化为叛乱压力。 |
| **门阀** | **家族占据度涨到 100% 时自动出现的被动形态。** 换人只能在世族内进行，且改革选项被锁死。**不是解锁条目。** |

> **两类进度的区别（重要）：** **科技节点**是**技能**——进度 0–100，会流失，跌破 50 失效。**政治线经验**是**制度**——只累积不清零。两者并存，对应两类不同的东西。
