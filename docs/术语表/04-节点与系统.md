# 术语表 · 节点与系统

**定位：** 节点、操作与设施类名词的权威定义。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

## 三类节点

| 术语 | 定义 |
| --- | --- |
| **科技节点** | 进度 0–100。**研发**从任务经验中涨；**流失**每期自动掉；损失人口时按各节点自己的**影响系数**额外**掉落**。**100 解锁，已解锁跌破 50 失效，失效后要重新爬满 100 才能再用。状态只有 0 / 1。** |
| **图鉴** | 材料 / 动物 / 植物。条目等级逐物种不同，**升级制**，**永久保留**。推进条件是在区块内**停留并实际使用**该资源。 |
| **社会节点** | 三类节点之一。era 01 引入（主动教学），era 04 起是**提高村落凝聚力的唯一手段**。 |

| 术语 | 定义 |
| --- | --- |
| **影响系数** | 每个科技节点自带的值，含义是"这项技能有多依赖特定的人"。系数高掉得多，系数低掉得少。 |
| **文明 flag** | 文明级状态，**不占科技节点位**。例：稳定火源。用于门控科技节点与图鉴阶段。 |

---

## 操作与设施

| 术语 | 定义 |
| --- | --- |
| **任务** | era 01 引入的**唯一操作面**：狩猎 / 采集 / 打制 / 探索。占用可投入劳动人口与期数，有损失概率。**狩猎走统一战斗结算。** |
| **建筑** | era 02 引入。era 01 一座都没有。无工人时只是不产出；**迁移时进入废除状态**。 |
| **道路** | era 04 引入。修在相邻区块之间，**降低该跳的临近度 cost**。 |
| **灾害** | 损失人口与储存，**同时提升抗性**——这是抗性的唯一来源。 |
