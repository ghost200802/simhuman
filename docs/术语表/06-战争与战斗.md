# 术语表 · 战争与战斗

**定位：** 战争与战斗类名词的权威定义。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

**战争系统从 era 01 起就在用——组织一次狩猎就是一次战斗。四种场景（狩猎 / 袭击 / 冲突 / 会战）共用同一套规则。这一族不按时代排列。占领一族同样不按时代排列。**

---

## 一、战斗

| 术语 | 定义 |
| --- | --- |
| **队** | **战斗的基本单位。** 由**人数、装备**两样定义。**同一种装备 + 一定人数。** 一个区块可以有多支队。**最小可以是 1 个人**（狩猎小队 3–5 人）。**一个队只能有一种装备**——混编必须拆成多个队。 |
| **职能** | 一个队在战斗中输出的方式：**近战 / 投射 / 远程支援**。**由装备决定，不由玩家指定。** |
| **作战编队** | **左翼 / 中翼 / 右翼三个位置的整体。** 玩家把**队**分配到三个位置。两军相向而立，**左打对方的右**（镜像）。 |
| **左翼 / 中翼 / 右翼** | 作战编队的三个位置。**中翼有【两个】相邻翼**（左右都够得着）；**侧翼只有【一个】相邻翼**（只能是中翼）。 |
| **前排 / 后排** | 阵型的两个层次。**远程支援装备出现之前只有单排**——所有队都在线上，**全部承受伤害**。远程支援装备出现后，只有远程支援职能的队能放后排，**不承受近战伤害**。 |
| **战线宽度** | 每场战斗一个值，**由地形决定**，单位是人数。**它的唯一作用不是限制参战人数，而是决定对方能不能包抄。** |
| **包抄** | 当对方展开人数**小于战线宽度**时，对方的两端是空的，我方余量可以绕过去攻击最外侧的翼，**该翼无法还击**。**正面取线性，包抄产生平方效应。** |
| **侧翼攻击效率** | **0–100%，每队一个。** 一支队**打崩当面、转入相邻翼时从 0 开始**，随时间爬到 100%。**爬升速度由移动力决定**——重甲要很久。 |
| **士气** | 每方一条，**0–100%**。**独立的线，不从属于兵力**——减员只是它众多来源之一（还有被包抄、侧翼被突破、疲劳等），且可在间歇期恢复。**上限由训练度决定。归零即溃退。** |
| **溃退** | 士气归零后进入的状态。溃退方**不还击**，单纯承受减员，直到脱离或被歼灭。 |
| **对射** | 战斗阶段之一。**投射职能输出**，减员小，士气缓慢消耗。 |
| **近战** | 战斗阶段之一。**近战职能输出**，**减员集中在这里**。 |
| **间歇** | 战斗阶段之一。接触不是持续的——间歇期**士气小幅恢复**，双方重整。 |
| **追击** | 战斗阶段之一，发生在对方溃退后。按**追击值**造成减员，**追击值普遍低于近战值**（骑兵例外）；**溃退方不还击**，**追击方自己的士气也会掉**（队形散）。 |

## 二、战争潜力

| 术语 | 定义 |
| --- | --- |
| **基础动员率** | 每个区块一条，0–100%。这是**没有编户时**的动员率。**由该区块的村落凝聚力决定**——凝聚力高，人们愿意跟你走，基础动员率就高。**村落凝聚力成为计量之前，基础动员率取一个固定的低值。** |
| **目标动员率** | 每个区块一条，0–100%。**当前编户档位所指向的值。** |
| **当前动员率** | 每个区块一条，0–100%。**随时间向目标动员率靠拢的那一个。升和降都有滞后。** |
| **可动员兵力** | 每个区块一个数。`当前动员率 × 可投入劳动人口`。**分母是可投入劳动人口，不是总人口**——所以征召会咬掉自己未来的兵源。 |
| **可装备兵力** | 全局一个数。`兵器库存 ÷ 每个士兵所需装备量`。**与可动员兵力共同构成两个上限。** |
| **兵器库存** | 全局按类型分组的存量。**四类：武器 / 盔甲 / 弓箭 / 战马。** 每类可以有材质，每件有**攻击、防御、移动力**三个数值。**铁器降低每套的资源消耗，不提升单兵战斗力。** |
| **训练度** | 每队一条，0–100%。**新征募的士兵为 0**，补充兵会**摊薄**整体。作用两处：**① 士气上限（主要）② 攻防里技巧那一部分**。 |
| **移动力** | 每队一个数值。`基础 + 战马加成 − 装备拖累`，其中`装备拖累 = max(0, 装备惩罚 − 战马免罚上限)`。**影响两件事：战略层行进速度、侧翼攻击效率的爬升速度。** |

## 三、占领

| 术语 | 定义 |
| --- | --- |
| **占领** | **战斗结算之后的动作。** 一次行动的目标是**一块或几块地区**，不是消灭对方。**不绑定时代。** |
| **消化** | 把一块刚占领的地区**养回能产出的状态**。手段就是既有的治理手段，本系统不新增。分三阶段：刚占领（产出接近零、维持成本照付）→ 消化中（产出按上交比例逐步恢复）→ 已消化（与自有地区无异）。 |
| **入不敷出** | 占领的天然刹车。**一次占得太多，要在同一段时间里同时消化多块地区**，而每块都在吃粮、占期数、耗兵力去驻守——**产出还没回来，成本已经压上来**。**上限是消化能力，不是军队规模。** |
