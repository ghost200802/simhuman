# 术语表 · 时代计量

**定位：** 各时代计量类名词的权威定义。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

## era 01 起

| 术语 | 定义 |
| --- | --- |
| **人口** | 分**成年 / 未成年**分别计数。只有成年执行任务；任务损失只扣成年人口。 |
| **可投入劳动人口** | 当下能派出去执行任务的那部分成年人口。 |
| **成年率** | 成年人口占总人口的比例。 |
| **成年存活率** | **era 01 的时代主线计量。** 决定科技节点的**流失**速度。 |
| **营养 / 体力 / 脑力** | 营养由食物产出转化；体力提高狩猎产出；脑力提高所有科技节点的研发。 |
| **教育值** | 知识在人口中铺开的程度。决定同样的人口损失会掉多少科技。 |
| **科技节点进度** | 见时代计量中「节点与系统」一族的定义。 |

## era 03 起

| 术语 | 定义 |
| --- | --- |
| **村落凝聚力** | **era 03 引入、era 04 扩展的时代主线计量。每个区块一条，各自结算。随时间增减。** 下降来源：本区块人口、分工深度、**临近度**；政治线带来的两项——**委派任期**（同一个人管得越久，每单位时间掉得越多）与**家族占据度**（可换的人越少，掉得越快）；战争带来的**动员**。**一次性下降**：切换统治方式。上升来源：**社会节点**、提高临近度、以及政治线与科技线上提高基础上升速度的那些项。**它同时决定该区块的上交比例**——这是它在本系统里除叛乱值之外的第二处作用。 |
| **可耕地上限** | 区块属性，固定值，**科技不改变它**。占满后人口继续涨即产生缺口。 |
| **单位面积产量 / 选育进度 / 抗性** | 产出的三个派生量，逐项独立。 |
| **储粮容量 / 地力** | 区块与设施的属性。 |

## era 04 起

| 术语 | 定义 |
| --- | --- |
| **叛乱值** | **0–100，每个区块一条。** 该区块的村落凝聚力**跌破 0** 后开始上涨，速度由凝聚力决定。上涨期间该区块**全部产出按叛乱值等比打折**。玩家把凝聚力拉回 0 以上则它**自然下降**。**涨到 100 → 该区块直接独立。** |
| **网络总人口** | 玩家所有区块的人口之和。 |
| **主区块饥荒** | 主区块的村落凝聚力跌破 0 时的表现——人口损失与产出下降。**主区块不会独立。** |
