# 术语表 · 时代机制

**定位：** 时代机制类名词的权威定义。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

| 术语 | 定义 |
| --- | --- |
| **叠加原则** | **时代推进是叠加，不是替换。** 本时代 = 已有机制的全集 + 一条新增机制。旧机制一直可用，上限不变。 |
| **时代是机制层** | **时代不是时间段。** 每个时代是一次「新增一条机制」；机制一旦引入就**永久保留**，不因为进入下一个时代而消失。因此时代之间**不按年代切割**，不同文明可以停在不同时代——时代是**能力判定**，不是日历。 |
| **多成长线时代** | 一个时代可以拥有**不止一条**新增成长线。**era 05 是第一个，有六条。** 该时代的各条线**通往同一个目标、抢同一批资源、互相拆台**——所以玩家必须选先推哪一条。 |
| **贯穿始终的成长线** | 一条线可以**同时**属于某个时代、又是所有时代都要回答的问题。**「贯穿始终」不等于「不属于这个时代」——它两样都是。** era 05 的强化统治、征兵、军事装备三条都是这种。 |
| **不绑时代的线** | **政治线**不必属于某个时代——它按自己的经验与依赖推进，可以一直往深处走。**它们和时代的成长线并列存在。** |
| **失传** | 倒退的形式。**时代标签从不回退**；崩溃表现为人口崩塌、储存丢失、部分技能与匠人失传。玩家仍在同一时代。 |
| **裂变** | era 04 新增。派出一部分人口与物资到**相邻区块**建立新聚落。**母聚落不废弃**——这是与 era 02 整体搬迁的分界。 |
| **独立** | era 04 新增。区块的**叛乱值涨到 100** 后**脱离控制**。时代标签不退、图鉴不丢、科技节点不掉，丢的是那块地与上面的产能。**征讨与收服不在 era 04**；政治线的统治方式与干预手段，以及战争系统，都可以用来把它拿回来。**era 04 里它是中立聚落；era 05 起，脱离控制的区块可以成为邻国。** |
| **邻国** | era 05 新增。**网络之外、由别人控制的政体。** 它的国力**是算出来的，不是经营出来的**：按它占的地盘乘一个预置系数，直接得出兵力与粮草，并随时间成长。**来源有两个**——网络之外本来就存在的其他社群，以及**你自己脱离控制的区块**。 |
| **战力标尺** | 每个邻国一个数。用于比较双方强弱，**也是玩家改革的靶子**。它**一直在涨**——玩家面对的是一个不断往前跑的目标，不是静态的强弱对比。 |
| **支配比例** | 全局一条。**玩家自己支配的区块 ÷ 地图总大小。** 它有一条**配置的线**——过线之后「帝业」才开始累积。 |
| **帝业** | 全局一条，0–100。**进入 era 06 的计量。** 支配比例**在线上**时按**固定速率**上涨；**掉回线下则持续减少**。走满后「称帝」点亮，玩家手动确认进入 era 06。**它只能靠守住疆域累积，不看治理水平。** |
| **时代主线计量** | 每个时代用于承载核心张力的那个计量：era 01 成年存活率、era 03 起村落凝聚力。**只涨不跌的进度条不构成主线计量。** |
