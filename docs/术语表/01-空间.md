# 术语表 · 空间

**定位：** 空间类名词的权威定义。
**边界：** 只写定义与归属。不含数值、不含机制细节、不含设计依据。

---

| 术语 | 定义 | 引入 |
| --- | --- | --- |
| **区块** | 全局唯一的核心空间单位。采用固定 **50 km × 50 km 的方形地块**，有效面积约 2,500 km²，作为人口、生产、库存、市场、政治和军事的统一模拟省份。区块内部不再表达一日往返范围；本地移动、道路、地形与运输差异通过区块属性和图连接边的成本体现。区块的逻辑身份由稳定 ID 表示，连接关系由图结构保存；方形边界只属于当前地图表现层。内部无坐标、无地形网格、无移动。**区块是整局游戏唯一不会变动的空间概念。** | era 01 |
| **地图总大小** | 一局的地图规模。**区块数量由它决定**，具体数量走配置。 | era 01 |
| **主区块** | 玩家最初定居、并始终作为网络中心的那个区块。**临近度从这里起算。** | era 04 |
| **非主区块** | 属于玩家、但不是主区块的区块。**只有非主区块会独立。** | era 04 |
| **相邻区块** | 图结构中存在可通行边的区块。原型方格地图默认共享边的四邻接；河流、山口、道路、海峡与航线可以增加或修改连接，是否共享方形边界不决定逻辑上是否可达。新聚落只能建在满足规则的相邻区块上。 | era 02 |
| **区块图** | 由区块节点与连接边组成的地图数据结构。节点保存区块自身状态，边保存方向、通行类型、基础成本、容量、季节性和可见性；模拟核心只读取区块图，不读取渲染图片的像素或坐标。 | 架构层 |
| **地图几何层** | 区块的可视化边界与地图贴图。原型使用方形网格；后续可以把同一批稳定区块 ID 映射为不规则省份、多边形或栅格颜色区域，而不改变模拟状态与区块图。 | 架构层 |
| **临近度** | **一个区块到主区块的通达程度，0–100。主区块恒为 100。** 沿**最省路径**（不是最短路径）传播，每跳扣掉该跳的 cost。**cost 由基础距离、地形、道路、科技共同决定**——所以临近度不等于距离。它是可被玩家投资改善的量。 | era 04 |
| **基础距离** | 两个相邻区块之间的一跳。是临近度 cost 的**基准项**，本身不随游戏推进变化。 | era 04 |
| **建筑格** | **区块内可被建筑占用的等价格位。** 完全等价、没有空间位置与地形差异，仅作为可占用进行生产的抽象格。**它只是区块上的两个计数：容量与已解锁数**——不需要记录"占的是哪一格"。**不是实体。** | 架构层 |
| **聚落** | 一个**已开发的区块**。人口居住与建筑占用都归属于所在聚落。**不是实体**，由该区块上的建筑与人口表达。 | 架构层 |
| **区块探索度** | 区块级计量。随停留与实际使用上升，随时间缓慢回落，**不因迁移重置**。 | era 01 |
