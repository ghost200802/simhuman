# 术语表 · 总则

**定位：** 全项目关键名词的权威定义。任何文档里的名词，含义以本表为准。
**边界：** 只写定义与归属。**不含数值、不含机制细节、不含设计依据。**

**本表按概念族分成多份，各自独立可读。**

---

## 一、命名规则

1. **同一概念全文只有一个名字。** 不得出现同义词并存。
2. **不得使用 P / s / L 这类代码符号**，一律用中文表述（进度、研发、流失）。
3. **本表是唯一权威源。** 某份文档需要一个本表没有的名词时，**先加到本表**，再在文档里使用。
4. **按概念族分组**，组内按**引入时代**排列；不按文档归属分组。**政治线一族与战争一族不按时代排列**——政治线与时代独立，战争系统从 era 01 起就在用。
