## 二、新增关系的方向旁证

**Levi 1988（*Of Rule and Revenue*）的 quasi-voluntary compliance：** 遵从"is voluntary because actors choose to pay"，但"**quasi-voluntary because the noncompliant are subject to coercion**"。

**成本侧的核心结论：共识越广，交易成本越轻**——执行规则、获取信息、控制纳税人及其税基、管理征收、谈判税负分配，**每一项都随共识下降**。统治者特别偏好低执行与低行政开销的制度。

> **落点：这给了"凝聚力高 → 你拿得到更多"一个方向——它把上交比例挂到凝聚力上，而不是挂到暴力上。但 Levi 给的是"共识降低征收成本"这个方向，不是"共识与抽取比例成正比"这个函数。**

**另一处更贴近本系统的是"抽取率"这一整块研究**（国家能拿走产出中的多大比例、以及它受什么限制）。**本系统没有针对它做调研**——见第四节。

---

## 三、为什么把产出与上缴分开

**这不是文献结论，是本设计的结构选择。** 理由是它让两条本来分开的线在经济上会合：

- **天赋**（资源配额与品味，开局随机、科技不改）→ 决定产出
- **治理**（凝聚力，政治线上每一个决定都在影响它）→ 决定上缴

**如果合成一个数**，"这块地很富但我拿不到"这个状态就表达不出来——而它正是本系统要承载的体验。

> ⚠️ **文献侧的对应关系不能说满。** 「治理水平影响国家实际抽取到的比例」这个方向在财政史与国家形成研究里到处都是，但**本次没有为它做专门调研**，不能引用具体研究或数字。

## 四、查不到、有争议、未定的部分

**① 上交比例与凝聚力的映射曲线——纯设计，没有依据。** 甚至没有"这个比例大致在什么量级"的可引数字。

**② 「国家实际抽取率」的系统研究——本次未调研。** 这一块（税基、征收成本、实际入库率）在财政史里有相当多的研究，**本系统一条都没有引**。要细化本系统之前必须先补。

**③ 资源配额与品味的分布——纯设计。** 「开局随机生成、科技不改变」是设计选择，不是文献结论。

**④ 生产建筑的清单与消耗——未定。** 本系统只规定"受资源配额限制"这个约束，具体内容留到阶段详案。

**⑤ 实物上缴与市场交换的分界——未定。** 本系统只管前者。

## 五、设计取值标注

以下内容**是设计决定，不是文献结论**：

| 项 | 说明 |
| --- | --- |
| **上交比例 = 函数(村落凝聚力)** | **纯设计。** 方向有旁证（Levi），关系与曲线没有 |
| **产出与上缴必须是两个可分别读到的数** | **纯设计。** |
| **科技只改单位建筑产量，不改资源配额** | **纯设计。** |
| **建筑数量严格受资源配额限制** | 沿用已定稿的资源系统 |
| **叛乱值在最终收益上再打一次折** | 沿用 era 04 |
| **三根杠杆（凝聚力 / 建筑 / 科技）是"强化统治"的全部落点** | **纯设计。** 现实中强化统治的手段远不止这三样 |
| **本系统不绑定时代** | **纯设计。** |
| **各条映射的阈值与系数** | **未定**，走配置表 |

参数值一律走配置表，不写进本文档。
