# SimHuman 时代主线与转换条件

**定位：** 记录每个时代的六个问题，以及进入下一个时代所需的条件。
**边界：** 只写设计结论。**每个时代只回答六句话，不出现别的内容。** 更详细的在各自的阶段文档中。
**进度：** era 01–05 已定稿并带转换条件表；**era 06 及以后只保留标题**，后续再细化。

## 〇、时代是机制层，不是时间段

**每个时代是一次「新增一条机制」。机制一旦引入就永久保留，不因为进入下一个时代而消失。**

```
本时代 = 已有机制的全集 + 一条新增机制   （叠加原则）
```

由此推出三条：

1. **时代之间不按年代切割。** 一个后期文明同时握着统一分裂、大航海、工业动力——它们不互相取代。
2. **不同文明可以停在不同时代。** 时代是**能力判定**，不是日历。
3. **时代的先后由依赖关系决定，不由历史年份决定。** 「更晚被引入」意味着它建立在前面的机制之上。

**一个时代可以有多条成长线。** era 05 是第一个这样的时代——它有一个**主目标**、**三个大方向**，方向下面还有许多**小点**；它们**通往同一个目标、抢同一批资源、互相拆台**，所以玩家必须选先推哪一条。

**「贯穿始终」不等于「不属于这个时代」。** 一个时代的一条成长线可以同时是所有时代都要回答的问题——比如"这块地产多少、给我多少""我能点出多少人""这些人拿什么打仗"。**它两样都是。**

**一条线不必只属于一个时代。** 政治线按自己的经验与依赖推进，可以一直往深处走——它们和时代的成长线并列存在，**不绑在任何时代上**。

## 二、era 01 · 人类形成期

**1. 第一次出现什么** —— 可以留存的技术：技术第一次以进度存在——能积累，也会流失；流失多快由成年存活率决定。

**2. 独有体验** —— 人类能够通过积累提高生产效率：你花出去的时间不会消失，它会变成能力。

**3. 核心张力** —— 危险的任务产出高，但成年存活率会掉；安全的任务产量低，但成年存活率稳。

**4. 核心循环与乐趣** —— 派任务换产出与经验，产出养人口、经验养科技，但每次任务都在啃成年人口；乐趣在"第一次把节点推过 100""图鉴点亮""预估区间收窄"三处。

**5. 不该有的** —— 建筑、资源设施、储存、多区块控制；陷阱/网/投射装置/磨制工具；火作为稳定基础设施；定居农业、选育、抗性。

**6. 比上一条陡在哪** —— 从"个体体能能直接拿到的食物"提高到"工具能从同一片土地上多取出的那一类组织"（从肉到骨髓与脑），是提取**种类**的扩大，不是倍数。

### 进入 era 02 的条件

| 组 | 条件 |
| --- | --- |
| 知识 | **火已能连续维持**，不依赖偶然留火（→ 文明 flag） |
| 状态 | 已形成**固定的跨季节路线**——能走到别处并回来 |
| 状态 | 经验能**跨代不丢** |
| 状态 | 群体已达到**能整体迁移的规模**，走一趟不会散 |

## 三、era 02 · 旧石器时代

**1. 第一次出现什么** —— 食谱宽度：你能吃到多少种东西，第一次由**你走到过哪里**决定。

**2. 独有体验** —— 每要一样新东西，先扔掉一次窝。

**3. 核心张力** —— 搬到新地方才能遇到新物种、才知道别处有没有更好的区块；留下来能守住深耕好的产出，但食谱和眼光都停在这里。

**4. 核心循环与乐趣** —— 探索换来新区块与新物种，搬迁作废旧区块、在新区块重新积累；乐趣在图鉴点亮、候选区块清单变长、菜单上多出来的那一行。

**5. 不该有的** —— 定居农业、选育、抗性；系统性大规模储存；同时控制多个区块；常设分工与专业角色；货币、成文法律、税收、常备军、跨区域行政；化学农药。

**6. 比上一条陡在哪** —— 从"一个区块"提高到"你能到达的最好的那个区块"，换到繁殖快的资源后同一区块的可持续提取量再提高约 **7–10 倍**；天花板仍是野生资源。

### 进入 era 03 的条件

| 组 | 条件 |
| --- | --- |
| 知识 | 已认识至少一种可栽培植物，且图鉴升到能判断其生长节律 |
| 状态 | 已在同一地点**持续不搬迁**达到规定季节数 |
| 状态 | 人口达到规定规模 |
| 设施 | 具备简陋的保存设施 |
| 科技 | 具备磨制工具 |

全部满足后由玩家手动确认进入。

## 四、era 03 · 新石器时代与农业转型

**1. 第一次出现什么** —— 剩余：产出第一次可能超过当下所需，人第一次不必再跟着资源走。

**2. 独有体验** —— 第一次有东西可以失去，也第一次被土地锁住。

**3. 核心张力** —— 人口既是唯一的燃料，也是唯一的压力源；而**本时代新增的这条线没有出口**——旧退路还在，但代价随积累上升，压力只能在原地累积。

**4. 核心循环与乐趣** —— 定居 → 产出上升 → 人口增长 → 压力同步累积 → 仍在同一块地上；乐趣在选育的自动复利、灾害与抗性的对抗、以及稳定生活本身，压力全程逼近。

**5. 不该有的** —— 走出本区块建立新聚落、货币、成文法律、常备军、税收体系、跨区域行政、化学农药。

**6. 比上一条陡在哪** —— 上限从"一个采集群体能覆盖的野生资源量"变成"一块地的农业承载力"。

### 进入 era 04 的条件

| 组 | 条件 |
| --- | --- |
| 状态 | 聚落的**农业产出稳定**，可长期供养人口而不依赖野生资源兜底 |
| 状态 | **聚落人口达到社会压力阈值** |
| 科技 | 已掌握**可携带的种子与农具**，能在新区块重建生产 |

全部满足后由玩家手动确认进入。

## 五、era 04 · 聚落裂变与扩张

**1. 第一次出现什么** —— 增殖的聚落：聚落第一次能长出新的聚落，并连成网络。

**2. 独有体验** —— **走，第一次不是失去。** era 02 走是扔掉一次窝，era 03 走不起，era 04 走是多一个会还回来的生产单元。

**3. 核心张力** —— 分裂能卸掉主区块的压力，但分得越远，新聚落的**临近度**越低、**村落凝聚力**也就越低；不分裂，可耕地用光后人口一涨就闹饥荒。

**4. 核心循环与乐趣** —— 人口涨 → 可耕地用光 → 分裂派人口建立新聚落 → 主区块压力回落、地图上多一块地；同时新聚落的**临近度**低，**村落凝聚力**也就低，跌破 0 该区块的**叛乱值**就开始涨，涨到 100 就独立。乐趣在看网络长出来、每次裂变**派多少人走**、**挑哪个相邻区块**、**修路把临近度拉回来**，以及**把快独立的区块拉回来**。

**5. 不该有的** —— **命令另一个聚落**（本时代每个区块各自决定）；货币、成文法律、常备军、税收体系、跨区域行政、化学农药。

**6. 比上一条陡在哪** —— 上限从"一个聚落的承载量"变成"**整片区块网络的承载量**"。

### 进入 era 05 的条件

| 组 | 条件 |
| --- | --- |
| 科技 | 已掌握**畜力牵引**（牛拉犁） |
| 状态 | 网络总人口达到**正式政治精英必然出现的规模** |
| 状态 | **主区块已经无法直辖全部网络**——至少有一个区块，它的村落凝聚力仅靠社会节点已经拉不回来 |

全部满足后由玩家手动确认进入。

## 六、era 05 · 农耕文明时代

**1. 第一次出现什么** —— **代理：你的意志第一次要靠别人的手落地。** 在此之前权力和邻近度是同一件事；本时代第一次，你交给别人的事，他不在你眼前也做得成——**国力第一次能脱离你的双手增长**。

**2. 独有体验** —— **你第一次不在场。** 而你要处理的每一件事，都是这个「不在场」造出来的。

**3. 核心张力** —— **你要靠派出去的人把摊子撑大，而派出去的人迟早不再听你的；你回头压他们，压他们用的正是撑摊子的那份力气。**

**4. 核心循环与乐趣** —— 邻国标尺在涨 → 打不过，必须提升国力 → 占地、派人去管 → 放出去的手变长 → 代理人坐大，你的一部分变成新的邻国 → 回到最外层；另一条更慢：维持成本超过余力，只能救火 → 沿政治线往前推 → 政策替你承担一部分维持 → 你腾出手、看向外面。**正反馈**在"制度解锁 → 维持成本降 → 余力变多"；**刹车**在"政治线经验靠麻烦推，和平期推不动"与"维持一松手，那些读数就一路往下掉"。乐趣在国力第一次能被你自己推动、在三个方向里挑先推哪个、在看着自己放出去的诸侯变成对手，以及**操作量在减少，而这是奖励不是惩罚**。

**5. 不该有的** —— 地图之外（世界有边，边外无物）；公民权与民族认同；机械动力；化学农药。

**6. 比上一条陡在哪** —— 上一时代是**裂变**，上限从"一个聚落的承载量"提到"整片区块网络的承载量"；本时代是**代理**，上限从"你能管多少"提到"你派出去的人能替你管多久"；下一时代是**大航海：地图之外第一次有地图**，待定。
