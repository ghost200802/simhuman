# SimHuman 时代主线与转换条件

**定位：** 记录每个时代的六个问题，以及进入下一个时代所需的条件。
**边界：** 只写设计结论。**每个时代只回答六句话，不出现别的内容。** 更详细的在各自的阶段文档中。
**进度：** era 01–05 已定稿并带转换条件表；**era 06 基调已定、六问与条件待细化（暂定）**；**era 07 及以后只保留标题**，后续再细化。

---

## 〇、时代是机制层，不是时间段

**每个时代是一次「新增一条机制」。机制一旦引入就永久保留，不因为进入下一个时代而消失。**

```
本时代 = 已有机制的全集 + 一条新增机制   （叠加原则）
```

由此推出三条：

1. **时代之间不按年代切割。** 一个后期文明同时握着统一分裂、远洋探索、工业动力——它们不互相取代。
2. **不同文明可以停在不同时代。** 时代是**能力判定**，不是日历。
3. **时代的先后由依赖关系决定，不由历史年份决定。** 「更晚被引入」意味着它建立在前面的机制之上。

**一个时代可以有多条成长线。** era 05 是第一个这样的时代，有六条——它们**通往同一个目标、抢同一批资源、互相拆台**，所以玩家必须选先推哪一条。

**「贯穿始终」不等于「不属于这个时代」。** 一个时代的一条成长线可以同时是所有时代都要回答的问题——比如"这块地产多少、给我多少""我能点出多少人""这些人拿什么打仗"。**它两样都是。**

**一条线不必只属于一个时代。** 政治线按自己的经验与依赖推进，可以一直往深处走——它们和时代的成长线并列存在，**不绑在任何时代上**。

## 二、era 01 · 人类形成期

**1. 第一次出现什么** —— 可以留存的技术：技术第一次以进度存在——能积累，也会流失；流失多快由成年存活率决定。

**2. 独有体验** —— 人类能够通过积累提高生产效率：你花出去的时间不会消失，它会变成能力。

**3. 核心张力** —— 危险的任务产出高，但成年存活率会掉；安全的任务产量低，但成年存活率稳。

**4. 核心循环与乐趣** —— 派任务换产出与经验，产出养人口、经验养科技，但每次任务都在啃成年人口；乐趣在"第一次把节点推过 100""图鉴点亮""预估区间收窄"三处。

**5. 不该有的** —— 建筑、资源设施、储存、多区块控制；陷阱/网/投射装置/磨制工具；火作为稳定基础设施；定居农业、选育、抗性。

**6. 比上一条陡在哪** —— 从"个体体能能直接拿到的食物"提高到"工具能从同一片土地上多取出的那一类组织"（从肉到骨髓与脑），是提取**种类**的扩大，不是倍数。

### 进入 era 02 的条件

| 组 | 条件 |
| --- | --- |
| 知识 | **火已能连续维持**，不依赖偶然留火（→ 文明 flag） |
| 状态 | 已形成**固定的跨季节路线**——能走到别处并回来 |
| 状态 | 经验能**跨代不丢** |
| 状态 | 群体已达到**能整体迁移的规模**，走一趟不会散 |

全部满足后由玩家手动确认进入。

## 三、era 02 · 旧石器时代

**1. 第一次出现什么** —— 食谱宽度：你能吃到多少种东西，第一次由**你走到过哪里**决定。

**2. 独有体验** —— 每要一样新东西，先扔掉一次窝。

**3. 核心张力** —— 搬到新地方才能遇到新物种、才知道别处有没有更好的区块；留下来能守住深耕好的产出，但食谱和眼光都停在这里。

**4. 核心循环与乐趣** —— 探索换来新区块与新物种，搬迁作废旧区块、在新区块重新积累；乐趣在图鉴点亮、候选区块清单变长、菜单上多出来的那一行。

**5. 不该有的** —— 定居农业、选育、抗性；系统性大规模储存；同时控制多个区块；常设分工与专业角色；货币、成文法律、税收、常备军、跨区域行政；化学农药。

**6. 比上一条陡在哪** —— 从"一个区块"提高到"你能到达的最好的那个区块"，换到繁殖快的资源后同一区块的可持续提取量再提高约 **7–10 倍**；天花板仍是野生资源。

### 进入 era 03 的条件

| 组 | 条件 |
| --- | --- |
| 知识 | 已认识至少一种可栽培植物，且图鉴升到能判断其生长节律 |
| 状态 | 已在同一地点**持续不搬迁**达到规定季节数 |
| 状态 | 人口达到规定规模 |
| 设施 | 具备简陋的保存设施 |
| 科技 | 具备磨制工具 |

全部满足后由玩家手动确认进入。

## 四、era 03 · 新石器时代与农业转型

**1. 第一次出现什么** —— 剩余：产出第一次可能超过当下所需，人第一次不必再跟着资源走。

**2. 独有体验** —— 第一次有东西可以失去，也第一次被土地锁住。

**3. 核心张力** —— 人口既是唯一的燃料，也是唯一的压力源；而**本时代新增的这条线没有出口**——旧退路还在，但代价随积累上升，压力只能在原地累积。

**4. 核心循环与乐趣** —— 定居 → 产出上升 → 人口增长 → 压力同步累积 → 仍在同一块地上；乐趣在选育的自动复利、灾害与抗性的对抗、以及稳定生活本身，压力全程逼近。

**5. 不该有的** —— 走出本区块建立新聚落、货币、成文法律、常备军、税收体系、跨区域行政、化学农药。

**6. 比上一条陡在哪** —— 上限从"一个采集群体能覆盖的野生资源量"变成"一块地的农业承载力"。

### 进入 era 04 的条件

| 组 | 条件 |
| --- | --- |
| 状态 | 聚落的**农业产出稳定**，可长期供养人口而不依赖野生资源兜底 |
| 状态 | **聚落人口达到社会压力阈值** |
| 科技 | 已掌握**可携带的种子与农具**，能在新区块重建生产 |

全部满足后由玩家手动确认进入。

## 五、era 04 · 聚落裂变与扩张

**1. 第一次出现什么** —— 增殖的聚落：聚落第一次能长出新的聚落，并连成网络。

**2. 独有体验** —— **走，第一次不是失去。** era 02 走是扔掉一次窝，era 03 走不起，era 04 走是多一个会还回来的生产单元。

**3. 核心张力** —— 分裂能卸掉主区块的压力，但分得越远，新聚落的**临近度**越低、**村落凝聚力**也就越低；不分裂，可耕地用光后人口一涨就闹饥荒。

**4. 核心循环与乐趣** —— 人口涨 → 可耕地用光 → 分裂派人口建立新聚落 → 主区块压力回落、地图上多一块地；同时新聚落的**临近度**低，**村落凝聚力**也就低，跌破 0 该区块的**叛乱值**就开始涨，涨到 100 就独立。乐趣在看网络长出来、每次裂变**派多少人走**、**挑哪个相邻区块**、**修路把临近度拉回来**，以及**把快独立的区块拉回来**。

**5. 不该有的** —— **命令另一个聚落**（本时代每个区块各自决定）；货币、成文法律、常备军、税收体系、跨区域行政、化学农药。

**6. 比上一条陡在哪** —— 上限从"一个聚落的承载量"变成"**整片区块网络的承载量**"。

### 进入 era 05 的条件

| 组 | 条件 |
| --- | --- |
| 科技 | 已掌握**畜力牵引**（牛拉犁） |
| 状态 | 网络总人口达到**正式政治精英必然出现的规模** |
| 状态 | **主区块已经无法直辖全部网络**——至少有一个区块，它的村落凝聚力仅靠社会节点已经拉不回来 |

全部满足后由玩家手动确认进入。

## 六、era 05 · 青铜与铁器时代

> **这是第一个「多条成长线」的时代。** 六条线通往同一个目标，抢同一批资源，互相拆台。
>
> **其中三条（强化统治、征兵、军事装备）同时是贯穿始终的**——每个时代都要回答"这块地产多少、给我多少""我能点出多少人""这些人拿什么打仗"。

**1. 第一次出现什么** —— **内涵增长，而且路不止一条**：变强第一次不只靠多占地方，也能靠**改造自己**。同样一片地，因为制度和动员方式不同，能产出的力量可以差出一个数量级。**改造自己的路有六条**——拓展统治的地方、强化对已占领地的统治力、加强军事征兵能力、军事装备（自己研发自己打造）、政治改革、促进市场发展。

**2. 独有体验** —— **你发现邻国比你强，而你可以通过改革追上它。** 在此之前国力只能等它自己长；本时代第一次，国力是一个**你能主动改造的数字**——而且**你得选从哪改起**。

**3. 核心张力** —— 两层。

**第一层，六条路抢同一批粮食、同一批人、同一个期数，而且互相拆台。** 放权去拓展，已占地的统治力就掉；征召去打仗，种粮的人就没了；造装备又要种粮的那批人去挖矿；搞政治改革，既得利益者就反。**真正的决策不是"要不要发展"，是"先发展哪一条、放弃哪一条"。**

**第二层，其中两条之间那条解不掉的：动员要求集权，扩张产生分权。** 你要打赢邻居就得把人登记在册、把权力收上来；但你越成功、地盘越大，越只能放权去管——而你放出去的人正在变成新的邻居。**你为打赢而集中起来的力量，会因为打赢而散掉。**

**4. 核心循环与乐趣** —— 三层同时转：

```
最外层：邻国的攻击与战力标尺 → 打不过，必须改革 —— 但改革不止一条路
六条线分配同一批粮食、人口、期数 → 每条都有下限，哪条掉太低先把你拖垮
主循环：打得赢 → 占地 → 地盘变大 → 只能放权去管
        → 代理人坐大 → 诸侯化 → 你的一部分变成新的邻国 → 回到最外层
终点：支配比例过线 → 帝业开始累积 → 守住 → 走满 → 称帝
```

乐趣在「**国力这个数字第一次能被你自己推动**」、在**六条路里挑哪一条**、在看着自己放出去的诸侯变成对手、在追赶一个不断往前跑的邻国标尺、以及在**帝业条开始动之后守住它不掉回去**。

**5. 不该有的** —— **一个能长期维持的帝国**（本时代可以创建，但维持不住）；**成文法典**；**火药与火器**；**印刷**；**机械动力**。

**6. 比上一条陡在哪** —— era 04 的上限是"整片网络的承载量"——那是**外延增长**，靠多占。本时代第一次出现**内涵增长**：同样一片地，编户覆盖率与动员方式不同，能点出的人和造出的兵器差出数量级。**上限从"你有多少地"换成"你能把地和人都变成多少力量"。**

### 进入 era 06 的条件

| 组 | 条件 |
| --- | --- |
| 状态 | **「帝业」累计走满**——玩家**支配比例**（自己支配的区块 ÷ 地图总大小）达到规定值后开始累积；保持在比例线以上则按**固定速率**上涨，**掉回线下则持续减少** |

全部满足后由玩家手动确认进入——**玩家称帝，创建帝国**。

> **这是一条两段的门槛：先打够，再守住。** 你不能刚够线就称帝——**你必须在线上待够**。而刚占领的地区凝聚力极低、随时可能叛乱独立，所以**刚够线的那一段是最危险的窗口**。

### 倒退

倒退表现为人口崩塌、区块独立、部分技能与匠人失传。

- **损失**：人口、储存、脱离控制的区块及其上的产能、部分科技节点与传承它们的匠人、已编户区块的登记。
- **保留**：时代标签、图鉴、区块探索度、**选育与抗性**、**政治线经验（不清零）**、以及仍然握着的区块。
- **恢复到**：仍在本时代，可以从留着的区块重新铺出去。**制度还在，所以恢复比第一次快。**

## 七、era 06 · 帝国循环

### 基调（暂定）

> ⚠️ **这一段是方向，不是结论——它还没有过文献调研。**

**主旋律：内部维稳 + 对外扩张。**

- **第一个帝国不会自动稳住——秦二世而亡。** **对内维稳是有方法的**：独尊儒术、君权神授，一步步把政权稳住。
- **但稳下来之后，内部又长出新的病**：土地兼并、豪族坐大。**让它稳定的那些手段，正是下一次崩溃的原因**——王朝周期律。
- **对外**：周边有草原等**边缘地区**。把它们占下来转成农耕**得不偿失**；但**不占领，过一段时间那里会刷出游牧势力来劫掠**——**国家虚弱时甚至会被灭亡**。

**玩家在本时代主要在各种情况下斗智斗勇。**

---

**1. 第一次出现什么** —— **可重建的秩序**：秩序第一次成为可以被摧毁、**又可以被重建**的东西，而且重建得比上一次快。

**2. 独有体验** —— **第一次，崩溃不是终局。** era 01–05 的崩溃意味着失传与回退；本时代第一次，你会亲眼看着自己建起来的东西碎掉，然后**第二次建起来**。

**3. 核心张力** —— **你为了不再分裂而集中权力，而集中权力正是下一次分裂的原因。** 集权让帝国能维持，也让它在崩的时候崩得更彻底；分权让它活得久，也让它散得快。

**4. 核心循环与乐趣** ——

```
统一 → 集权（郡县 / 编户 / 常备军 / 官僚）→ 财政与治理成本随规模上升
     → 边患与内乱 → 分权或崩溃 → 分裂 → 竞争重新产生强者 → 统一
```

乐趣在「**重建得比上次更快、更大、更久**」——同一件事做第二次，而这次你知道哪里会断。

**5. 不该有的** —— **火药与火器**；**印刷**；**远洋航行**；**机械动力**。

**6. 比上一条陡在哪** —— era 05 的上限是"同样一片地能产出多少力量"——那是**产出的量**。本时代第一次把**时间**变成上限：这套东西**能维持多久、能重建几次**。从"能产出多少"换成"能持续多久"。

### 进入 era 07 的条件

待定。

### 倒退

倒退表现为帝国崩解为多个政体、人口崩塌、部分技能与匠人失传。

- **损失**：统一本身、人口、储存、部分科技节点与传承它们的匠人。
- **保留**：时代标签、图鉴、区块探索度、**选育与抗性**、**政治线经验（不清零）**。
- **恢复到**：**仍在本时代**——重建比第一次建立快得多，因为制度还在。**这就是本时代的循环，不是时代的回退。**
