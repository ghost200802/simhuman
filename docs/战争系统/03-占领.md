# 战争系统 · 占领

**定位：** 定义**一块地区在战斗之后如何易手、以及拿到之后玩家要面对什么**。
**边界：** 不含数值取值、不含界面方案。文献依据另存。

**一句话：** 打下来是一瞬间的事，拿住是很多期的事。

---

## 1. 这个系统管什么

**地区的易手与消化。**

战斗结算回答"这一仗谁赢"；本系统回答**"赢了之后那块地归谁、以及归了之后你养不养得起"**。

**它不管**战斗怎么打（战斗结算管），也不管人和装备从哪来（战争潜力管）。

**它不绑定时代。** 从第一次有人抢占别人的地块起就在用。

---

## 2. 玩家的目标不是灭国，是占地

**打一个邻国，不是把它从地图上抹掉，而是占领它的地区。**

一次行动的目标是一块或几块地区，不是"消灭对方"。**对方的其余地区照旧存在、照旧在发展。**

> 由此推出的第一件事：**战争是一个可以打一半、可以停、可以分次来的连续动作**，不是一次性结算。

---

## 3. 占领一块地区会发生什么

**占领是战斗结算之后的动作。**

### 3.1 打的时候

走统一的战斗结算——双方各自动员兵力与装备，按队的编制打，直到一方溃退或被歼灭。**邻国打你和打邻国，是同一套规则，没有任何特殊表单。**

### 3.2 打下来的时候，那块地已经坏了

**一次攻击落在一块地区上，该地区受到损害：**

| 后果 | 落在哪个已有读数 |
| --- | --- |
| 当地凝聚力大跌 | **村落凝聚力** |
| 建筑损毁 | **建筑格** |
| 人口损失 | **人口** |

**这不是"劫掠"这个特殊行为的效果，是"一块地被打"的通用后果。** 玩家打别人的地，别人的地也是一样的遭遇。

### 3.3 拿到手的时候，它几乎是负资产

**刚占领的地区凝聚力很低**，而凝聚力决定你从这块地拿到多少——**所以刚打下来的地，产出接近零，而它仍然在吃你的粮、占你的期数。**

**要把它变成正资产，只能靠投入治理，逐步消化。**

---

## 4. 消化

**消化 = 把一块刚占领的地区养回能产出的状态。**

能用的手段就是那些既有的治理手段——社会节点、修路、派驻、粮食、换统治方式。**本系统不新增手段，只规定"新占的地必须走一遍这个过程"。**

| 阶段 | 状态 |
| --- | --- |
| **刚占领** | 凝聚力极低，产出接近零，**维持成本照付** |
| **消化中** | 凝聚力爬升，产出按上交比例逐步恢复 |
| **已消化** | 与自有的地区无异 |

**消化要时间，也要资源。** 这两样都不能省。

---

## 5. 入不敷出

**占领是有上限的——不是兵力上限，是消化能力上限。**

**一次占得太多，你在同一段时间里要同时消化多块地区**，而每块地区都在吃粮、占期数、耗兵力去驻守。**产出还没回来，成本已经压上来。**

> **这条是战争扩张的天然刹车：你能打下来多少，和你养得起多少，是两个数。** 后者小得多。

**结果就是玩家必须在"再打一块"和"先把手里这块养熟"之间反复选。**

---

## 6. 它和其他系统的接口

| 方向 | 内容 |
| --- | --- |
| **上游** | **战斗结算**——先赢，才有占领<br>**战争潜力**——可动员兵力与可装备兵力决定你能不能打 |
| **下游** | **村落凝聚力、建筑格、人口**——承受占领的损害<br>**区块产出**——决定新占地区多久能回本 |
| **平行** | **邻国**——它们的地就是这么被拿走的，它们也是这么拿你的 |

---

## 7. 本系统的禁令

- **不得把"打下来"和"拿到产出"合并。** **中间必须隔着一段低产出期**——这是本系统唯一的存在理由。
- **不得让占领不损害当地。** 打下来就完好的地，等于没有消化成本。
- **不得给邻国的攻击做一套特殊规则。** 它和玩家的部队调动攻击**完全一致**。
- **不得让占领有兵力之外的上限。** 上限是消化能力，不是军队规模。

---

## 8. 验收要点

1. 玩家能感受到**打下来不等于拿到手**——新占的地区有一段只花钱不产出的时期。
2. 玩家能观察到**当地被打坏了**——凝聚、建筑、人口三项同时受损。
3. 玩家能亲身撞到**入不敷出**——一次占太多，粮和期数立刻不够用。
4. 玩家能理解**邻国的攻击没有任何特殊之处**——它就是一支队伍打过来。
5. 玩家会主动**在"再打一块"和"先养熟这块"之间犹豫**。
