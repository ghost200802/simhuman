# 战争系统 · 依据与推导

**定位：** 记录战争系统每条设计的文献依据与推导过程。
**边界：** **不写游戏规则**。本文只写"凭什么这么定"，以及哪些地方查不到、有争议。

## 一、参照对象：一个已存在的简化系统及其尺度死穴

### 1.1 它的结构

**《十字军之王 2》的战斗结构**（CK2 官方 Dev Diary 10，作者 Henrik Fåhraeus；CK2 Paradox Wikis "Combat" / "Warfare" 页）：

| 项 | 内容 |
| --- | --- |
| **编成** | 每方最多 **3 个侧翼**（左 / 中 / 右）；一场战斗最多 6 个侧翼 |
| **结算** | 每个侧翼**独立结算**，一对一对打对方的对应侧翼 |
| **指挥官** | 每个侧翼有自己的指挥官，其军事属性只作用于本侧翼 |
| **时间粒度** | **每 1 天**结算一次，所有侧翼同时结算 |
| **阶段** | 前哨战 → 混战 → 追击，**各侧翼独立推进，因此不同步** |
| **最小单位** | 由据点征召的**部队（regiment）**，官方设计上**不可拆分也不可合并** |

**它有意不模拟的东西**（Dev Diary 10 的官方设计意图）：具体战术动作、阵型、队列、士兵个体、战场地形上的位置与机动、**战斗宽度**、玩家实时干预。

> **它的战斗宽度缺失是官方选择**：CK2 全游戏唯一近似"前线"的机制是 **Narrow Flank**（2.0 补丁引入）——混战阶段且防守方被人数压制时，进攻方**无法投入超过防守方开战兵力的部队**。触发概率取决于地形（**山地、丛林最高**，丘陵、森林次之，平原最低）。**注意：伤害公式本身是尺度无关的——按人数比例分摊。它崩的是外壳，不是内核。**

### 1.2 它为什么不能直接用

**它的战斗尺度下限是「一个部队」，不是人。**

CK2 的最小作战单位是由据点征召的 regiment，**数百人量级，且不可拆分**。主战场抽象在**整个行省**层面。**没有"班 / 组 / 个人"概念，因此无法表示小规模遭遇、斩首、护卫。**

社区对它的批评集中在**中间层缺位**："堆栈打堆栈 + 每日骰子"，玩家在"极致微操兵种比例"和"无脑堆兵"之间**没有中间选项**。另有批评指出战术修正过大（约 **−150% ~ +420%**），常淹没科技与地形，使体验接近掷骰。

**它的继承者解决了宽度问题，但方式与本设计相反**：CK3 引入了 **Combat Width**——地形决定**同时能有多少人参战**。这是本设计**明确不采用**的方向（见第四节）。

## 二、战线宽度：它真正的作用是「决定能否包抄」

### 2.1 瓶颈模型

**Bongers, A. & Torres, J.L., "A bottleneck combat model: an application to the Battle of Thermopylae," *Operational Research* 21(4) (2021), 2859–2877。**

它把"只有一部分兵力能同时投入"形式化为**瓶颈参数 K**：每期只有 K 个单位能交战，损失率与 K 成正比。核心结论：

- **若双方都受瓶颈约束，模型退化为线性律**（无论瞄准还是非瞄准火力），**损失率是常数**。
- **初始总兵力几乎不影响胜负，只影响战斗时长**（也取决于 K 的大小）。
- 地形约束使**质量（战斗效能）与可投入规模**变得更重要，**削弱了纯粹的数量优势**。
- **若双方质量相近，地形瓶颈对胜负无关。**
- 应用于温泉关：**如果瓶颈约束一直保持不被解除，波斯军会被击败。**

### 2.2 一个"数量优势被地形抹平"的史实案例

**Wagon Box Fight（1867）**：Crazy Horse 沿**狭窄峡谷**进攻，数量优势无法展开，**25:1 的兵力优势未能转化为胜利**（Johnson & MacKay 2015 作为"地形强制线性律"的实例引用）。

### 2.3 另一条同类规律（数值需谨慎）

**前线宽度与兵力的平方根成正比**：Sabin (2007) 与 Isby (1988) 被引述为——古代军队正面宽度 ∝ √N。由此推出**投入率 ∝ 1/√N**。

ISMOR 第 34 届 Lanchester 研讨会的算例：**1,000 名进攻方在 1 km 正面，只有约 300 名防守方被卷入**；进攻方翻倍到 2,000 人，正面只扩展到约 1,414 m，被卷入的防守方升至约 424 人。

> ⚠️ **该 PDF 未能直接抓取，内容来自检索摘要，未经验证。**

**⚠️ 两条规律互相冲突**：若战场宽度固定，多出来的人只能加纵深，则投入率 ∝ 1/N；若军队能自由展开，则投入率 ∝ 1/√N。**文献中两条都被提到，未找到调和两者的研究。**

## 三、线性律与平方律

### 3.1 基本模型

| 模型 | 战斗强度 | 适用 |
| --- | --- | --- |
| **线性律** | ∝ N | **近战单挑**、非瞄准面射 |
| **平方律** | ∝ N² | **瞄准的远程火力**、全员互射 |

现代分析有时取中间指数 **1.5**。

### 3.2 史实检验：两个都不完全对

| 研究 | 结果 |
| --- | --- |
| **Willard** | 参数 γ **不在 0 与 1 之间**，而是 **−0.27 到 −0.87**，中心约 **−0.5**。结论：**兵力比对预测胜负几乎没有作用**，平方律作为确定性模型表现很差 |
| **Helmbold，92 场战役** | **α = 1.29，β = 0.21，R² = 0.54**。映射：α = 0 → 平方律；α = 1 → 线性律；α = 2 → 对数律。**1.29 落在线性与对数之间**，α ≈ **1.35** |
| **Fain，60 场二战地面交战** | γ = −0.594 / −0.413 |
| **National Training Center** | γ = **−0.9111**，倾向对数律，**不支持平方律** |
| **Mark Thornton，486 场历史战役** | **兵力较大的一方只有 51% 的胜率**，兵力规模与胜负**无显著关系**；败方在近 **80%** 的战役中损失更大 |

**Helmbold 关系的微分形式**：dx/dt = −e^C · x^0.75 · y^0.40，dy/dt = −e^F · x^0.40 · y^0.75。

> ⚠️ **重要警告**：因为 x₀、y₀ 同时出现在等式两边，这个关系"**可能近乎是同义反复**"，对任意数据都可能给出高 R²。另一竞争模型（constraint model）模拟 92 场战役得到 α 均值 **1.20**、R² 均值 0.66，与史实值足够接近，说明史实数据**也可能**由拓扑约束产生。**Lanchester 的两条律从未被验证过。**

### 3.3 一个相反方向的假说（重要）

**Johnson, D.D.P. & MacKay, N.J., "Fight the power: Lanchester's laws of combat in human evolution," *Evolution and Human Behavior* 36(2) (2015), 152–163。**

它主张人类演化史上主导且最致命的战斗形式是**不对称袭击**——多人围攻少数人、以压倒性局部数量优势伏击，**近似平方律**。因此人类可能演化出"**平方律启发式**"。

- **平方律会降低人数多一方的个体风险**，从而帮助解决战争的集体行动难题，有利于合作与规模扩张。
- **代价**：这种启发式在**现代战争**中可能**适应不良**。
- **证据是混合的**：黑猩猩群体冲突符合平方律预测；澳洲肉蚁与阿根廷蚁符合平方律；**火蚁与珊瑚礁鱼符合线性律**。

> **含义：不同尺度可能适用不同的律。** 这是"一套模型贯通六个数级"这个目标的**最大理论障碍**。

## 四、正面 / 后排的军事意义

### 4.1 后排不是"不能打"，是"以另一种方式打"

**戚继光《纪效新书》鸳鸯阵**——11 名战斗员 + 1 名火兵，由前到后：

| 位置 | 人员 | 职能 |
| --- | --- | --- |
| 第 1 排 | 队长 1（居中调度督战）+ **盾牌手 2** | 长牌挡重箭长枪；藤牌手带标枪 2 支、腰刀 1 把，掷标枪后趁敌拨挡时取腰刀砍杀 |
| 第 2 排 | **狼筅手 2** | 毛竹制，长约 3 m 至一丈三四尺，梢加利刃，横扫敌阵，掩护盾牌手推进 |
| 第 3 排 | **长枪手 4** | 丈二长枪，刺杀被狼筅扫倒之敌 |
| 第 4 排 | **短兵手 2** | 七尺短兵器；长枪未中则冲上劈杀，并警戒两翼 |
| 最后 | 火兵 1 | 炊事 |

配合原则原文：**"筅以用牌，枪以救筅，短兵救长枪"**。戚继光还按**体质配兵器**：胆勇便捷者使藤牌；体壮力大者使狼筅；30 岁上下、精力充沛者使长枪。

**韦格蒂乌斯《De Re Militari》"论布阵"**：

- **步兵**："**后排的人确实以他们的纵深支撑着第一列**"（those pressing from behind indeed support the first rank with their depth）。
- **骑兵完全相反**：骑兵是"一个整块"，后面的人推前面的人"**毫无作用，只会一起倒下、扰乱队形，自乱甚于敌勇**"。
- 方阵长宽比：最佳为**长是深的两倍**（如长 8、深 4；或长 10、深 5）；有人主张**三倍**。

### 4.2 投射兵放在正后方是错的——这是"早期没有后排"的直接依据

**Onasander 明确反对**把轻装兵（标枪手、弓手、投石手）放在方阵**后面**——"**他们对自己军队的伤害会大于对敌人的伤害**"。若混编在重装兵中间，他们也无法后退助跑投掷、前冲投掷或旋转投石。

**放在后排的弓手必须高抛射击**，箭"**只有上升段有动能**"，下坠时已成强弩之末，造成"很小的困扰"。**例外**：轻装兵在**高地**上时可以放在后方。

**投射兵占比**：亚历山大与希腊化军队中投射兵约占 **10%**；罗马中期三线阵中，投射 / 轻装兵纸面上约占步兵的 **2/7**。投石兵（巴利阿里）的铅弹可超 **100 mph**，能隔着盔甲砸碎骨头。训练有素的弓手**每分钟 10–12 箭**。

### 4.3 前沿的实际纵深

| 项 | 数据 |
| --- | --- |
| 希腊方阵武器触及 | 只有前 **1–2**（一说 3）列能够到敌人；后列的矛"**不可能造成任何实质伤害**" |
| 纵深 | 标准 **8 列**；斯巴达 4 世纪常用 **12 列**；叙拉古、雅典、底比斯用 **16 列**；底比斯后来用 **25 或 50 列** |
| 正面密度 | 常序约 **0.9 m/人**；密序约 **0.45–0.5 m/人** |
| 马其顿方阵 | 前 **5 列**的萨里沙可前伸 |
| **力学测算** | **超过 12–16 列后，每加一个人增加的推力几乎为零**（平台效应） |

### 4.4 一个"参战比例"的古代推算

**修昔底德《伯罗奔尼撒战争史》5.68**：斯巴达 7 个营，每营 4 连、每连 4 排、每排第一列 4 人 → **第一列共 448 人**；全军按平均 8 列纵深算 = **4,184 人**。即 **前排 ≈ 1/8 ≈ 10–11%**。

> ⚠️ **这是唯一由古典作家自己算出的"参与交战的绝对人数"，但修昔底德本人明说这是推测性的重构**，现代学者也认为他这一段的数字"方法比结果更重要"。

## 五、伤亡率：战斗本身低，溃退时高

### 5.1 伤亡率表

| 年份 BC | 战役 | 胜方 | 败方 |
| --- | --- | --- | --- |
| 472 | Acragas | 10.0% | 20.0% |
| 432 | Potidaea | 5.0% | 15.8% |
| 426 | Olpae | 5.0% | 16.7% |
| 425 | Solygea | 2.5% | 12.1% |
| 424 | Delium | 7.1% | 14.3% |
| 418 | Mantinea | 3.3% | 13.8% |
| 415 | Syracuse | 2.0% | 5.2% |
| 413 | Syracuse | — | 20.0% |
| 412 | Miletus | — | 20.0% |
| 409 | Ephesus | — | 10.0% |
| 395 | Naryx | 8.3% | 16.7% |
| 394 | Nemea | 4.9% | 11.7% |
| 394 | Coronea | 1.7% | 3.0% |
| 371 | Leuctra | 5.0% | 10.0% |
| | **平均** | **~5%** | **~14%** |

Krentz 的推论：因为希腊方阵**几乎没有骑兵**，追击能力弱，所以败方 14% 已经算高；有骑兵的时代败方损失大得多。**Krentz 还指出伤亡高度集中在前排。**

> ⚠️ **Krentz 自己的样本很小（约 14 场）**，且依赖质量不齐的史料（修昔底德较好，Diodorus 差，色诺芬很少给数字）。他主动排除了 Tanagra 等难估的战役。有学者认为胜方 5% 可能被史家"修饰过"；若把**丧失战斗力者（伤员）**也算进去，总数可能到约 **20%**。

### 5.2 溃退是主要杀伤场

| 战役 | 数据 |
| --- | --- |
| **Zama** | Hannibal 步兵"只有少数逃过罗马人的复仇，**超过 20,000 人在逃过开阔平原时被杀，几乎同样多被俘**" |
| **Regulus 的 15,500 人军队** | 只有 2,000 人逃脱，其余"在战斗或追击中被屠杀"（约 **87% 损失**） |
| **Cannae** | Livy 称 **48,200 人"在包围圈中被屠杀"**；Polybius 称罗马阵亡约 **70,000**，迦太基仅损失 5,700–8,000 |
| **剑桥本《希腊罗马战争史》** | **败方大部分伤员随后会被杀死或俘虏** |
| Konijnendijk 的章节标题 | **"No Shortage of People to Kill: The Rout"** |

**Gabriel, R.A. & Metz, K.S., *From Sumer to Rome* (1991)**：

- 起初**胜方阵亡 5%、败方 11%**；一旦溃退或遭伏击，伤亡"大幅增加"。
- p.87：六场大战合计损失 **227,000 人** ≈ **79,000 阵亡 + 76,000 被俘 + 72,000 负伤**；参战者约 **50 万** → **总损失率接近 45%**。**阵亡 : 负伤 ≈ 1.1 : 1**（古代比值接近 1:1，与近代 1:3–1:4 相反）。

> ⚠️ 另有一处转述称败方阵亡率 **30%–75%**，与上面的 11% 冲突。该来源是论坛转述，**不可靠**。

### 5.3 脉冲模型：为什么伤亡率能低到 5% 以下

**Sabin, P., "The Face of Roman Battle," *Journal of Roman Studies* 90 (2000), 1–17。**

核心：罗马战斗是"**自然的对峙，被周期性的局部冲锋打断**"。所谓 **battle pulse** = 冲锋（pulse）+ 间歇（lull）。间歇时双方退到标枪距离喘息、互掷、重整，然后再次接触。

**Sabin 用这个模型专门解释"为什么伤亡率低到 5% 以下"**——如果真是持续贴身打几小时，损失应该远不止此。

**支持**：**Zhmodikov, A., *Historia* 49.1 (2000)** 指出 *pila* 标枪是**贯穿整个战斗**反复使用的，不是开场的齐射一次。

**核心反证**：Sabin 的"换班轮替"假说——罗马会定期用生力军替换疲惫的前排。但批评者指出**古代史料里从未真正描写过"在交战中换班"**（Herda、Pharsalus 是孤例），把它推广为常规制度**超出了证据**。

**othismos（推挤）之争**：Hanson 派认为纵深就是用来"推"的，越深越强；Krentz、van Wees 反驳说重装兵需要约 **6 英尺**空间才能挥动武器，字面意义的盾抵背推挤不成立。

## 六、士气与溃退

### 6.1 士气是决定性的，但没有固定阈值

**士气 / 凝聚力崩溃是古典战斗的决定性变量**，这一点在文献中高度一致（Keegan、du Picq、Lendon、Sabin 都持此论）。

**但"伤亡 5% 即溃"这类说法没有学术依据。**

**Clark, Dorothy (1954)**，研究 **43 场营级战斗**，结论：

> **"称一支部队损失特定伤亡百分比后即不再有战斗力，是严重过度简化，不被战斗数据支持。"**

事实上 **43 例中有 15 例（35%）在超过 40% 伤亡后才崩溃**。另：**50 年里这只被严格研究过约两次**。

**现代兵棋惯例的阈值全部有争议**：1964 年美军机动控制手册给出**防御方约 40%、进攻方约 20%**（**营级**数据，后被错误推广到师级）；"40% 规则"（Dupuy Institute）**分析依据不明**；C-WAM 模型旅级——低于 **50%** 只能防御，低于 **30%** 撤出。有兵棋开发者说行为模式"在不同时期、不同文化间差异极大"，需要 **15 套不同的模型**——**反过来说，"一个统一的崩溃阈值"这个假设本身就被从业者否定。**

### 6.2 古典侧与溃退的触发因素

**du Picq（*Battle Studies*，1870 年前）**：战场上较量的是"**两支道德力量，甚至超过两支物质力量**"。他提出两条悖论：① 个体最勇武的（日耳曼、高卢）反而战绩最差；② **败方伤亡总是远大于胜方**——他的解释是败方大部分伤亡**不发生在战斗本身，而发生在逃离战场的过程中**。

> ⚠️ 注意：du Picq 强调**训练与纪律才是道德凝聚力的基础**，**并非"士气高就能赢"**（那是 Grandmaison 对他的曲解，导致 1914 年法军的灾难）。

**Lendon, *Soldiers and Ghosts* (2005)**：强调文化传统而非技术。希腊方阵是"**终极的集体活动**，但希腊人是以竞赛的方式理解它的"。罗马则以 **virtus（个人勇武）**与 **disciplina（含节制、训练）**的张力为核心。**Lendon 明确质疑"铁的纪律"和"单位凝聚力"是罗马成功秘诀。**

**剑桥本《希腊罗马战争史》**：在单场战斗中，**将道是胜负最重要的单一决定因素**。

**溃退的触发因素**（*Unit Cohesion and Warfare in the Ancient World*）：**敌军威名、战吼、可怖的外貌或凶猛整齐的推进、敌军战斗力超出预期、优势的投射火力**——都能"绷断凝聚力的缰绳"。

**预备队决定追击能否被利用**：Geronium 一役，Hannibal 趁罗马军混乱施压，但罗马生力军一到就收手，怕被反击。**追击败军的一方如果自己也失序，可能反被反击**——所以胜方常常主动克制追击。

### 7.2 史料数字默认不可用

**Herodotus 的薛西斯远征**：总数列 **2,641,610**（含后勤 5,283,220）。现代学者一致判定为荒谬。常见解释是 Herodotus 把"千夫长"误作"万夫长"，**去掉一个零**。

**Delbrück（1900–1920）** 是系统纠偏的第一人。他的名言：**如果薛西斯真的有几百万人，那么当先头部队抵达温泉关时，最后一个人还在从苏萨出发。** 他估算温泉关陆军 **~65,000 人**。

现代估计仍高度分歧：Munro **170,000–180,000**；Meyer/Hignett **100,000**；Hinz **80,000**；Delbrück **65,000**；von Fischer **< 50,000**。有人说 **> 100,000 已不太可能**，上限受**供水**约束在约 **175,000**。

> **结论：任何"带甲十万""波斯百万"式的史料数字，默认不可直接使用。**

## 八、铁与战斗力的关系

### 8.1 铁兵器并不优于青铜兵器

**Champion, T.C., "The early development of iron working," *Nature* 284 (1980), 513–514**：

> 近期研究显示"**早期铁并不优于青铜，使用青铜的社群并未立即采用它**"。他称"铁因具有制造更优武器的潜力而在赫梯崩溃（约公元前 1200 年）后传播"的传统观点**"站不住脚"**。

**Waldbaum (1999)** 明确批评旧假设，包括"**铁在性质上天生优于青铜**"。

**Britannica**：铁早在公元前 3000 年就作为"稀缺贵金属"使用，但"**没有迹象表明当时的人认识到它优于青铜的性质**"。

**剑桥经济史**：掌握渗碳、淬火、回火用了约 **150 年**（关键期 **1200–1050 BC**）。"**起初，铁的使用限于装饰品，其相对青铜的劣势无关紧要。**"

**铁 : 青铜比例（兵器与盔甲）**：

| 时期 | 比例 |
| --- | --- |
| 1200–1100 BC | **0.03** |
| 1100–1000 BC | **0.19** |
| 1000–900 BC | **0.54** |

**这是渐进替代，不是优势驱动的突变。**

**Maddin, Muhly & Wheeler, "How the Iron Age Began" (1977)**：西南亚到西地中海、跨 2000 年，**铁器不足 500 件**（多为装饰品），而青铜器**数以万计**（含工具与兵器）。

**荷马研究**：在史诗创作年代，铁"仍在试用期"；"**佩剑之人出于一切军事目的都偏好青铜**"。铁首先用于农具和器皿，而非兵器。

### 8.2 替代解释不是铁的优势

**青铜 / 锡价格上涨与供应中断**（1200 BC 后塞浦路斯、东希腊、沿海安纳托利亚）；以及**青铜时代崩溃后冶金的去中心化**——工匠脱离王室庇护，转向更实用的日常需求。

> ⚠️ **Mirau (1997)** 认为"锡短缺说"和"木炭短缺说"**都不正确**，因为没有出现冶铁设施的剧增。**赫梯 / 腓力斯丁人的"铁垄断"说也被判定为"站不住脚"。**

### 8.3 实验考古学（只测了青铜，没有对比）

**Bronze Age Combat Project (BACP)**：7 把复制青铜剑，与武器和盾牌做单次击打测试，然后由受训的中世纪格斗志愿者做真实对抗序列。磨损分析对比了英国和意大利的 **110 把**真实青铜时代剑，编目 **2,500+ 处**磨损痕迹。

**Molloy (2007)**：青铜时代中期复制剑对复制盔甲、新宰猪尸、卷起的草席。Group II 剑切软组织有效；短 Group IV 剑切割有限但刺击优秀。**两者都无法切开复合盔甲**。

**关键发现**：青铜剑**会崩口、缺口**，因此战士**避免剑刃对剑刃**，专打身体。

> **没有任何来源报告过青铜剑 vs 铁剑的受控实战对比。**

## 九、狩猎作为战斗

### 9.1 直接类比的学术传统

**Wrangham 的力量失衡假说（imbalance-of-power）**：狼和黑猩猩都有对邻近群体成年个体的**致命联合杀戮**。预测条件：群体间敌对 + **足够的力量失衡使一方可以无代价攻击**。这是把"联合杀戮"类比为一种**低成本的"狩猎"**。

**Corning, "Synergy Goes to War"**：把人类战争直接类比**群猎哺乳动物**（狼、非洲野犬、鬣狗、狮）和**集群掠食的蚂蚁**。驱动力是"协同"：规模经济、风险分摊、分工、功能互补、信息共享、工具共生。即**战争的组织基础与协作狩猎高度重叠**。

**反证**：安达曼群岛的民族志显示，狩猎队相遇时确实可能互相伏击，**但 Wrangham 的"无代价攻击"前提经常不成立**——群体间敌对常常形成**僵局与消耗战**，而非一方压倒。群体可能**回避边界、低度利用资源，甚至举行联合狩猎与捕鱼的和解集会**。

### 9.2 狩猎的风险（间接量化）

**Gurven, M. & Kaplan, H., "Longevity Among Hunter-Gatherers," *Population and Development Review* 33(2) (2007), 321–365**：

- 狩猎采集者中只有约 **57% 的人活到 15 岁**。
- 死因构成：**疾病 ~70% / 暴力与意外 ~19–20% / 退行性疾病 ~9%**。
- **Ache（巴拉圭）15–59 岁成人**：暴力 **46%**、疾病 **28%**、**意外 23%**、退行性 3%。
- **Hadza**：意外死亡占男性 **2.9%**；暴力占男性 **7.3%**；凶杀率 **66/10 万/年**。

**伤病侧**：**Machiguenga** 最多 **10% 的男性每年因带刺竹类割伤损失 1–4 周**；**Yora** 一名猎人有 **8 周**未出猎，其中超过一个月明确是因伤；**Shiwiar** 蛇咬伤导致 **3–6 个月**无法有效狩猎。

**推算影响**：损伤一名**普通**猎人 → 仅肉类蛋白摄入下降 **18%**；损伤**最好**的猎人 → 下降 **32%**。

**风险作为"代价高昂的信号"**：**Meriam 海龟狩猎**是"人类代价高昂信号"**被研究得最充分的案例**。海龟狩猎**危险、能量回报率远低于采集贝类**，因此是"诚实信号"。成功的猎人获得社会认可、更早开始生育、更好的配偶。

> ⚠️ **但这不是"狩猎死亡率"数据，而是"风险被主动追求并作为信号"的证据。狩猎采集社会"狩猎导致的受伤/死亡率"本身，没有任何研究给出过量化数字。**

## 十一、登记与编户

### 11.1 登记的深度是递进的

**秦「为户籍相伍」（前 375，献公十年）的具体著录内容史无明文。** 学界公认的关键转折点是**秦王政十六年（前 231）「初令男子书年」**——**年龄从此时起才正式入籍**。

登记的深度是一条递进线：

```
名  →  名 + 亲属关系 + 爵  →  + 年龄  →  + 财产土地
```

**里耶秦简户籍简（迁陵县南阳里，约 20 余户）** 的格式是一户一牍，长 46 cm（秦二尺），**五栏**：

| 栏 | 内容 |
| --- | --- |
| ① | 户人 + 爵 + 名 |
| ② | 配偶（及兄弟配偶） |
| ③ | 儿子 |
| ④ | 女儿 |
| ⑤ | 伍长 / 臣（奴婢） |

**它明确不登记年龄、身高、肤色、财产。**

《商君书·境内》「四境之内，**丈夫女子皆有名于上，生者著，死者削**」；《商君书·去强》「强国知十三数」含壮男壮女之数、老弱之数。**注意：这只说明登记对象，不含年龄。**

### 11.2 傅籍年龄——四说并存

睡虎地《傅律》**只有两条残文，均不载始傅年龄**。数字全部是从《编年记》墓主「喜」的傅年反推的（喜，秦昭王四十五年即前 262 年生，秦王政元年即前 246 年傅）：

| 说法 | 主张者 |
| --- | --- |
| **17 岁** | 传统主流（《云梦秦简研究》《发掘简报》系统）；张金光认为当时无周岁虚岁之分 |
| **16 岁** | 陈直、马非百、陈伟（据走马楼西汉简主张用「实岁」） |
| **18 岁** | **凌文超《秦代傅籍标准新考》，《文史》2019 年第 3 期**；陈伟另据岳麓秦简《尉卒律》指出士伍与公士以上子皆 18 岁傅 |
| **15 岁** | 朱德贵《岳麓秦简课役年龄中的几个问题》 |

**汉初按爵分等**（张家山汉简《二年律令·傅律》）：不更以下子 **20 岁**、大夫至五大夫及小爵不更至上造 **22 岁**、卿以上及小爵大夫以上 **24 岁**。景帝二年（前 155）统一为 **20**；**昭帝以后改 23**（《盐铁论·未通》；如淳注引律「年二十三傅之畴官」）。傅籍于**每年八月**进行。

> ⚠️ **另有「以身高为标准」一说**（高恒、曹旅宁）：秦长期以身高傅籍，因为秦王政十六年以前官府尚未掌握年龄数据。

### 11.3 户籍与普遍征兵互为因果

**杜正勝《編戶齊民——傳統政治社會結構之形成》（臺北聯經，1990）。** 分章论证：「編戶」= 按戶登錄人口，使基層人民透過戶籍受國家統治。第一章区分离「**名籍**」（宦籍、市籍、宗籍，多以个人为单位）与「**户籍**」（含全部家户成员）；第二章《全国皆兵的新军制》论「作州兵」「作丘甲」「用田賦」为春秋诸侯**扩大征兵范围**之举，并指出**户籍制度与普遍征兵互为因果**。

**James C. Scott, *Seeing Like a State* (1998)**：前现代国家「**部分失明**」，不知臣民财富、地产、位置乃至身份；**集体估税使地方官系统性低报人口**。

> **落点：这给了「编户档位」一个文献基础——登记的深度是一个可以被投资推进的量，而不是有/无的二值状态。**

## 十二、动员率

### 12.1 概念有来源，数据集不存在

**动员率在文献中的正规名称是 Andreski 的「军事参与率」（Military Participation Ratio, MPR）。**

**Stanisław Andreski, *Military Organization and Society*（1954）**：MPR 定义为「**用于军事行动的成年男性人口比例**」。核心命题：**给定技术水平下，社会不平等程度与 MPR 反比。**

> ⚠️ **不存在一个权威的、跨文化的「动员率」数据集。** 可用的量化数字存在**双峰结构**。

### 12.2 双峰结构

| 类型 | 数值 |
| --- | --- |
| **常备 / 野战军** | 普遍 **< 1% – 2.5%** |
| **全面动员** | **8% – 11%** |
| **理论天花板** | 约 **20–25%，且不可持续**（15–60 岁男性约占总人口 25–30%，持续数月至一年即因农时中断而崩溃） |

**具体数字：**

| 政权 | 军队 | 人口 | 比例 |
| --- | --- | --- | --- |
| 罗马帝国（奥古斯都） | ~300,000（含海军） | 50–60M | **≤ 1%** |
| 罗马（Marcus Aurelius 期） | ~2% **成年男性** | — | 2% |
| **罗马 212 BC（布匿战争）** | 陆军 + 海军 | 自由人口 | **< 11%**（Rosenstein, *Rome at War*, 2004） |
| 拜占庭 1025 | 250,000 | 12M | 2.4% |
| 查理曼 | 20,000 | — | ~0.2% |
| 汉（一估计） | 200,000 常备 | 60M | 0.3% |
| 拿破仑法国 | 3M | 30M | **10%** |

**Azar Gat, *War in Human Civilization*（OUP, 2006）的经验规律：**

> **任何国家通常最多只能长期维持约 1%（通常更少）的人口为全脱产职业军人。**

**中国的比例记载：**

| 来源 | 比例 |
| --- | --- |
| 《孙子兵法·作战篇》「凡兴师十万，出征千里……不得操事者，七十万家」 | **1 : 35** |
| 沈括《梦溪笔谈》「**三人饷一卒，极矣**」 | 1 : 3（运粮者与战兵） |
| 唐贞观 | ≈ 1 : 25 |
| 盛唐（57 万兵 / 910 万户） | ≈ 1 : 75 |
| 隋炀帝征高句丽（70 万兵「馈运者倍之」） | ≈ 1 : 20——**直接导致崩溃** |
| 明初军户制（200 万军队，但**脱产仅 60 万**） | 实际 ≈ 1 : 100 |

**赵文林、谢淑君《中国人口史》**：战国总兵力估约 **400 万**，对应人口至少约 3,000 万。认为最严酷的兵役是「**三户二丁**」，即 15 人中最多 2 兵。

**《岳麓秦简》**「凡三乡，其一乡卒千人，一乡七百人，一乡五百人」（共 2,200）——学者据此推兵民比 **1:25 至 1:50**，并指出真正脱产者仅约 1,000 人。

### 12.3 两条必须一起记的警告

**① 「8:1」这个军民比没有出处。** 多轮定向检索返回空结果。最接近的具名数字是 Rosenstein 的「212 BC 陆军 + 海军 < 11% 自由人口」。**不要把它当成有出处的事实使用。**

**② 「低动员率」不等于「低战争强度」——这是最重要的一条。**

**Lawrence Keeley, *War Before Civilization*（OUP, 1996）**：

- **三分之二的原始民族常年处于战争状态，典型年战争死亡率约 0.5% 人口。**
- **部落战争平均比 20 世纪战争致命 20 倍**（按战争死亡占总死亡比例或年均战争死亡率计）。
- Yanomami **逾 1/3 男性死于战争**；Murngin 20 年内 800 名男子中至少 200 人（**25% 成年男性**）死于部落战争；Crow Creek 屠杀中约 800 人的村落 **> 60% 被杀**；Gebel Sahaba 约 **40–50%** 骸骨有暴力致死痕迹。

> **含义：动员率低，但战争频率高、致死率高。** 这两件事不矛盾——早期社会是「**低比例、高频率、高致死率**」。

## 十三、兵制：从征发到募兵

### 13.1 希腊：雇佣兵兴起源于小农破产

**H. W. Parke, *Greek Mercenary Soldiers*（Oxford, 1933）** 把制度成长**首要归因于中产小农的困境**——战争、领土破坏与大地主缓慢增长使小农破产。Parke 表 II：**前 399–375 年间服役雇佣兵从不少于 25,000 人，后期平均数保持约 50,000 人**。

**Charlotte Van Regenmortel, *Soldiers, Wages, and the Hellenistic Economies*（CUP, 2024）**：①**亚历山大死后政治合法性崩塌，事实上把全部士兵变成了可自由交易的志愿者**；②继业者王国巩固期**回归征发制**（从定居者与臣民中征召），雇兵仅在前 323–272 的混乱五十年占优；③**土地授予**把受赠者绑定于授予者，是「把退役志愿者及其后代转化为未来征召兵」的手段；④付酬：**步兵约每日 4–9 obols**。

### 13.2 罗马：征发 → 常备 → 以金代征

dilectus（征发）长期存续。后期出现 **aurum tironicum（以金代征）**——至 370 年代，**年度征募作为税项与「新兵折金」选项均已稳固**，只有其他兵源短缺时才实际要求交人。

### 13.3 中国：出钱免役自发完成募兵化

**汉代兵役结构**：23–56 岁男子，每年在本县服**更卒一月**（地方力役），一生服**正卒一岁**、**戍卒一岁**。

**「更」之三品**（如淳注）：

| 名 | 内容 |
| --- | --- |
| **卒更** | 一月一更 |
| **践更** | **贫者受雇代役，出钱月二千** |
| **过更** | 天下人皆直戍边三日，不行者**出钱三百入官** |

**雷海宗的经典论断**：汉初理论上恢复战国征兵制（力役与军役合一），但因践更、过更之制，**上等社会多出钱免役，卫国责任渐移于贫民**，「更赋」中「赋」的成分极重，**已接近募兵制**。

### 13.4 魏武卒：早期募兵精锐，以及它的财政批判

**《荀子·议兵》**：

> 魏之武卒以度取之，**衣三属之甲，操十二石之弩，负矢五十，置戈其上，冠胄带剑，赢三日之粮，日中而趋百里**。中试则**复其户，利其田宅**。

**全盛约五万人。** 这是**选拔性募兵 + 免税免役 + 授田宅**。

**荀子对这套制度的批判是本问中最关键的文献**——他说武卒是「**危国之兵**」，因为「复其户、利其田宅」导致「**地虽大，其税必寡**」，且「数年而衰而未可夺也，改造则不易周也」。

> **这是「精锐募兵的财政不可持续性」在古代文献中最明确的表述。**

## 十四、训练

### 14.1 训练时长有数字

| 政权 | 时长 | 出处 |
| --- | --- | --- |
| **罗马** | **4 个月** | Vegetius, *De Re Militari* II.5；Davies, "Joining the Roman Army," *Bonner Jahrbücher* 169 (1969), 208–232 |
| 斯巴达 agoge | **约 14 年**（7–21 岁或 7–29 岁，古代来源本身分歧） | — |

**罗马的新兵流程**：**probatio**（审查年龄、身高、体格、自由出身、品行）→ **in numeros referre**（记入单位名册）→ **4 个月基础训练** → 合格方正式入伍。训练次序：**先教行军步伐**，再教武器（用**加重训练武器**）。新兵**每日两练**，正式士兵每日一练。

> ⚠️ **但多项来源指出斯巴达的 agoge 并不教武器使用或操练**——斯巴达强调群体战术而非个人格斗。

### 14.2 训练对战斗力的量化证据——前现代查不到

**没有找到任何古代/中世纪的「训练→战斗力」效应量研究。** 最接近的量化框架是 Dupuy 的 **CEV**（*Numbers, Predictions and War*, 1979：`P = S × V × CEV`），但那是 **20 世纪地面战数据**。

### 14.3 「训练是道德凝聚力的基础」——有争论，而且我引错了对立面

**du Picq（*Battle Studies*）的原论点**：**moral force 是军队力量中最强的元素**；他研究 Polybius 与 Caesar，认为罗马军团成功在于其组织与战术建立于「**对人心的深刻理解**」；强调**严酷的外部纪律必须由道德力量（含自尊）补充**；提出**凝聚力**（cohesion）——「逃跑是可耻的，因为士兵不再独自作战，而是军团的一部分」。

**van Wees 的强反证**：Hans van Wees, *Greek Warfare: Myths and Realities*（Duckworth, 2004），第三部分标题即「**Amateur Armies**」。

> p.89：**「集体操练与正式机动在前四世纪不存在」**
> 「是个人而非集体的锻炼，且大体取决于个人偏好，**不锻炼也不被非议**」
> p.112：纪律「**靠士兵之间的同侪性施加，而非通过精密的指挥链**」

**Lendon, *Soldiers and Ghosts*（Yale, 2005）**：①**批评「罗马铁纪律」这一被尊崇的理想，视其为约 16 世纪才形成的神话**；②主张罗马成功的关键是 **virtus 与 disciplina 之间的张力**；③**早期希腊人「拒斥训练的观念」**，因为史诗强调个人英雄式战斗。

> ⚠️ **修正**：**没有找到 Lendon 点名批评 du Picq 的文本。** Lendon 的批评是**间接的**（论证「铁纪律」是后世神话；早期希腊人拒斥训练）。**若设计依赖「Lendon vs du Picq」这一具体对立，需要回到 Lendon 原书核查。**

**Goldsworthy, *The Roman Army at War 100 BC–AD 200*（Oxford, 1996）** 的定性结论：罗马的相对优势在于「**纪律、对惩罚的恐惧与良好士气**」，**「道德因素远比物质因素更决定战斗进程」**（p.244）。**但全书没有量化训练→战斗力的转换率。**

> ⚠️ **另一处要打折的**：Goldsworthy 引用了 S. L. A. Marshall 的「只有 25% 士兵开火」，而**这一论断本身在学界有争议**。

## 十五、装备成本

### 15.1 希腊：现代估算与铭文实价差三倍

| 来源 | 全套价格 |
| --- | --- |
| **现代学者估算**（Hanson 1995；Jarva 1995） | **75–100 德拉克马**，约熟练工匠 **3–5 个月工资** |
| 前 6 世纪末萨拉米斯殖民者法令（要求自备） | **30 dr** |
| **刻俄斯（Ceos）铭文**（前 3 世纪初） | 盾 **20** + 盔 **6** + 矛 **2** ≈ **28 dr** |
| 塔索斯全套甲胄 | 300 dr |

> ⚠️ **75–100 dr 是现代估算，不是铭文原文。使用它时必须声明这一点。**
> van Wees 笔下典型重装兵是拥有 **4–6 公顷**土地、价值 **2000–3000 dr** 的小自耕农，「**刚刚够买得起**一套重装」。

**梭伦财产等级——「能装备多少人」最接近的量化：**

**zeugitai（第三等级）** = 能负担重装者，财产门槛 **200 medimnoi**。占比估计**分歧达 2–4 倍**：**10–20%**（Foxhall & van Wees 的精英解读）/ **约 15%** / **30–40%**（Valdés Guía）。

> **关键限定**：古典雅典存在一层**法律上是 thetes 但在经济上付得起重装**的「中间阶层」，约占 30%——所以**法律等级 ≠ 装备可负担性**。

### 15.3 罗马：基本无可靠原始数据

**2 世纪中叶军团兵年饷 300 denarii。** **Masada 薪条**（Gaius Messius，辅助兵）记 stipendium **50 denarii**，扣项：大麦钱 16、伙食 20(?)、靴 5、皮条 2、亚麻内袍 7——**「发薪日后实际一文不名」**。

**Pliny** 记一名被任命为百夫长者获 **40,000 nummi（10,000 denarii）** 用于装备——这是最接近「装备总价」的古代数字。

## 十六、行军、负重与战马

### 16.1 行军速度

| 来源 | 速度 |
| --- | --- |
| Vegetius 操典 | **20 罗马里（29.6 km）/ 5 个夏季小时**，负重约 20.5 kg（*gradus militaris*） |
| Vegetius 进阶 | **24 罗马里（35.5 km）**（*gradus plenus*） |
| **实际日行军** | **7–20 km/天**（依地形、道路、天气、有无辎重） |
| 无辎重（*expedita*） | 可达 30 km |
| 许多学者认为的实际 *iustum iter* | 约 **15–16 罗马里（12–13 英哩）** |
| **中国「师行三十里」** | 《汉书·陈汤传》「**轻行五十里，重行三十里**」；汉里约 400–419 m → **12–21 km/天** |
| 急行军 | 《后汉书·段颎传》「一日一夜二百余里」，但兵法警告「百里而争利」会致士卒掉队 |

> ⚠️ **Vegetius 自己承认 20 英里/5 小时「几乎无法连续多日维持」**；概率分析发现**极少有**将领达成他的标准。

### 16.2 负重的分歧极大

| 估算 | 数值 |
| --- | --- |
| Vegetius 推荐的**训练**负重 | 60 罗马磅（约 **19.6–20 kg**），**不含衣物与武器** |
| 现代实验估计**实战**负荷 | **18–25 kg** |
| 更重的估计 | **37–38 kg**，可达 45 kg |
| **Junkelmann 1985 实验** | 11 人全副公元 1 世纪军团装备，22 天从维罗纳走到奥格斯堡约 **540 km**；**武器甲胄 31.25 kg + 个人装备 13.65 kg ≈ 45 kg**，另加 3 日口粮约 4 kg |

> ⚠️ **负重数字的分歧幅度极大**，且各家对「是否含口粮、是否含共用工具、体型估算」的口径不一致。**Junkelmann 的 45 kg 是他自己重建装备的重量，未必等于历史实际。**

### 16.3 轻重装的机动差异——唯一有古代原文证据的一条

**修昔底德记 Sphacteria 之战**：**轻装部队「没有重装备，在崎岖难行的地面上能轻易甩开追击者」。**

**peltast 与 hoplite 的定义依据是队形角色而非装备绝对重量**——「是**以散兵队形作战**这一点使 peltast 成为轻步兵，**是以方阵队形列于战线上**这一点使 hoplite 成为重步兵」。**peltast 装备逐渐变重、hoplite 装备逐渐变轻的同时，这一区分依然成立。**

> ⚠️ **没有找到任何受控的「负荷—速度」对照研究。** 若要建量化模型，须自建，不能引用。

## 十七、查不到、有争议、未定的部分

### 明确查不到

1. **"溃退阶段伤亡占总伤亡的百分比"的任何量化数值。** 所有文献只做定性表述（"bulk""vast majority"）或给整场战役总数。
2. **狩猎采集社会"狩猎导致的受伤/死亡率"的量化数据**（每年 / 每千小时）。只有合并统计的"意外 + 暴力 ≈ 20% 死亡"。
3. **青铜剑 vs 铁剑的受控实验对比。** 实验考古只测了青铜剑本身。
4. **"伤亡 5%（或 10%）即溃"的学术出处。** 可能源于对 Krentz "胜方 5%" 的误读。唯一给出此类百分比的是一个中文通俗文章，**不可用**。
5. **任何给出"古代会战参战比例"通用数值的研究。** 只有修昔底德对斯巴达的一次性推算（1/8，且被学者视为推测）。
6. **把 Lanchester 定律用经过验证的参数应用于前火药时代的专门研究。** 只有需人工调参的工具，以及 Bongers & Torres 的温泉关案例。
7. **CK2 每个侧翼的单位数上限 / 兵力上限。** wiki 未记载任何硬性上限。
8. **「8:1」军民比（动员率约 11%）的出处。** 多轮定向检索（含精确短语）返回空结果。最接近的具名数字是 Rosenstein 的「212 BC 陆军 + 海军 < 11% 自由人口」。**不要把它当成有出处的事实使用。**
9. **跨文化的「动员率」系统数据集。** 不存在。概念有（Andreski 的 MPR），**数字零散且互相不可比**。
10. **训练程度对战斗力的量化效应（前现代）。** 不存在。Dupuy 的 CEV 是 20 世纪地面战数据。
11. **「装备重量 → 行军速度」的受控量化研究。** 不存在。所有数字都是不同来源的孤立并列，不是同一实验的不同负荷对照。**若要建量化模型须自建，不能引用。**
12. **「能装备多少人」的专门研究。** 不存在。最接近的是梭伦等级占比（**10–40% 的宽幅**），以及中国「披甲率 74%」（但那是**已入伍者**的比例，非人口比例）。
13. **骑兵成本的专门量化研究。** 不存在。成本分解（马价 + 饲料 + 备用马 + 马具马甲 + 随从）是算术组合，不是文献结论。
14. **罗马装备的可靠价格表。** 只有 Pliny 的百夫长 10,000 denarii 与 Masada 薪条两类硬数据；盔甲价格全部来自论坛估算且自相矛盾。
15. **Lendon 点名批评 du Picq 的文本。** **不存在。** Lendon 的批评是**间接的**（论证「铁纪律」是 16 世纪神话；早期希腊人拒斥训练）。**若设计依赖「Lendon vs du Picq」这一具体对立，须回原书核查。**

### 有争议

1. **前排是否轮替**：Sabin 的换班假说 vs "史料里从未描写过在交战中换班"。
2. **othismos（推挤）是否字面成立**：Hanson vs Krentz / van Wees；**超过 12–16 列推力饱和**的力学测算。
3. **前线宽度 ∝ √N vs 投入率 ∝ 1/N**：两条规律给出相反的尺度律，**未找到调和两者的研究**。

5. **古代战斗究竟是线性律还是平方律**：Johnson & MacKay vs 传统运筹学。
6. **Gabriel & Metz 的败方伤亡率**：一处转述说 **11%**，另一处说 **30–75%**，无法核实。
7. **CK2 的单位属性数值**：wiki 的 "Combat" 页表与 "Warfare guide" 页表**数值不同**——轻步兵士气 **2 vs 3**、轻骑兵士气 **3 vs 4**、弓骑兵士气 **5 vs 7**、弓箭手混战防御 **1 vs 2**。另有：每名阵亡者的士气伤害 **3 / 6 / 2.5** 三个互斥数字；溃退阈值 **25% vs 20%**；侧击加成 **+10% / +30% / +90%**。**均未解决，故本设计不采用其任何数值。**
8. **CK2 的阶段天数**：wiki 正文只说 "a few days"，**没有权威的硬编码天数**。

## 十八、设计取值标注

以下内容**是设计决定，不是文献结论**，必须与文献数字分开对待：

| 项 | 说明 |
| --- | --- |
| **把"战线宽度"的作用限定为"决定能否包抄"** | 方向来自 Bongers & Torres 的瓶颈模型与 Wagon Box Fight；**但"包抄 = 平方律"这个具体映射是设计取值**，文献只给出"瓶颈使数量优势失效"这一结果 |
| **包抄兵力 = min(我方人数 − 对方展开, 战线宽度 − 对方展开)** | 纯设计。文献给的是"瓶颈存在"与"被包抄者无法还击"的方向，**具体公式是设计取值** |
| **包抄的伤害不走分摊、直接打最外侧的翼** | 纯设计。文献只说"侧翼被攻击"，**没有给数学模型** |
| **正面取线性律（∝ N）** | 文献实测 α ≈ 1.29（介于线性与对数之间），**取线性是保守的简化**；Johnson & MacKay 主张袭击近似平方律，**统一取线性是设计取舍** |
| **"远程支援装备"作为单排 / 后排的分界** | 方向来自 Onasander（投射兵放正后方无效）；**把分界定在"射程差足够大"是设计取值** |
| **四个阶段（对射 / 近战 / 间歇 / 追击）** | 方向来自 Sabin 的脉冲模型（冲锋 + 间歇）与 CK2 的三阶段；**四阶段的划分与命名是设计取值** |
| **"间歇期士气恢复"** | 方向来自 Sabin 的 lull 与"重整"；**恢复量是设计取值** |
| **士气不从属于兵力** | 方向来自 Clark 1954（明确否定固定伤亡阈值）；**士气各来源的权重是设计取值** |
| **士气归零即溃退** | 纯设计。**文献里没有任何可靠的崩溃阈值**（Camp 的 20%/40% 都是兵棋惯例，且 Clark 1954 直接否定固定阈值） |
| **追击方的士气也会掉** | 方向来自 Geronium 一役（胜方怕被反击而克制追击）；**具体量是设计取值** |
| **"补位"操作（后排调前排）** | 纯设计。文献中"交战中换班"**没有可靠史料**，此处是作为游戏操作引入的 |
| **伤害按人数比例分摊、防御只减减员不减士气** | 沿用 CK2 的公式结构（**结构可借，数值不借**） |
| **最小单位为 1 个人** | 纯设计。CK2 的下限是数百人的部队，本设计把它降到个人 |
| **四种场景（狩猎 / 袭击 / 冲突 / 会战）共用一套规则** | 纯设计 |
| **铁降低装备成本、不进单兵战斗力** | 方向来自 Champion 1980 等（铁不优于青铜）；**"成本"这一维度的具体实现是设计取值** |
| **野兽没有士气** | 纯设计 |
| **各装备的攻击 / 防御 / 士气 / 阶段数值** | **全部是设计取值**，走配置表，不写进文档 |
| **「编户档位」这个概念** | 方向来自杜正勝（户籍与普遍征兵互为因果）与秦「初令男子书年」（登记深度递进）；**把登记深度做成 4 个可投资的档位，是设计取值** |
| **编户「1 年达到目标值」** | 纯设计。文献只说明登记是逐渐推进的，**没有任何收敛速度数据** |
| **动员率的上限与档位差距** | 文献给的量级是「常备 <1–2.5% vs 全面动员 8–11%」（Andreski MPR 的双峰结构）；**游戏里的具体百分比是设计取值** |
| **可动员兵力 = 动员率 × 可投入劳动人口** | 纯设计。文献里征兵对象是「成年男性」，而本游戏的分母是已有计量「可投入劳动人口」 |
| **可装备兵力 = 兵器库存 ÷ 每套所需** | 纯设计。文献**没有**「能装备多少人」的专门研究（最接近的是梭伦等级占比 10–40% 的宽幅） |
| **装备四类（武器 / 盔甲 / 弓箭 / 战马）** | 纯设计。文献里的分类更细，这里做了大幅归并 |
| **铁器降低每套资源消耗、不提升单兵战斗力** | 方向来自 Champion 1980（铁不优于青铜）；**"降成本"这一维度的具体实现是设计取值** |
| **训练度 = 0 起、补充兵摊薄** | 纯设计。**文献里没有训练→战斗力的效应量**（Dupuy 的 CEV 是 20 世纪数据） |
| **训练度主要作用于士气上限** | 方向来自 du Picq（道德力量主导）与 Goldsworthy（道德因素远重于物质）；**但 van Wees 与 Lendon 对这一传统构成反证**（前 4 世纪无集体操练、"铁纪律"是后世神话）。**权重是设计取值** |
| **攻防 = 技巧 + 装备两部分，远程不看防御技巧** | 纯设计 |
| **移动力 = 基础 + 战马加成 − 装备拖累** | 纯设计。文献有速度与负重的数字，**但没有「负荷—速度」的量化关系**（该对照研究不存在） |
| **战马提供「免罚上限」** | 纯设计 |
| **移动力决定侧翼攻击效率的爬升速度** | 纯设计。**没有文献依据**——"重装转向慢"是常识推理，不是查证结果 |
| **侧翼攻击效率从 0 爬到 100%** | 纯设计 |
| **三翼镜像、中翼有两个相邻翼** | 方向来自 CK2 的 3 侧翼结构与「侧翼找不到对手时去支援友方」；**"打崩当面后转入相邻翼、中翼可两边"是设计取值** |
| **「队」这个单位及其规模** | 纯设计 |
| **四类装备的三个数值（攻击 / 防御 / 移动力）** | **全部是设计取值**，走配置表 |
