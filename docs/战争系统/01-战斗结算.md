# 战争系统 · 战斗结算

**定位：** 定义一次战斗里玩家看到什么、能做什么、会发生什么。
**边界：** 不含文献依据、不含数值取值、不含界面方案。依据与推导另存。
**与战争潜力的分工：** 本文只写"打起来之后怎么结算"。攒兵、养兵、装备从哪来，写在战争潜力里。

**一句话：** **队决定你有多少战力，三翼的位置决定谁先被打崩，战线宽度决定谁能绕到外面。**

---

## 1. 这个系统管什么

**一次"打"的完整结算。** 它不管谁跟谁打、为什么打、打完能得到什么。

**它从第一个时代起就在用。** 组织一次狩猎，就是一次战斗：分队、接敌、减员、溃退，走的是同一套规则。

> **"战争"不是这个系统新增的东西。** 新增的只是规模与对手。

**四种场景用同一个结算器：**

| 场景 | 队的人数 | 对手 |
| --- | --- | --- |
| **狩猎** | 几人 | 野兽 |
| **袭击** | 几人到几十人 | 另一个群体 |
| **冲突** | 几十到几百人 | 邻邦 |
| **会战** | 几千到几万人 | 政权 |

---

## 2. 玩家看到的读数

| 读数 | 位置 | 值域 | 含义 |
| --- | --- | --- | --- |
| **队** | 每方若干 | — | 战斗的基本单位。**同一种装备 + 一定人数** |
| **人数** | 每队 | 整数，最小 1 | 这个队有多少人 |
| **装备** | 每队 | 武器 / 盔甲 / 弓箭 / 战马 | 决定攻击、防御、移动力、职能 |
| **位置** | 每队 | 左翼 / 中翼 / 右翼 | 玩家把队分配到三个位置 |
| **战线宽度** | 每场战斗一个 | 整数（人数） | **整条正面**最多能容纳多少人 |
| **士气** | 每方一条 | 0–100% | **归零即溃退**，与兵力是两条独立的线 |
| **阶段** | 每场战斗一个 | 对射 / 近战 / 间歇 / 追击 | 当前在打什么 |
| **侧翼攻击效率** | 每队一个 | 0–100% | **转入侧翼攻击后从 0 爬到 100%**，爬升速度由移动力决定 |
| **减员** | 每队 | 整数 | 这个队已经损失多少人 |

**九个读数全部可见。**

---

## 3. 玩家能做的操作

| 操作 | 时机 | 玩家做什么 | 会发生什么 |
| --- | --- | --- | --- |
| **分配位置** | 战前 | 把每个队放到左翼 / 中翼 / 右翼 | 决定它先和谁打 |
| **接战 / 撤退** | 随时 | 开始或退出战斗 | 撤退要走一次士气结算 |
| **调动** | 战中 | 把一个队从一个翼调到另一个翼 | **它在该翼重新从零爬侧翼攻击效率** |
| **追击 / 不追击** | 对方溃退后 | 选择追或不追 | 追击继续造成减员，但**追击方士气也会掉**（队形散） |

**「分配位置」是本系统里最重要的玩家决策**——同样的兵，放在中翼和放在侧翼，打的是完全不同的仗。

---

## 4. 队

**队是战斗的基本单位。它由两样东西定义：人数、装备。**

| | 说明 |
| --- | --- |
| **人数** | **最小可以是 1 个人**。狩猎小队是 3–5 人，会战里一个队可以有几万人 |
| **装备** | **一个队只能有一种装备**。混编必须拆成多个队 |

**为什么要拆队**：一个队只能有一种装备，所以**兵种搭配只能通过多队实现**。这是玩家在战前最主要的工作。

**队的规模有取舍：**

| | 好处 | 代价 |
| --- | --- | --- |
| **队大** | 承受打击时人多，不容易被打光 | 单一装备；士气是一整块，**崩起来一起崩** |
| **队小** | 可以搭配多种装备 | 每队都薄，容易被逐个打掉 |

---

## 5. 作战编队：左翼 / 中翼 / 右翼

**玩家把队分配到三个位置。两军面对面，你的左手边对的是对方的右手边。**

### 5.1 正面战（镜像）

```
我方左翼  ↔  对方右翼
我方中翼  ↔  对方中翼
我方右翼  ↔  对方左翼
```

**左打对方的右，是物理必然**——两军相向而立，你的左手边正对对方的右手边。

### 5.2 战线的容量

```
一方展开 = min(该方总人数, 战线宽度)
```

**整条正面最多容纳「战线宽度」这么多人。** 超出的部分是**余量**，见第 7 节。

**战线宽度由地形决定：**

| 地形 | 战线宽度 |
| --- | --- |
| 平原、开阔地 | 大 |
| 丘陵、林地 | 中 |
| **山地、关隘、渡口、桥** | **极小** |

### 5.3 阵型：单排 → 后排

| 时期 | 阵型 | 规则 |
| --- | --- | --- |
| **远程支援装备出现之前** | **单排** | 所有队在同一条线上，**全部承受伤害**。投射队也在线上 |
| **远程支援装备出现之后** | **前排 + 后排** | 远程支援队放**后排**，**不承受近战伤害** |

**为什么早期没有后排**：早期的投射装备（投矛、弓箭）与近战装备的**距离差不够大**——放到近战兵正后方，投射物只能高抛，下坠时已经没有杀伤力，**放在后面等于不参战**。

**后排成立的条件是射程差足够大。**

---

## 6. 打崩当面 → 转入相邻翼

**每个翼先打自己的当面。把当面打崩之后，自动转入相邻的翼。**

```
侧翼：只有【一个】相邻翼
      我方左翼打崩对方右翼后  →  转入对方中翼
      我方右翼打崩对方左翼后  →  转入对方中翼

中翼：有【两个】相邻翼
      我方中翼打崩对方中翼后  →  可以同时攻击对方左翼与右翼
```

**中翼是全场的杠杆**——它在中间，两边都够得着。**这就是"中路可以同时攻击对方左右侧翼"的机制。**

---

## 7. 侧翼攻击效率

**一支队打崩当面之后，要转向去打旁边那个翼——而转向要时间。**

```
侧翼攻击效率：
    刚转入侧翼攻击时  = 0
    随时间爬到        = 100%
    爬升速度由【移动力】决定

侧翼攻击的实际伤害 = 正常伤害 × 侧翼攻击效率
```

**重甲的后果**：打崩当面之后，**有很长一段时间打不出全力**。它突破得动，但**扩大不了战果**。

**轻装的后果**：突破之后马上就能追杀。

**这是移动力最重要的作用。**

---

## 8. 包抄（从外面绕）

**第 6 节的"转翼"是从内部撕开；包抄是从外面绕过。**

```
对方展开 = min(对方总人数, 战线宽度)

若 对方展开 < 战线宽度   →  对方没填满，它的两端是空的
                            我方余量可以绕过去
若 对方展开 = 战线宽度   →  对方的线封满了，绕不过去
```

**包抄兵力 = min(我方余量, 战线宽度 − 对方展开)**

**包抄的效果**：从对方**最外侧的翼**外面打进去，**该翼无法还击**，且**该方士气下降加速**。

**为什么战线宽度重要**:它不限制你参战多少人，**它决定对方能不能绕到你背后**。

**狭窄地形的后果**：对方人少也能填满战线（因为宽度小）→ **你人再多也绕不过去** → 数量优势被地形抹平。

## 9. 战斗阶段

**接触是间歇的，不是持续的。**

| 阶段 | 谁输出 | 特征 |
| --- | --- | --- |
| **对射** | 投射职能 | 减员小，士气缓慢消耗 |
| **近战** | 近战职能 | **减员集中在这里** |
| **间歇** | 投射职能（弱） | **士气小幅恢复**——重整 |
| ↻ 三者交替，直到一方士气归零 | | |
| **追击** | 追击值高的一方 | **溃退方不还手** |

**阶段长度由双方装备与士气差决定**，不是固定的天数。

---

## 10. 结算

**每个阶段结算一次。**

```
本阶段总伤害 = Σ (各队人数 × 该队本阶段攻击力)

某队承受 = 受方总伤害 × (该队人数 / 该翼总人数)
该队减员 = 系数 × (该队承受伤害 / 该队防御力)
```

**四条要记住的：**

1. **伤害在翼内按人数比例分摊。** 该翼里占两成的人数，就承受两成的伤害。
2. **进攻方向由第 5–6 节决定**——先打当面，打崩后转相邻翼。
3. **防御只减减员，不减士气。** 高防御的队活得久，但挡不住士气崩。
4. **全是比例运算**——两边同乘 1000 倍，结果完全一样。**这是本系统能同时支持几人小队与几万人会战的原因。**

**包抄兵力造成的伤害不走分摊：它直接打对方最外侧的翼，且对方无法还击。**

## 11. 士气与溃退

**士气是一条独立的线，不是兵力的从属量。**

| 士气下降 | 士气恢复 |
| --- | --- |
| 减员 | **间歇期重整** |
| **被包抄** | 预备队投入（还有队没上场） |
| **侧翼被突破** | 我方投射火力占优 |
| 对方战斗力超出预期 | |
| 持续疲劳（阶段数累积） | |

**士气上限由训练度决定**（见战争潜力）——**训练度低的部队，士气封顶就低。**

**士气归零 → 溃退。**

### 溃退之后

| | 规则 |
| --- | --- |
| 溃退方 | **不还击**，单纯承受减员 |
| 追击方 | 按**追击值**造成减员；**自己的士气也会掉**（队形散） |
| **追击值普遍低于近战值** | **每次打的不多**——但溃退方一直不还手，时间一长总数就上去了 |
| 例外 | **骑兵的追击值高** |
| 追击持续 | 直到溃退方脱离，或追击方士气也归零（反被打散） |

**所以"要不要追"是一个真实的选择**——追得狠能把对方打残，但追过头自己的队形会散。

---

## 12. 乐趣产生在五个位置

1. **战队与分配位置**——同样的兵，放中翼还是放侧翼，打的是完全不同的仗。
2. **看出对方会不会被包抄**——战线宽度是看得见的，"这一仗能不能绕过去"是**算得出来的**。
3. **用重甲突破、看它追不动**——突破与扩大战果是两件事，重甲只能做前一件。
4. **要不要追**——追得狠与队形散是一对真实取舍。
5. **以少胜多**——狭窄地形下数量优势被抹平，**地形本身就是一种战力**。

---

## 13. 这个系统不该有的

**系统上不存在的东西：**

- **远程支援装备出现之前的后排。** 单排制下，投射队也在线上挨打。
- **玩家在战斗中直接指挥单个队走位。** 战场空间不建模。
- **战斗中的临时变阵**（除了「调动」这一种）。

**属于后续内容的：**

- **补给、运力、就地取粮、军队规模的软上限**——这是独立的大内容，本次不做。**本系统只结算战斗，不结算军队怎么活到战场。**

**针对本系统的五条禁令：**

- **不得让战线宽度变成"限制参战人数"的上限。** 它的作用只有一个：**决定对方能不能包抄**。
- **不得让兵力成为压倒性因素。** 正面取**线性**（人数翻倍，战力翻倍），**只有包抄产生平方效应**。
- **不得让士气从属于兵力。** 减员只是它众多来源之一。
- **不得让侧翼攻击效率立刻到位。** 转向一定要时间，**且重甲要更久**。
- **不得让追击变成划算的收割。** 追击值普遍低，且**追击方自己的士气也要掉**。

---

## 14. 验收要点

1. 玩家能**看见战线宽度**，并据此判断"这一仗能不能包抄"。
2. 玩家能亲手造出**以少胜多**——靠地形把对方的数量优势抹平。
3. 玩家能感受到**被包抄的代价**——最外侧的翼挨打还不了手，士气掉得明显更快。
4. 玩家能观察到**打崩当面之后不是立刻赢**——还要爬侧翼攻击效率。
5. 玩家能看出**重甲突破得动、但扩大不了战果**。
6. 玩家能感知**士气是独立的一条线**——有时人还很多，但士气先崩了。
7. 玩家在"追击"上**面对真实取舍**。
8. 玩家能看出**狩猎与会战走的是同一套规则**，只是规模不同。
