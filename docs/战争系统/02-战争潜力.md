# 战争系统 · 战争潜力

**定位：** 定义玩家怎么攒出能打的兵、怎么养得起、装备从哪来。
**边界：** 不含文献依据、不含数值取值、不含界面方案。依据与推导另存。
**与战斗结算的分工：** 本文写"打之前"。打起来之后怎么结算，写在战斗结算里。

**一句话：** **你能动员多少，取决于你养得起多少；而你养得起多少，取决于你没把人抽走多少。**

---

## 1. 这个系统管什么

**一个国家能拿出多少兵力、这些兵力有多能打、以及养它们要付出什么。**

**它从第一个时代起就在用，只是参数很低。**

| | 编户齐民之前 | 编户齐民之后 |
| --- | --- | --- |
| 动员率由什么决定 | **村落凝聚力**（人们愿不愿意跟你走） | **可以刻意抬高** |
| 能动的兵 | 少 | 多 |

> **本系统新增的不是"有兵"，是"能把动员率刻意抬上去"。**

**它管两个上限：**

```
可动员兵力（人）  ┐
                  ├→ 实际能凑出的兵力 = min(两者)
可装备兵力（装备）┘
```

---

## 2. 玩家看到的读数

| 读数 | 位置 | 值域 | 含义 |
| --- | --- | --- | --- |
| **基础动员率** | 每区块 | 0–100% | **由该区块的村落凝聚力决定。** 没有编户时的动员率 |
| **目标动员率** | 每区块 | 0–100% | 当前编户档位所指向的值 |
| **当前动员率** | 每区块 | 0–100% | **随时间向目标靠拢的那一个** |
| **可动员兵力** | 每区块 | 整数 | `当前动员率 × 可投入劳动人口` |
| **可装备兵力** | 全局 | 整数 | `兵器库存 ÷ 每个士兵所需装备量` |
| **兵器库存** | 全局 | 按类型分组 | 各类装备的存量 |
| **队** | 每区块若干 | — | 征召出来的兵，**同装备 + 人数不多** |
| **训练度** | 每队 | 0–100% | 新征募的为 0，**补充兵会摊薄** |
| **移动力** | 每队 | 数值 | 由装备与战马决定，**影响行进与侧翼攻击效率** |
| **每期粮草** | 每队 | 数值 | 维持这支队要吃掉多少粮食 |

**九个读数全部可见。**

---

## 3. 玩家能做的操作

| 操作 | 粒度 | 消耗 | 结果 |
| --- | --- | --- | --- |
| **设编户档位** | 每区块 | **粮食（持续）** | 抬高目标动员率 |
| **征召** | 每区块 | **兵器库存 + 占用可投入劳动人口** | 生成或补充队；**训练度摊薄** |
| **训练** | 每队 | **额外粮食（持续）** | 训练度上升 |
| **生产兵器** | 全局 | 资源 | 兵器库存上升 |
| **调动** | 每队 | 移动力决定耗时 | 队在主区块之间移动 |
| **解散** | 每队 | — | 人回到可投入劳动人口，装备回库存 |

**六个操作全部手动，全部有代价。**

---

## 4. 编户齐民

**一个持续投入的政策。它只做一件事：设定目标动员率。**

| 档位 | 目标动员率 | 每期粮食 |
| --- | --- | --- |
| **未编户** | **基础动员率** | 0 |
| **低** | 基础 + 一档 | 小 |
| **中** | 基础 + 二档 | 中 |
| **高** | 基础 + 三档 | 大 |

**每区块单独设档位。**

### 滞后是有意设计的

```
每期：当前动员率 +=（目标动员率 − 当前动员率）× 收敛速度
收敛速度按「1 年到位」取值
```

- **升档：从点击到到位约 1 年**——临战才点高档位来不及。
- **降档：同样有滞后**——停供粮食后，动员率是**慢慢掉回去**的，不会瞬间归零。

### 基础动员率

```
基础动员率 = f(村落凝聚力)
```

**凝聚力高 → 人们愿意跟你走 → 基础动员率高。**

**这直接复用已有计量，不新增读数。** 而且它自带一个反向作用：

**征召会压低凝聚力 → 基础动员率跟着掉。** 所以**即使不编户，动员也是有代价的。**

---

## 5. 可动员兵力

```
可动员兵力 = 当前动员率 × 可投入劳动人口
```

**分母是「可投入劳动人口」，不是总人口。**

**所以征召会咬自己**：

```
征召 100 人  →  可投入劳动人口 −100  →  下期的可动员兵力也少了 100
                              ↓
                        产出下降  →  粮食下降  →  编户供不起  →  目标动员率掉回去
```

**征召会吃掉自己未来的兵源。**

---

## 6. 装备与可装备兵力

### 6.1 兵器库存

| | |
| --- | --- |
| **四类** | **武器 / 盔甲 / 弓箭 / 战马** |
| **每类可以有材质** | 例：皮质盔甲、铁质盔甲；青铜武器、铁质武器 |
| **每件三个数值** | **攻击 / 防御 / 移动力** |
| **生产** | 由建筑产出，消耗资源 |

### 6.2 可装备兵力

```
可装备兵力 = 兵器库存 ÷ 每个士兵所需装备量
```

### 6.3 铁器在这里落地

**铁器降低每套装备的资源消耗**——同样的产能，产出**更多套**。

> **铁器不提升单兵战斗力**，它抬高的是**能装备多少人**。
> 这一条决定了铁在游戏里的位置：它不是战斗力加成，是**上限**。

**所以国家战争潜力被两个方向夹住：**

```
人不够      →  可动员兵力 是瓶颈
装备不够    →  可装备兵力 是瓶颈
```

---

## 7. 队

**征召出来的兵，按「同装备 + 人数不多」编成队。**

| | |
| --- | --- |
| **定义** | **同一种装备 + 一定人数。** 战争系统的基本单位 |
| **一个区块可以有多支** | 不同队可以是不同装备 |
| **与战斗结算的关系** | **队就是战斗里的基本单位**——战前把它们分配到左翼 / 中翼 / 右翼 |

**队是战略层与战术层之间唯一的接口。**

---

## 8. 训练度

| | |
| --- | --- |
| **每队一个训练度** | 0–100% |
| **新征募的士兵** | **训练度 = 0** |
| **摊薄** | `部队训练度 = Σ(各批次训练度 × 该批次人数) ÷ 该队总人数` |
| **训练** | 额外消耗粮食 → 训练度上升 |

### 8.1 摊薄的后果

一支打了半年、训练度 80% 的老队，补进 1,000 新兵后整体掉到 40%。

**技巧加成一腰斩，士气上限一腰斩。** 补充兵会稀释战力。

### 8.2 训练度作用在两处

**① 士气上限**（主要作用）——训练度低的队，士气封顶就低。

**② 攻防里的「技巧」部分：**

```
技巧 = f(训练度)
        训练度 0   →  技巧 = 0
        训练度 100 →  技巧 = 满

攻击力 = 技巧 × 武器技巧系数 + 武器攻击值
防御力 = 技巧 × 护具技巧系数 + 护具防御值
```

**系数由装备类型决定——这就是"不同装备两部分不一样"：**

| 单位类型 | 武器技巧系数 | 护具技巧系数 |
| --- | --- | --- |
| **近战** | 中 | **> 0**（会格挡、会护住要害） |
| **远程** | 中 | **= 0**（**只看防御装备**） |

**远程不看防御技巧**——一个未训练的弓手和一个老兵弓手，**生存力一样，差别全在输出上**。

---

## 9. 移动力

**装备的第三个数值。**

```
基础移动力  =  部队的底子
战马加成    =  提高移动力，并提供【免罚上限】
装备拖累    =  max( 0, 装备的移动力惩罚 − 战马免罚上限 )

部队移动力  =  基础移动力 + 战马加成 − 装备拖累
```

**战马的作用落在那个 `max(0, ...)` 里**——有马，重甲不拖累移动力；没马，重甲全额拖累。

**移动力影响两件事：**

| 影响 | 怎么影响 |
| --- | --- |
| **战略层行进** | 部队在主区块之间移动要多久 |
| **侧翼攻击效率的爬升速度** | **重甲慢 → 打崩当面之后很久打不出全力** |

## 10. 完整链条

```
粮食 ─→ 编户齐民（每区块，4 档）─→ 目标动员率
                                      ↓ 1 年收敛
                                  当前动员率
                                      ×
                              可投入劳动人口
                                      ↓
                                 可动员兵力 ──┐
                                              ├→ min ─→ 征召
 兵器产能 ─→ 兵器库存 ÷ 每套所需 ─→ 可装备兵力 ┘         ↓
                                                     队（同装备）
                                                       ├ 训练度 → 技巧 + 士气上限
                                                       └ 装备   → 攻防数值 + 移动力
                                                              ↓
                                                    分配到 左翼 / 中翼 / 右翼
```

**三条持续消耗**：编户的粮食、队的粮草维持、训练的额外粮食。

**一个反馈**：征召 → 劳动人口下降 → 产出下降 → 粮食下降 → 编户供不起。

## 11. 核心张力

> **你能动员多少，取决于你养得起多少；而你养得起多少，取决于你没把人抽走多少。**

三个环咬在一起：

```
抬高编户档位 → 粮食每期扣 → 动员率慢慢爬 → 可动员兵力涨
                 ↓
             征召 → 兵器库存扣 + 劳动人口扣 → 产出下降 → 粮食更紧
                 ↓
             队养着 → 每期粮草 → 粮紧就得降档位 → 动员率掉回去
```

**加上装备那一侧：**

```
铁器 → 每套兵器更省 → 同样的产能装备更多人 → 可装备兵力上限抬高
```

**所以战争潜力被「人」和「装备」两个方向夹住，而「粮食」是把两者连起来的约束。**

---

## 12. 这个系统不该有的

**系统上不存在的东西：**

- **不花粮食的编户。** 持续投入是它的定义。
- **瞬间到位的动员。** 收敛有滞后，升和降都有。
- **不需要装备的兵。** 没有兵器库存，可动员兵力只是纸面数字。
- **不摊薄的补充兵。** 新兵训练度是 0，一定会拉低整体。

**属于后续内容的：**

- **完整后勤**——运力、就地取粮、距离衰减、军队规模的软上限。**本系统只做"维持"（每期粮草），不做"投送"。**

**针对本系统的五条禁令：**

- **不得让编户免费。** 每期扣粮食。
- **不得让动员率瞬间到位。** 1 年收敛是有意的滞后。
- **不得让征召不消耗可投入劳动人口。** 否则"咬自己"的反馈就没了。
- **不得让装备免费。** 可装备兵力必须是真上限。
- **不得让训练度只涨不跌。** 补充兵一定摊薄。

---

## 13. 验收要点

1. 玩家能看见**两个上限**——有时人多装备少，有时装备多人少。
2. 玩家能感受到**编户的滞后**——临战才点高档位来不及。
3. 玩家能感受到**征召的代价**——抽走人之后产出掉了、粮紧了。
4. 玩家能看出**铁器抬高的是上限，不是战力**。
5. 玩家能观察到**补充兵稀释战力**——老兵队补新兵后战力明显下降。
6. 玩家能感受到**养兵是负担**——队越多，每期粮草越重。
7. 玩家在"抬多高"上**始终面对取舍**——动员率越高，粮食越紧，凝聚力越低。
