# era 05 · 游玩核心：青铜与铁器时代

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、节点清单、界面方案。**不定义任何一条政治线的机制**——机制以该线自己的设定为准，本文只写本时代用它们做什么。阅读可脱离其他文档。

**一句话：** 你发现邻居比你强，而变强这件事第一次有了一个你能亲手推动的旋钮。

---

## 1. 时代的叠加原则

> **时代推进是叠加，不是替换。**

```
本时代 = 已有机制的全集 + 一条新增机制
```

- 新增的那条线**更陡、上限更高**。
- 旧的机制**一直可用，上限不变**。本时代仍然可以采集、狩猎、整体迁徙、裂变。
- 玩家的行为变化来自"新线更划算"，不是旧能力被拿走。

**解锁是扩菜单，不是替换。** 委派没有取代直辖；编户没有取代征发。

**倒退通过失传发生，不通过时代回退。** 时代标签与能力框架保留。崩溃表现为人口崩塌、区块独立、部分技能与匠人失传、已编户区块的登记丢失；**政治线经验不清零**——制度是学会了就不会忘的东西。

只有文明整体灭绝时本局才结束。**时代标签不退。**

---

## 2. 第一次出现的东西：内涵增长，而且路不止一条

era 04 有一面墙：**邻近度撑不住的地方，你拿不到**。

在本时代之前，**变强只有一条路——多占地方**。那是外延增长：上限就是你有多少区块。

**本时代第一次出现第二条路：同样一片地，能产出的力量可以差出一个数量级。** 因为制度和动员方式不同——权力能不能伸到邻区、人能不能被登记在册、兵器能不能便宜到人人有份。

**而且本时代第一次，通往国力的路不止一条。** 前四个时代每个只有一条新线；本时代有**六条**，它们抢同一批资源，而且互相拆台。

> **历史参照：** Taagepera 把帝国规模的**三次跃升**定位在约 2800 BC（城市出现）、**约 600 BC**、1600 AD，并把中间那次称为「**power delegation breakthrough**」——**授权**。规模的突破来自"能派人去管"，不来自走得更快。

---

## 3. 独有体验：国力第一次是一个你能亲手推动的数字

同一个动作，四个时代四种结果：

| 时代 | 想变强，你能做什么 |
| --- | --- |
| era 03 | 在同一块地上等它慢慢长 |
| era 04 | 多分出去一个聚落——**更多的地** |
| **era 05** | **改造你自己**——换一种管法、把户籍铺下去、让兵器便宜下来 |

**而且你会先撞到墙上：一开始你的国力跟邻国差得很远。** 这个差距是你进入本时代时拿到的初始条件，也是整个时代的驱动力。

## 4. 本时代的成长线

**这是项目里第一个「多条成长线」的时代。**

**本时代只有一个目标——扩张国力。通往这个目标的路有六条**，玩家不必每条都走，但**每走一条都要付出别的线要用的东西**。

| # | 成长线 | 玩家在推动什么 | 推动它要付出什么 |
| --- | --- | --- | --- |
| 1 | **拓展统治的地方** | 把权力铺到邻近度之外 | 该区块凝聚力**随任期持续下降**，迟早变成新的权力中心 |
| 2 | **强化对已占领地的统治力** | 一块地**产多少**、其中**多少到你手上** | 粮食（收买）、期数（修路、建生产建筑）、兵（派驻） |
| 3 | **加强军事征兵能力** | 抬高动员率、征召、训练 | 咬掉劳动人口——**征召的就是种粮的那批人** |
| 4 | **军事装备：自己研发、自己打造** | 让兵器库存涨起来、让每套更便宜 | 铁矿、工匠、粮食，以及**有些技术只能自己攻** |
| 5 | **政治改革** | 换资格标准、换管法 | **既得利益者的叛乱**——失败教你统治 |
| 6 | **促进市场发展** | 让交换从村落之间长成市镇与商路 | 人口与粮食流向非农；**商人坐大后中央更难控制** |

六条线各自挂在不同的系统上。本文只写它们在本时代**各自推动什么、代价是什么、以及怎么互相拆台**；机制定义以各自的系统为准。

### 4.1 有三条线贯穿始终，不是本时代独有

**线 2、线 3、线 4 在后续时代都还在跑。**

**「贯穿始终」不等于「不属于这个时代」——它两样都是。** 它是本时代的一条成长线，同时也是所有时代的地基。

| 线 | 为什么贯穿始终 |
| --- | --- |
| **2 强化统治** | 每个时代都要回答"这块地产多少、给我多少" |
| **3 征兵** | 每个时代都要回答"我能点出多少人" |
| **4 装备** | 每个时代都要回答"这些人拿什么打仗" |

**它们在本时代有本时代的形态**——青铜到铁器的装备、村落规模的动员、委派制下的统治——**但杠杆本身不随时代改变**。

### 4.2 线 3 和线 4 是一对：人和物

**它们是战争潜力的两个上限，缺一个都打不了仗。**

- **线 3 管人**：可动员兵力 = 当前动员率 × 可投入劳动人口
- **线 4 管物**：可装备兵力 = 兵器库存 ÷ 每个士兵所需装备量

**实际能上战场的 = 两者取小。** 人够了没装备不行，装备堆着没人拿也不行。

**所以这两条线天然互相拉扯**：都吃粮食，而粮食是同一批人种的。**扩军和扩产抢的是同一口锅。**

**线 4 里有一半是"买不来"的**：市场能买到稀缺的成品，**但买不到你还没掌握的技术**。渗碳、淬火、高炉——**有些技术只能自己研发打造**，这半边不依赖市场也能成立。

### 4.3 为什么必须一起看

**单独推任何一条都会撞墙：**

- **只有 1（拓展）**：铺出去的是空架子——你叫不出兵，也收不上东西。
- **只有 3（征兵）**：你能点出很多人，但只能点到你走得到的地方；而且他们没有装备。
- **只有 4（装备）**：兵器堆在库里，而你没有足够的人去拿。
- **只有 5（改革）**：制度换了，但换来的能力没有地方用。
- **只有 2（统治）**：地盘稳，但你永远停在原地，而邻国在长。

**六条一起推，你才第一次能把一片网络变成一支军队。**

### 4.4 它们抢的是同一批东西

**粮食、人口、期数——六条线全都要吃这三样。**

- 征兵咬劳动人口 → 种粮的人少了 → 下一轮谁都推不动
- 造装备要铁矿、工匠、粮食 → 又是同一批人
- 打仗要粮 → 改革和修路的粮就没了
- 修路、开垦、建生产建筑也要期数和粮

**这是本时代最实在的压力：不是"要不要发展"，是"先发展哪一条"。**

**而它们的下限比上限更狠**——哪条线掉得太低，都会先把你拖垮：地盘掉了没产出，凝聚力掉了要独立，动员率掉了打不过，装备跟不上打不赢，改革停滞则所有线的解锁都停。

## 5. 核心张力

**两层。第一层是六条线之间的，第二层是其中两条线之间的——第二层更狠。**

### 5.1 六条路抢同一批东西

> **六条线都能扩张国力，但它们和底下的基础系统吃的是同一批粮食、同一批人、同一个期数，而且互相拆台。**
>
> 放权去拓展，已占地的统治力就掉；征召去打仗，种粮的人就没了；搞政治改革，既得利益者就反；压住叛乱，就没有余粮去修路、开垦、建生产建筑。

**所以本时代真正的决策不是"要不要发展"，是"先发展哪一条、放弃哪一条"。** 而且六条线**各有下限**——哪条掉得太低，都会先把你拖垮。

### 5.2 其中两条之间那条解不掉的

> **动员要求集权，扩张产生分权。**
>
> 你要打赢邻居，就得把人登记在册、把权力收上来；但你越成功、地盘越大，越只能放权去管——**而你放出去的人正在变成新的邻居。**
>
> **你为打赢而集中起来的力量，会因为打赢而散掉。**

这一条**没有最优解**——集权和放权各有代价，玩家只能平衡。这是本时代唯一一处"无论怎么点都会疼"的地方。

| | 收益 | 代价 |
| --- | --- | --- |
| **放权（1 拓展统治的地方往前走）** | 权力越过邻近度的墙；拿到远处的资源与人 | 该区块凝聚力**随任期持续下降**；迟早变成新的权力中心 |
| **集权（3 加强军事征兵能力往前走）** | 人可以被点出来；战力标尺往上抬 | 咬掉劳动人口；粮少；下一轮更征不动 |

**形式化：** Boulding 1962 的 Loss of Strength Gradient——**控制每单位面积的总成本随半径增长**。

**历史形状：** 周代分封从春秋初的 **148 国**收敛到战国的 **7 雄**；罗马行省从 1 个涨到 **~100 个**。

## 6. 核心循环

**三层同时转：外层的竞争压力、内层的六线分粮、以及那两条互相拆台的主线。**

```
最外层：邻国的攻击与战力标尺
        ↓  你打不过，必须改革 —— 但改革不止一条路

六条线分配同一批粮食、人口、期数
  1 拓展统治  2 强化统治  3 征兵  4 军事装备  5 政治改革  6 市场
        ↓  每条都有下限，哪条掉太低先把你拖垮
     总国力上升 → 战力标尺追上去
        ↓
主循环：打得赢 → 占地 → 地盘变大
        ↓
     地盘变大 → 只能放权去管（1 → 分权）
        ↓
     代理人坐大 → 诸侯化 → 你的一部分变成新的邻国
        ↓                                      （3 → 逼你集权）
     回到最外层 —— 而新的邻国比旧的强，因为它是你养出来的
```

**正反馈**：多管一块地 → 更多上缴 → 养更多人口与常备暴力 → 能管更远
**刹车**：任期 → 村落凝聚力 → 叛乱值 → 独立；征召 → 劳动人口 → 粮 → 征不动；**六条线互相抢粮**

### 慢变量与中间可见态

| 慢变量 | 中间可见态 |
| --- | --- |
| **六条线各自的位置** | 每条都有可读的深度——玩家能看出自己偏在了哪一条上 |
| **政治线经验** | 条在涨；**出事的时候会跳一截**——玩家能看出"这次叛乱买到了什么" |
| **村落凝聚力** | 每区块一条。**会随委派者的任期持续往下走**；**它同时决定你从这块地拿到多少** |
| **上交比例** | 每区块一条。**凝聚力往下走的时候，它跟着掉**——玩家能看见"这块地还在产，但我拿得越来越少" |
| **叛乱值** | 每区块一条。涨的时候**同时把该区块的产出折掉** |
| **统治方式** | 地图上能直接看出哪块直辖、哪块委派——**同一个网络里可以有多种管法** |
| **当前动员率** | 每区块一条。**它会滞后于目标值**——玩家能看出"改革还没落地" |
| **邻国战力** | 每邻国一个数。**它一直在涨**——玩家能看出窗口在关 |
| **支配比例** | 全局一条。**自己支配的区块 ÷ 地图总大小。** 过线之前它只是个读数，过线之后它会启动下面那条 |
| **帝业** | 全局一条，0–100。**本时代的终点。** 支配比例在线上就涨、掉线下就减——**玩家能看着它涨，也能看着它掉回去** |

### 乐趣产生在七个位置

1. **国力这个数字第一次能被你自己推动**——改革按钮按下去，标尺真的往上走。
2. **六条路里挑哪一条**——同一个目标有多条路径，每一次分配都是一次取舍。
3. **追赶一个不断往前跑的邻国标尺**——不是静态的强弱对比，是竞速。
4. **在叛乱值涨满之前压下去**——粮食收买、调政策、修路、派驻军队，各有代价。
5. **看着自己放出去的诸侯变成对手**——压力有一部分是自己造的，而这能被看见。
6. **每一次解锁都是被上一次的麻烦逼出来的**——玩家会亲身经历"制度是长出来的，不是设计出来的"。
7. **帝业条开始动之后，守住它**——它涨得慢、掉得快，而**刚够线的那一段最危险**。

## 7. 邻国：本时代的压力源

**没有邻国，这个时代的张力不成立。** 六条线各自都有代价，如果外面没有人在追你，玩家没有理由付出那些代价。

**邻国不是第二个模拟。** 它的国力是**算出来的**，不是经营出来的：

- 按它占的地盘，乘一个预置的系数（不同邻国有强弱之分，系数不同），**直接得出兵力和粮草**。
- **随时间成长**。成长由它的地盘和系数决定，玩家不参与。
- **它什么时候动手，走配置。**

### 7.1 它的攻击没有任何特殊规则

**邻国打你，就是一支队伍打过来——和玩家调动部队攻击，走的是完全同一套规则。**

**没有预警，也没有"劫掠"这种特殊表单。** 它出现在你的边境上，然后战斗结算开始。

打完之后，那块地受到和任何一块被打的地**一样的损害**——凝聚力跌、建筑损、人口掉。**这是「一块地被打」的通用后果，不是为邻国特设的。**

### 7.2 你打它，也不是灭国

**打邻国是占领它的地区，不是把它抹掉。** 对方的其余地区照旧存在、照旧在发展。

**占领是战争系统的通用行为：打下来是一瞬间，拿住是很多期。** 刚占的地区凝聚力极低、产出接近零、维持成本照付，要靠投入治理逐步消化。

**而且占领有上限——上限是你的消化能力，不是你的军队。**

> **一次占太多地区，产出还没回来，成本已经压上来。** 这条正是本时代扩张的天然刹车：**你能打下来多少，和你养得起多少，是两个数。**

### 7.3 由此产生的三种压力

1. **它是标尺，不是威胁。** 你不想打就永远不打——但你也永远拿不下它的地，而它在长。**机会窗口在关闭。**
2. **它会打你。** 你不能不管——边境地区的凝聚力会一路掉，掉到独立。
3. **你放出去的诸侯会变成新的邻国。** 这是本时代最狠的一条：**压力有一部分是你自己造出来的。**

**第一步只做这些**：邻国按地盘给数值、随时间成长、按配置动手。**不做外交，邻国之间不互相打**——那些留到后续细化。

## 8. 本时代玩家在操作什么

**按六条成长线排。** 每条线的操作细节以它自己挂的系统为准，本表只列玩家实际在动的东西。

| 类别 | 玩家在动什么 |
| --- | --- |
| **1 拓展统治的地方** | **每区块设统治方式**（直辖 → 委派 → 任期制度 → 分封 → 郡县）、**设任期长度 / 换代理人**、**收上缴** |
| **2 强化对已占领地的统治力** | **粮食收买人心**、**修路**提高邻近度、**派驻军队镇压**、**切换统治方式**、**建生产建筑**、**提科技** |
| **3 加强军事征兵能力** | **编户齐民**抬高目标动员率、**征召**、**训练**（新兵会摊薄训练度） |
| **4 军事装备：自己研发、自己打造** | **造兵器**——铁压低每套装备的资源消耗；**研发冶金技术**（有些技术只能自己攻） |
| **5 政治改革** | 沿政治线解锁与切换条目、换资格标准 |
| **6 促进市场发展** | 开市集、修商路、铸币、与邻国通商；**收税**；**用钱买到稀缺的军事产品** |
| **（共用）防守边境** | 应对邻国的攻击。**走统一的战争系统** |

**外加沿用 era 01–04 的全部系统**，规则不变：

| 系统 | 在本时代的形态 |
| --- | --- |
| **任务 / 人口 / 成年存活率 / 教育值** | 规则不变 |
| **科技节点与图鉴** | 规则不变 |
| **临近度与道路** | 规则不变；**修路现在是压叛乱的手段之一** |
| **村落凝聚力** | 规则不变；**新增"委派任期"这一下降来源** |
| **叛乱值与独立** | **就是 era 04 那一条**，规则不变。**独立出去的区块在本时代变成邻国** |
| **选育与抗性** | 规则不变，不清零 |

## 9. 这个时代不该有的

**系统上不存在的东西：**

- **一个能长期维持的帝国。** 本时代可以**创建**帝国——那是它的出口——但维持它是下一个时代的事。
- **成文法典。** 本时代有文字与会计，但没有法典。

**属于后续时代的：**

- 火药与火器、印刷、远洋航行、机械动力
- 化学农药——一直不在

## 10. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增机制**。质差体现在新机制把上限提到了哪。

| 时代 | 已有能力 | 新增的成长线 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代（era 04） | 裂变、临近度、村落凝聚力、叛乱值 | **裂变：聚落可以增殖** | 上限是**整片区块网络的承载量**——**外延增长** |
| **本时代** | era 04 全部能力 | **六条并行**：拓展统治 / 强化统治 / 征兵 / 军事装备 / 政治改革 / 市场 | 从"你有多少地"提高到"**你能把地和人都变成多少力量**"——**第一次出现内涵增长，而且路不止一条** |
| 下一时代（era 06） | era 05 全部能力 | **秩序可被反复重建** | 从"能产出多少力量"提高到"**这份秩序能维持多久、能重建几次**" |

一句话概括：**在一个地方活下去 → 换到有更多种类的地方 → 把资源固定在土地上 → 让聚落增殖成网络 → 让权力既能伸出去、又能落到人头上 → 让秩序可以被反复重建 → 待定。**

## 11. 验收要点

1. 玩家能感受到**变强第一次有了第二个来源**——不只靠占地，还能靠改造自己。
2. 玩家能感受到**通往国力的路不止一条**——而且**必须选**，因为六条线抢同一批粮食和人口。
3. 玩家能感受到**一开始真的打不过邻居**，而且这个差距是能被改革追上的。
4. 玩家能感受到**代理人真的会坐大**——同一个区块管得越久，凝聚力掉得越快。
5. 玩家能感受到**邻国是标尺不是背景板**——它的数值在涨，窗口在关。
6. 玩家能感受到**一（拓展）和二（征兵）互相拉扯**——集权和放权各有代价，不能只要一个。
7. 玩家能观察到**每个区块的统治方式**，并且可以随时重画这张图。
8. 玩家能感知**政治线经验是被麻烦推上去的**——叛乱之后，能解锁的东西明显多了一截。
9. 玩家能理解**压力有一部分是自己造的**——独立出去的区块回来了，以邻国的身份。
10. 玩家能感受到**称帝是一条两段的门槛**——先打够，再守住；而且**刚够线时最危险**。
11. 玩家在本时代**始终有解不掉的压力**——集权与放权是同一件事的两面，只能平衡不能取消。
12. 崩溃后玩家仍在同一时代，**图鉴、选育与抗性、政治线经验都还在**，丢的是区块、产能和已编户的登记。
