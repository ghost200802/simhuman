# era 02 · 游玩核心：旧石器时代

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、节点清单、界面方案。阅读可脱离其他文档。

**一句话：** 你只能待在一个区块，而新东西在别的区块——所以你每要认识一样新物种，都得先扔掉一次已经攒起来的窝。

---

## 1. 时代的叠加原则

> **时代推进是叠加，不是替换。**

```
本时代 = 已有能力的全集 + 一条新增的成长线
```

- 新增的那条线**更陡、上限更高**。
- 旧的那些线**一直可用，上限不变**。
- 玩家的行为变化来自新线更划算，不是旧能力被拿走。

由此推出两条贯穿全篇的结论：

**① 迁徙没有被奖励，只是它现在能换来别处换不到的东西。**

搬走一次，旧区块的建筑全部废弃。**攒得越多越舍不得走**——但新物种只长在人在的地方。这个两难是自然涌现的，不需要额外设一条规则。

**② 倒退通过失传发生，不通过时代回退。**

时代标签与能力框架保留。崩溃表现为人口崩塌、建筑废弃、人力不足无法迁徙；**图鉴永不丢失，区块探索度也不重置**。玩家仍在本时代。

只有文明整体灭绝时本局才结束。**时代标签不退。**

---

## 2. 第一次出现的东西：食谱宽度

这个时代真正第一次出现的不是迁徙——是**食谱宽度**。

在此之前，你能吃什么由脚下这片地有什么决定。本时代开始，**你能吃到多少种东西，第一次由你走到过哪里决定**。

era 01 的公式是"**一个区块 × 提取率**"；本时代多了一个乘数：**你能到达多少个区块、那些区块上有什么。**

**这是 7–10 倍的来源。** era 01 造出了工具（陷阱、网、木矛），但工具换不来没有的东西——同一个区块里物种是固定的。要拿到野兔对陆龟 7 倍、山鹑 10 倍的可持续捕获量，得先**走到有野兔和山鹑的地方**。

---

## 3. 独有体验：每要一样新东西，先扔掉一次窝

**本时代是唯一一个"丢"的时代。**

| 时代 | 对旧地盘做什么 |
| --- | --- |
| era 01 | 不搬 |
| **era 02** | **搬走就作废** |
| era 03 | 定居 |
| era 04 | 分家，**保留**旧地 |

你每要认识一样新物种、每要试一块可能更好的区块，都得先把已经建起来的东西留在身后，让它废弃。

---

## 4. 核心张力

> **搬到新地方，才能遇到新物种、才知道别处有没有更好的区块；留下来，才能守住已经深耕好的产出，但食谱和眼光都停在这里。**

| | 代价 |
| --- | --- |
| **搬** | 旧区块建筑**全部废弃**（停产 + 修复费）；新区块好坏要住过才知道 |
| **不搬** | 图鉴停涨、**食谱宽度不再增加**；邻区块探得到、看得见，**但吃不到**——要吃就得搬过去 |

两侧都不是纯损失，也都不是纯收益。玩家每推进一段，就要重做一次这个判断。

---

## 5. 核心循环

```
探索 → 探到相邻区块、遇到新物种
   ↓
搬迁 → 旧区块建筑全部废弃 + 搬迁期间不生产
   ↓
在新区块停留并实际使用 → 探索度涨、图鉴解锁或升级
   ↓
食谱宽度扩大 → 同一区块能养活更多人            ← 正反馈
   ↓
人口涨到该区块的野生资源上限 → 停滞
   ↓
只能去探下一个区块
```

这是一个**正反馈循环，野生资源天花板是它的刹车**。

**慢变量与各自的中间可见态：**

| 慢变量 | 中间可见态 |
| --- | --- |
| 图鉴 | 一条条**亮起来**。因为它是跳变不是斜坡，每次点亮都有明确的时刻 |
| 区块探索度 | 条在涨、也在**缓慢回落** |
| **候选区块清单** | 探到过的区块被记下来，清单在变长。**定居就是从这份清单里挑一个** |
| 食谱宽度 | 菜单上多出来的行数——**看得见自己多会吃了几样** |

### 乐趣产生在五处

1. **图鉴点亮的瞬间**——它是**跳变**（从不能吃变成能吃），不是缓慢上涨的数字；而且**永久**，每次点亮都是不可撤回的资产。
2. **候选区块清单在变长**——每探到一个新区块就进清单。**这份清单就是本时代最直接的成绩单**，而且它是定居时的选择池。
3. **区块探索度被做满**——它决定这个区块上所有建筑的产出效率。而且它会随时间缓降，**要维持就得回来用它**。
4. **"我认识它"带来的效率落差**——同样的建筑、同样的人，认识前后产出差几倍，玩家能直接感知。
5. **食谱上第一次出现一种新东西**——不是抽象的"变强"，是**菜单上多了一行**，而这一行是走出来的。

---

## 6. 核心机制清单

以下机制服务于第 4 节的张力。凡不能映射到"搬"或"留"某一侧的机制，不应进入本时代。

### 6.1 跨区块探索（本时代新增）

- 探到**相邻区块**，把它加入**候选区块清单**。
- 逐步揭示该区块的资源与物种。
- **持续占用人力**，不是一次性动作。

**接口：** 是 6.2 迁徙的前提；是 6.5 图鉴的触发源（探到才能遇到新物种）。

### 6.2 迁徙（本时代新增）

- **整体搬迁**，本时代只能控制一个区块。
- 搬迁期间不生产。
- **旧区块建筑全部进入"无产物 + 废弃"状态**——不摧毁、不释放格位。
- **搬到哪由玩家挑**：看着候选区块清单，觉得哪块好就搬过去。想继续探就继续探；不想探了，随时可以回到清单上任何一个区块。

**接口：** 代价落在 6.3 上；收益来自 6.4 与 6.5 的重新积累。

### 6.3 建筑与废弃（本时代引入）

- **本时代起才有建筑**——era 01 一座都没有。
- 最高只有**简陋建筑**。
- **废弃的触发源是迁徙，不是缺工。** 缺工只是不产出。
- 废弃建筑消耗资源**修复**后可重新使用。

**接口：** 是 6.2 的代价出口；修复费构成"回头"的成本。

### 6.4 区块探索度

- **区块级**，随停留与实际使用上升，**随时间缓慢回落**。
- **不因迁移重置**——来过就是来过。
- 决定该区块上建筑的**产出效率**，**不触发废弃**。

**接口：** 是 6.5 图鉴的落地面（图鉴决定"能拿什么"，探索度决定"拿多少"）；是 6.2 迁徙决策的比较依据。

### 6.5 图鉴

- **沿用 era 01 的规则**：物种级、有内在认知难度、需在区块内停留并实际使用、部分需科技门控、**解锁即永久**。
- 本时代新增的是**触发源**：跨区块探索让你遇到本来遇不到的物种。

**接口：** 与 6.4 共同决定"这个区块你能拿到多少"；与科技互相门控（单向不成环）。

### 6.6 沿用 era 01 的全部系统

| 系统 | 在本时代的形态 |
| --- | --- |
| **任务** | 四类：狩猎 / 采集 / 打制 / 探索。本时代只有**探索**这一类升级为可跨区块 |
| **人口** | 成年 / 未成年分别计数，规则不变 |
| **成年存活率** | 仍是时代主线计量，决定科技节点的流失速度 |
| **科技节点** | 进度 0–100，研发涨、流失掉、损失人口时按影响系数掉落。规则不变 |
| **教育值** | 规则不变 |

## 7. 这个时代不该有的

- 定居农业、选育、抗性——era 03
- **系统性大规模储存**——era 03。本时代只有能在路上带走的小规模保存
- **同时控制多个区块**——era 04。本时代只能占一个，搬家就是放弃
- 常设的分工与专业角色——era 03
- 货币、成文法律、税收、常备军、分封、跨区域行政——era 05
- 化学农药——一直不在

两条针对本时代的禁令：

- **不得让探索不占人力。** 探索必须持续占用一部分劳动力。
- **不得让玩家不搬就吃到别的区块的资源。** 破了这条，本时代的张力就没了。

---

## 8. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增一条成长线**。质差体现在新线的上限提高了多少。

| 时代 | 已有能力 | 新增的成长线 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代（era 01） | 任务、科技节点、图鉴、人口结构 | **工具从使用到改造到复制** | 提取**种类**的扩大——从只能拿肉，到能拿骨髓与脑。不是倍数 |
| **本时代** | era 01 全部能力 | **换地方 + 探索 → 换种类** | 从"一个区块"到"**你能到达的最好的那个区块**"；换到繁殖快的资源后，同一区块内的可持续提取量提高约 **7–10 倍**。**天花板仍是野生资源** |
| 下一时代（era 03） | era 02 全部能力 | **定居农业 + 选育 + 抗性** | **突破野生资源天花板**——采集与农业的承载力差距约一个数量级 |

一句话概括三个时代：**在一个地方活下去 → 换到有更多种类的地方 → 把资源固定在土地上。**

---

## 9. 验收要点

1. 玩家能感受到**"搬"和"留"都在付出代价**，而不是有唯一最优解。
2. 玩家能观察到图鉴是**跳变式点亮**，且点亮后**永久保留**。
3. 玩家能感知**"食谱宽度"是可以自己挣出来的**——菜单上多出来的每一行都是走出来的。
4. 玩家在本时代**始终有解不掉的压力**——野生资源天花板。
5. 玩家能找到并占住一块资源齐全的区块，且这份优势来自**判断与探索**，不是纯运气。
6. 崩溃后玩家仍在同一时代，**图鉴、区块探索度、候选区块清单都还在**，但要走不动路、要修建筑。
