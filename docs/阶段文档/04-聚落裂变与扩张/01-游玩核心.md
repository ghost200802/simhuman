# era 04 · 游玩核心：聚落裂变与扩张

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、节点清单、界面方案。阅读可脱离其他文档。

**一句话：** 你第一次能把人派出去，而不是带着人走——但那条路你握不住。

---

## 1. 时代的叠加原则

> **时代推进是叠加，不是替换。**

```
本时代 = 已有能力的全集 + 一条新增的成长线
```

- 新增的那条线**更陡、上限更高**。
- 旧的那些线**一直可用，上限不变**。本时代仍然可以采集、狩猎、整体迁徙。
- 玩家的行为变化来自"新线更划算"，不是旧能力被拿走。

由此推出两条贯穿全篇的结论：

**① 迁徙与裂变并存，区别只在"旧的留不留"。**

era 02 的开拓逻辑完整保留——跨区块探索、候选区块清单、区块探索度，一条都没改。变的只有一件事：**不是整体搬走，而是分一部分人过去。** 旧区块不废弃。

**② 倒退通过失传发生，不通过时代回退。**

时代标签与能力框架保留。崩溃表现为人口崩塌、**区块脱离控制**、部分技能与匠人失传；**选育与抗性不清零**。玩家仍在本时代。

只有文明整体灭绝时本局才结束。**时代标签不退。**

---

## 2. 第一次出现的东西：增殖的聚落

这个时代真正第一次出现的不是扩张，是**增殖**。

era 02 扩张的方式是"整体搬走"——走一趟，旧地作废，你手里始终只有一个区块。era 03 把区块锁死了，因为没有第二块地能接管。

本时代起，**聚落第一次能长出新的聚落，而你仍然握着旧的**。地图上属于你的点从 1 个变成 N 个——「上限」这个词第一次有了网络的含义。

---

## 3. 独有体验：走，第一次不是失去

同一个动作，三个时代三种结果：

| 时代 | 派人口出去，意味着 |
| --- | --- |
| era 02 | 扔掉一次攒起来的窝 |
| era 03 | 走不起——储存、熟地、水利全在原地 |
| **era 04** | **多一个会还回来的生产单元** |

**这是本时代新增的那条线直接给的感受**，不需要额外解释。

---

## 4. 核心张力

> **分裂能卸掉主区块的压力，但分得越远，新聚落的临近度越低、凝聚力也就越低；不分裂，可耕地用光后人口一涨就闹饥荒。**

两侧都是具体的、看得见的：

| | 代价 | 收益 |
| --- | --- | --- |
| **分裂** | 主区块人口与物资减少；新聚落的**临近度**低 → **村落凝聚力**低 | 主区块压力回落；地图上多一块可开发的区块 |
| **不分裂** | 可耕地用光 → 人口一涨就闹饥荒；凝聚力也随人口下降 | 不用付出人口与物资 |

**本时代的出口是软的，不是硬锁。** 你可以一直分，但每多一块地，网络就更难握住一点。

**而"更难握住"是可以投资的。** 临近度不等于距离——**修路、选地形、推科技，都能把它拉回来**。这是本时代除了社会节点之外的第二条对抗独立的路。

**灾害仍在**，规则不变：损失人口与储存，同时提升抗性。

---

## 5. 核心循环

```
畜力牵引  →  单位劳动产出提高，能养活更多人
     ↓
人口涨  →  可耕地用光  →  饥荒                    ← 推力
     ↓
分裂：派人口与物资到相邻区块建新聚落               ← 本时代新增的动作
     ↓
主区块：人口、物资减少，压力回落                    ← 卸压
地图上：多一块可开发的区块                         ← 收益
     ↓
新聚落的临近度低  →  村落凝聚力低
     ↓
凝聚力跌破 0  →  叛乱值开始涨，该区块产出同时被折掉
     ↓
叛乱值涨到 100  →  脱离控制（中立）                 ← 出口的代价
```

**正反馈**：多一块地 → 更多产出 → 养更多人 → 能再分
**刹车**：临近度 → 村落凝聚力 → 叛乱值

**两条对抗独立的路**（玩家看得见、能动手）：

| 路子 | 怎么走 | 治什么 |
| --- | --- | --- |
| **提高临近度** | 修路、挑好走的相邻区块、推相关科技 | 把扣掉的临近度补回来 |
| **提高凝聚力** | 社会节点——仪式、宴飨、议事 | 同样的临近度，掉得少 |

### 慢变量与中间可见态

| 慢变量 | 中间可见态 |
| --- | --- |
| **临近度** | **每个区块一个 0–100 的数**，主区块是 100。地图上能直接看出哪条路"贵" |
| **村落凝聚力** | **每个区块一条**。主区块的高，临近度低的低；人口涨会压它 |
| **叛乱值** | 凝聚力跌破 0 后开始涨，**同时把该区块的产出按比例折掉**——玩家看得见它既在烂、又在拖累你 |
| 可耕地 | 条在涨，涨满就停止增长，饥荒开始 |
| 网络 | 地图上的点从 1 个变多 |

### 乐趣产生在四个位置

1. **地图上多出一个点**——最直观的进度感，而且这一次旧的还在。
2. **修一条路，把一个快散的区块拉回来**——临近度是可投资的，玩家能亲眼看到那个数往回走。
3. **每次裂变派多少人走**——派多了主区块缓过来但新聚落是空壳；派少了新聚落活不下来。
4. **挑哪个相邻区块**——**好走**决定凝聚力，**资源**决定能不能活。这两个条件经常冲突。

## 6. 核心机制清单

以下机制服务于第 4 节的张力。凡不能映射到"分裂"或"不分裂"某一侧的机制，不应进入本时代。

### 6.1 裂变（本时代新增）

- **派出一部分人口与物资**，到相邻区块建立新聚落。
- **完整复用 era 02 的开拓逻辑**：跨区块探索 → 候选区块清单 → 从清单里挑一个。
- **与 era 02 的唯一区别：旧区块不废弃。** 母聚落继续生产，只是人口与物资少了。
- 新聚落从零开始：区块探索度归零、建筑要重盖。
- **派多少人、带多少物资，由玩家决定。**

**接口：** 上游是 6.3（凝聚力低构成推力）与 6.7（可耕地用光）；下游决定 6.2 的临近度输入与 6.8 的起点。

### 6.2 临近度（本时代新增的计量，每个区块一条）

- **每个区块一个 0–100 的值。主区块恒为 100。**
- 沿**最省路径**从主区块传播，**不是地理最短路径**——绕远但好走的路可能更划算。
- 每一跳扣掉该跳的 cost，**cost 由四项决定**：

| 项 | 作用 |
| --- | --- |
| **基础距离** | 一跳的基准 cost，固定 |
| **地形** | 难走的地形提高 cost，好走的降低 |
| **道路** | 修了路的跳 cost 显著降低（见 6.5） |
| **科技** | 相关的科技节点给出全局减免 |

- **临近度是"到主区块"的，所以它天然随网络扩张而变**——每多一跳，后面所有区块的临近度都往下走。

**接口：** 上游是地图与 6.5；下游是 6.3。**它是本时代唯一能被玩家直接投资改善的空间量。**

### 6.3 村落凝聚力（era 03 引入，本时代扩展）

- **每个区块一个数值。** 这是 era 03 那个计量加了新来源，不是新属性。
- **下降来源：**
  - 本区块**人口越多越低**
  - **分工越深越低**（era 03 已定）
  - **临近度越低**（本时代新增）
- **上升来源：社会节点。** 仪式、宴飨、议事——**这是玩家唯一能直接把它拉回来的手段**。
- **每个区块各自结算**，不共用。

**接口：** 上游是 6.2 与人口；下游是 6.4。它是本时代张力的落点。

### 6.4 叛乱值与独立（本时代新增）

- **只有非主区块会独立。** 主区块凝聚力跌破 0 时表现为**饥荒与产出下降**。
- 凝聚力**跌破 0** → 该区块的**叛乱值**开始上涨，**速度由凝聚力决定**。
- 叛乱值上涨期间，**该区块的全部产出按叛乱值等比打折**——它既在烂，又在拖累你。
- 玩家随时可以把凝聚力拉回 0 以上——**叛乱值自然下降**。
- **叛乱值涨到 100** → 该区块**脱离控制，成为中立的独立聚落**。
- **丢的是那块地和上面的产能**；时代标签不退，图鉴不丢，科技节点不掉。
- **征讨与收服不在本时代**，归后续战争逻辑。

**接口：** 上游是 6.3；它是 6.1 的直接代价出口；era 05 会在它上面叠加更多干预手段。

### 6.5 道路与运输（本时代新增）

- **在两个相邻区块之间修路**，降低该跳的临近度 cost。
- 修路要**消耗产能与时间**，且路上的区块都受益。
- **没有路时走自然地形**——河流与平原天然便宜，山地与林地天然贵。
- **这是玩家对抗独立的第二条杠杆**：社会节点治凝聚力的分子，道路治临近度的分母。

**接口：** 上游是科技节点与产能；下游作用于 6.2。

### 6.6 畜力牵引（本时代新增的科技节点）

- 解锁后，**单位劳动的产出提高**——能养活更多人。
- 它同时做两件事：**养活更多人** + **让可耕地更快被占满**。
- **前提是养殖线存在**——而养殖线由地图决定（era 03）。**没有可驯化物种的区块，这条路走不通。**

**接口：** 上游是 era 03 的养殖线；下游作用于 6.7 与饥荒；它同时是进入 era 05 的条件之一。

### 6.7 可耕地上限

- **每个区块一个固定值**，由区块属性决定，**科技不改变它**。
- 占满之后，人口继续涨 → 缺口 → **饥荒**。
- 这是 6.1 的推力来源。

**接口：** 上游是 6.6（加速占满）；下游是 6.1 与饥荒。

### 6.8 新聚落的继承（本时代新增）

- 新聚落建立时，**从母聚落带走一部分产能**——工具、种子、畜力。
- **带走多少由玩家决定，但主区块要相应减少。**
- 结果是：**富的聚落分出去的子聚落起点也高。** 网络里因此会长出强弱差异，而且这个差异会跟着每一次分裂传下去。

**接口：** 上游是 6.1；下游影响 6.3 的承载力与 era 05 的从属关系。

### 6.9 沿用 era 01–03 的全部系统

| 系统 | 在本时代的形态 |
| --- | --- |
| **任务** | 规则不变 |
| **人口** | 规则不变；**分裂时从可投入劳动人口里扣** |
| **成年存活率** | 规则不变 |
| **科技节点** | 规则不变；**新增 6.6** |
| **教育值** | 规则不变 |
| **图鉴** | 规则不变。**新聚落要重新积累区块探索度，但图鉴是永久的** |
| **选育与抗性** | 规则不变，不清零 |
| **建筑** | 规则不变；新聚落从零盖起 |
| **灾害** | 规则不变：损失人口与储存，同时提升抗性 |

## 7. 这个时代不该有的

**系统上不存在的东西：**

- **命令另一个聚落的操作。** 本时代每个区块各自结算，玩家没有"下达"这个动作。

**属于后续时代的：**

- **从属关系、征讨与收服**——era 05
- 货币、成文法律、常备军、税收体系、跨区域行政——era 05
- 化学农药——一直不在

**四条针对本时代的禁令：**

- **不得让裂变免费。** 人口、物资、以及主区块的产能都要真扣。
- **不得把临近度做成距离。** 它必须由地形、道路、科技共同决定，**否则玩家就没有投资的对象**。
- **不得让独立可以靠规则避免。** 它是凝聚力掉出来的，不是一条禁止规则。
- **不得禁止玩家不扩张。** 不扩张的代价是饥荒，不是规则。

## 8. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增成长线**。质差体现在新线的上限提高了多少。

| 时代 | 已有能力 | 新增的成长线 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代（era 03） | 定居农业、选育、抗性、图鉴、村落凝聚力 | **定居农业 + 选育 + 抗性** | 上限是**一块地的农业承载力** |
| **本时代** | era 03 全部能力 | **裂变：聚落可以增殖** | 从"一个聚落的承载量"变成"**整片区块网络的承载量**" |
| 下一时代（era 05） | era 04 全部能力 | **代理：把权力交给别人的手**（一个主目标、三个大方向） | 从"你能管多少"变成"**你派出去的人能替你管多久**"——**第一次出现内涵增长** |

一句话概括：**在一个地方活下去 → 换到有更多种类的地方 → 把资源固定在土地上 → 让聚落增殖成网络 → 让权力既能伸出去、又能落到人头上，还能自己站着 → 让地图之外还有地图 → 待定。**

---

## 9. 验收要点

1. 玩家能感受到**走不是失去**——派出去的人和物资会以新聚落的形式还回来。
2. 玩家能感受到**主区块真的被抽空了**——人口与物资都少了，不是免费的增殖。
3. 玩家能观察到**每个区块的临近度**，并看懂它是被什么扣掉的。
4. 玩家能感知**临近度是可以投资的**——修一条路，那个数真的往回走。
5. 玩家在本时代**始终有解不掉的压力**——可耕地上限与村落凝聚力，两条都只能缓解，不能取消。
6. 玩家能把**快独立的区块拉回来**，但拉回来的代价一次比一次高。
7. 崩溃后玩家仍在同一时代，**图鉴、选育与抗性都还在**，丢的是区块和产能。
