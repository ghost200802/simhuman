# era 01 · 游玩核心：人类形成期

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、节点清单、界面方案。阅读可脱离其他文档。

**一句话：** 你花出去的时间不会消失——它变成能力；而能力会掉，认得的东西不会。

---

## 1. 时代的叠加原则

> **时代推进是叠加，不是替换。**

```
本时代 = 已有能力的全集 + 一条新增的成长线
```

本时代是**开局**，没有"上一时代的能力"可继承；但从此以后，每个时代都遵循这条。

由此推出一条贯穿全篇的结论：

**倒退通过失传发生，不通过时代回退。**

科技节点会失效，人口会掉，但**图鉴永不丢失**，时代标签也不退。玩家仍在本时代。

只有文明整体灭绝时本局才结束。

---

## 2. 第一次出现的东西：可以留存的技术

在此之前没有可累积的技术，所以**没有东西会掉**。本时代起，技术第一次以**进度**的形式存在——**积累成为事实**，而**掉就是积累的代价**。

进度会自己往下走；流失的快慢**不由你决定**，由成年存活率决定。

正面就是本时代的成长线：**工具从使用 → 改造 → 复制**。

而节点的状态**只有两个**：解锁（满效果）与失效。中间没有"半会"——你要么会打，要么不会。

---

## 3. 独有体验

**人类能够通过积累提高生产效率。**

> **你花出去的时间不会消失，它会变成能力。**

做过的任务会留下经验，经验推高科技节点的进度，节点解锁之后效率就上一个台阶。**这条线此后不会消失**——它是后面所有时代的地基。

---

## 4. 核心张力

> **危险的任务产出高，但成年存活率会掉；安全的任务产量低，但成年存活率稳。**

两侧作用在**同一条结算**上：

| | 任务产量 | 成年存活率 | 研发 | 流失 |
| --- | --- | --- | --- | --- |
| **派危险任务** | 高 | **低** | 快 | **快** |
| **派安全任务** | **低** | 高 | 慢 | 慢 |

危险那边：产量高、研发快，**但人在死，流失也快**。
安全那边：人活得久、流失慢，**但产量低，研发也上不去**。

**这是本时代唯一的、也是全部的矛盾。** 不需要额外规则来制造它——它就在那条结算里。

玩家对抗"技术下滑"有三条路，彼此不同：

| 路子 | 怎么走 | 治什么 |
| --- | --- | --- |
| **多派任务** | 提高研发 | 涨得更快 |
| **降低损失概率** | 图鉴·动物、体力、少派冒险任务 | 成年存活率不跌 → 流失慢 |
| **提高教育值** | 社会节点 | 同样的损失，掉得更少 |

第三条是**唯一一条不靠冒险、也不靠躲的路**。

---

## 5. 核心循环

```
派任务（狩猎 / 采集 / 打制 / 探索）
   ↓
产出：食物 → 营养          经验 → 科技节点进度
同一次任务也推进图鉴（因为"使用了该资源"）
   ↓
营养 → 体力 / 脑力
   ↓
脑力  → 提高所有科技节点的研发
体力  → 提高狩猎任务的产出
图鉴·动物 → 降低狩猎任务的损失概率
   ↓
成年人口涨 → 能派更多人 → 任务规模上升          ← 正反馈
   ↓
每次任务的损失概率都在啃成年人口 → 成年存活率跌 → 流失加快   ← 刹车
   ↓
进度跌破 50，节点整个失效，要重新爬满 100
```

**正反馈**：任务 → 经验 → 进度 → 节点解锁 → 任务效率更高
**刹车**：任务的损失概率 → 成年存活率 → 流失速度 → 进度

### 慢变量与中间可见态

| 慢变量 | 中间可见态 |
| --- | --- |
| 科技节点进度 | **进度条在涨、也在掉**——两个方向都看得见 |
| 图鉴 | 一条条亮起来 |
| 人口构成 | 成年 / 未成年两段的变化 |
| 区域探索度 | 条在涨 |
| 任务预估 | **预计损失概率的区间**——图鉴等级越高，区间越窄 |

### 乐趣产生在五个位置

1. **第一次把一个科技节点的进度推到 100**——整个游戏的第一次解锁，而且是**挣来的**：研发必须压过流失。而在那之后你会一直看着它往下掉。玩家从第一分钟就学会"技术是要养的"。
2. **图鉴点亮**——跳变，永久，而且**立刻有系统效果**（狩猎任务的预估损失概率往下调）。
3. **预估区间收窄**——图鉴越深，"预计损失概率"的区间越窄。**你越来越知道自己要付什么代价**，而这是"知道"换来的，不是装备换来的。
4. **技术掉回去了，图鉴没掉**——玩家第一次亲身体验到图鉴与科技的不对称。
5. **每次任务出发前那个预估**——派几个人、去不去、什么时候去。**本时代最高频的决策点**，每一次都直接连着成年人口。

## 6. 核心机制清单

以下机制服务于第 4 节的张力。凡不能映射到它的任一侧的机制，不应进入本时代。

### 6.1 任务

**本时代唯一的操作面。**

| 项 | 内容 |
| --- | --- |
| 类型 | 狩猎 / 采集 / 打制 / 探索 |
| 投入 | 从「可投入劳动人口」扣除人数，占用若干期 |
| 出发前 | 显示预估：**预计产出**与**预计损失概率的区间** |
| 结算 | 产出 + 经验 + 按概率损失成年人口 |

**接口：** 喂 6.5（经验 → 进度）、喂 6.6（使用了该资源 → 图鉴）、喂 6.3（损失人口 → 掉落）；是 6.2 的唯一消耗方。

### 6.2 人口

- 分**成年 / 未成年**分别计数。
- 出生进未成年；未成年按固定期数自动晋升为成年。
- **未成年不执行任务。**
- 任务损失只扣成年人口。

**接口：** 是 6.1 的人力池；成年人口的损失同时触发 6.3 与 6.5。

### 6.3 成年存活率

- **本时代的时代主线计量。**
- 决定 6.5 的**流失速度**：成年存活率越低，技术流失越快。
- 由任务的损失概率与事件共同决定。

**接口：** 唯一的上游是 6.1 与事件；唯一的下游是 6.5。

### 6.4 教育值

- 由社会节点（建议：主动教学）少量提升。
- 决定**承载知识的人口**的构成，从而决定同样的人口损失会掉多少技术。

**接口：** 只作用于 6.5 的掉落公式；是 6.1 之外的第二条对抗技术下滑的路。

### 6.5 科技节点

```
进度 0 – 100

【涨】研发    做任务给的经验
【掉】流失    每期自动，作用于全部节点；快慢由 6.3 决定
【掉】掉落    损失人口时触发，作用于全部节点；
              各节点按自己的影响系数分档

每期结算：进度 ← 进度 + 研发 − 流失 − 掉落

100 → 解锁（满效果）
已解锁跌破 50 → 失效
失效后 → 重新爬满 100 才能再用
状态只有 0 / 1
```

**影响系数 = 这项技能有多依赖特定的人。** 系数高（只有少数人掌握的手艺）掉得多；系数低（人人都沾一点的"家里的"技术）掉得少。

**接口：** 上游是 6.1、6.3、6.4；下游是所有任务效率。

### 6.6 图鉴

- 大类：**材料 / 动物 / 植物**。
- **升级制**，条目等级逐物种不同；**永久保留**。
- 推进条件：在区块内**停留并实际使用**该资源（由 6.1 的任务自然满足）。
- **动物条目降低狩猎任务的损失概率**；材料条目的等级门控 6.5 的「石器打制」各级；植物条目提高采集类任务的可用资源量。

**接口：** 双向门控 6.5（不成环）；调节 6.1 的预估与实际风险。

### 6.7 区域探索度

- 由**区域内探索任务**提高，消耗人力。
- 范围是**区块内**（约 10 km，当天往返）。

**接口：** 是 6.6 的辅助（探索提高遇到新物种的机会）；不越出区块是本时代与 era 02 的分界。

### 6.8 社会节点

- **主动教学**（无选项类）。
- 解锁条件：**群体里真的有活到能教的老人**。
- 效果：提升 6.4 教育值。

**接口：** 由 6.2 与 6.3 的长期结果解锁；作用于 6.5 的掉落。

## 7. 这个时代不该有的

**系统上不存在的东西：**

- **建筑**——本时代没有任何建筑。
- **资源设施**——没有固定区域，资源直接与区块绑定。
- 储存设施、多地块控制。

**属于后续时代的：**

- 陷阱、套索、网；专门化的投射装置（投矛器、弓）——era 02
- 磨制工具——era 02
- 火作为稳定基础设施——era 01 → era 02 的门槛
- 定居、农业、选育、抗性——era 03

**四条针对本时代的禁令：**

- **不得让图鉴掉。** 图鉴永久是系统不变量。
- **不得让科技进度不掉。** 流失是本时代的机制核心，拿掉它这个时代就空了。
- **不得让任务无风险。**
- **不得让探索与搬运免费。**

---

## 8. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增一条成长线**。

| 时代 | 已有能力 | 新增的成长线 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代 | （无，本时代是开局） | — | — |
| **本时代** | — | **工具从使用到改造到复制** | 从"个体体能能直接拿到的食物"提高到"**工具能从同一片土地上多取出的那一类组织**"——从只能拿到肉，到能拿到**骨髓与脑**（脂肪）。这是**提取种类的扩大**，不是倍数 |
| 下一时代 | 本时代全部能力 | **换地方 + 探索 → 换种类** | 从"一个区块"到"**你能到达的最好的那个区块**"；并且换到繁殖快的资源之后，同一区块内的可持续提取量提高约 **7–10 倍** |

一句话概括三个时代：**在一个地方活下去 → 换到有更多种类的地方 → 把资源固定在土地上。**

---

## 9. 验收要点

1. 玩家能感受到**技术是会掉的**——不是惩罚，是他自己派任务派出来的结果。
2. 玩家能感受到**投入的时间变成了能力**——同一件事做久了，产出真的变多。
3. 玩家能观察到**图鉴与技术的不对称**：崩溃后认得的东西还在，会做的东西没了。
4. 玩家能感知**出发前那个预估**是有用的，而且图鉴越深它越准。
5. 玩家在本时代**始终有解不掉的压力**——成年存活率压在低位，无法同时既让人去取食、又让人活到能教。
6. 玩家能体验到**三条对抗技术下滑的路**（多派任务 / 降低损失 / 提高教育值），而不是只有一条。
7. 崩溃后玩家仍在同一时代，**图鉴还在**，但科技要从头爬。
