# era 05 · 游玩核心：农耕文明时代

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、节点清单、界面方案。**不定义任何一条政治线的机制**——机制以该线自己的设定为准，本文只写本时代用它们做什么。阅读可脱离其他文档。

**一句话：** 你要靠别人的手把摊子撑大，而别人的手迟早不再听你的；等你把它按住，你花在维持上的已经比花在发展上的多了。

---

## 1. 时代的叠加原则

> **时代推进是叠加，不是替换。**

```
本时代 = 已有机制的全集 + 一条新增机制
```

- 新增的那条线**更陡、上限更高**。
- 旧的机制**一直可用，上限不变**。本时代仍然可以采集、狩猎、整体迁徙、裂变。
- 玩家的行为变化来自"新线更划算"，不是旧能力被拿走。

**解锁是扩菜单，不是替换。** 委派没有取代直辖；编户没有取代征发。

**倒退通过失传发生，不通过时代回退。** 时代标签与能力框架保留。崩溃表现为人口崩塌、区块独立、部分技能与匠人失传、已编户区块的登记丢失；**政治线经验不清零**——制度是学会了就不会忘的东西。

只有文明整体灭绝时本局才结束。**时代标签不退。**

---

## 2. 第一次出现的东西：代理

era 04 有一面墙：**邻近度撑不住的地方，你拿不到**。

在本时代之前，**权力和邻近度是同一件事**——你只能管你走得到的地方。

**本时代第一次，你能把一件事交给一个不在你眼前的人去做，而他做得成。** 权力第一次越过邻近度那面墙。

**由此国力第一次可以脱离你的双手增长。** 同样一片地，因为交给谁管、怎么管不同，能产出的力量可以差出一个数量级——权力能不能伸到邻区、人能不能被登记在册、兵器能不能便宜到人人有份。

**而本时代第一次，通往国力的路不止一条。** 前四个时代每个只有一条新线；本时代有**三个大方向**，它们抢同一批资源，而且互相拆台。

> **历史参照：** Taagepera 把帝国规模的**三次跃升**定位在约 2800 BC（城市出现）、**约 600 BC**、1600 AD，并把中间那次称为「**power delegation breakthrough**」——**授权**。规模的突破来自"能派人去管"，不来自走得更快。

---

## 3. 独有体验：国力第一次是一个你能亲手推动的数字，而它同时在离开你的手

同一个动作，五个时代五种结果：

| 时代 | 想变强，你能做什么 |
| --- | --- |
| era 03 | 在同一块地上等它慢慢长 |
| era 04 | 多分出去一个聚落——**更多的地** |
| **era 05** | **派人去管**——换一种管法、把户籍铺下去、让兵器便宜下来 |

**而你会先撞到墙上：一开始你的国力跟邻国差得很远。** 这个差距是你进入本时代时拿到的初始条件，也是整个时代的驱动力。

---

## 4. 本时代的三个大方向

**这是项目里第一个「多条成长线」的时代。**

**本时代只有一个主目标——提升国力。通往这个目标的方向有三个**，每个方向下面挂着原有的成长线。玩家不必每个都走，但**每走一条都要付出别的线要用的东西**。

```
领地内发展 ── 强化统治 · 市场
扩张领地   ── 拓展统治 · 征兵 · 军事装备
维稳       ── 政治改革
```

| 方向 | 小点 | 玩家在推动什么 | 推动它要付出什么 |
| --- | --- | --- | --- |
| **领地内发展** | **强化对已占领地的统治力** | 一块地**产多少**、其中**多少到你手上** | 粮食（收买）、期数（修路、建生产建筑）、兵（派驻） |
| | **促进市场发展** | 让交换从村落之间长成市镇与商路 | 人口与粮食流向非农；**商人坐大后中央更难控制** |
| **扩张领地** | **拓展统治的地方** | 把权力铺到邻近度之外 | 该区块凝聚力**随任期持续下降**，迟早变成新的权力中心 |
| | **加强军事征兵能力** | 抬高动员率、征召、训练 | 咬掉劳动人口——**征召的就是种粮的那批人** |
| | **军事装备：自己研发、自己打造** | 让兵器库存涨起来、让每套更便宜 | 铁矿、工匠、粮食，以及**有些技术只能自己攻** |
| **维稳** | **政治改革** | 换资格标准、换管法 | **既得利益者的叛乱**——失败教你统治 |

各个小点挂在不同的系统上。本文只写它们在本时代**各自推动什么、代价是什么、以及怎么互相拆台**；机制定义以各自的系统为准。

### 4.1 方向之外还有一批独立的小点

**青铜炼制、铁器炼制、市场建立、火药使用……** 它们各自有独立的解锁条件与效果，彼此**不直接依赖、不互相阻塞**，先后顺序纯看它们在这个文明里怎么发生。

**它们不绑在本时代上。** 它们是科技、政治、图鉴这些系统里本来就有的内容；本时代特殊的地方只是它很长，所以玩家在这里能走完的变化比别的时代多。**本时代没走完的，下一个时代可以接着走。**

### 4.2 有三个小点贯穿始终，不是本时代独有

**强化统治、征兵、军事装备在后续时代都还在跑。**

**「贯穿始终」不等于「不属于这个时代」——它两样都是。** 它是本时代的一条成长线，同时也是所有时代的地基。

| 小点 | 为什么贯穿始终 |
| --- | --- |
| **强化统治** | 每个时代都要回答"这块地产多少、给我多少" |
| **征兵** | 每个时代都要回答"我能点出多少人" |
| **装备** | 每个时代都要回答"这些人拿什么打仗" |

**它们在本时代有本时代的形态**——青铜到铁器的装备、村落规模的动员、委派制下的统治——**但杠杆本身不随时代改变**。

### 4.3 征兵和装备是一对：人和物

**它们是战争潜力的两个上限，缺一个都打不了仗。**

- **征兵管人**：可动员兵力 = 当前动员率 × 可投入劳动人口
- **装备管物**：可装备兵力 = 兵器库存 ÷ 每个士兵所需装备量

**实际能上战场的 = 两者取小。** 人够了没装备不行，装备堆着没人拿也不行。

**所以这两条线天然互相拉扯**：都吃粮食，而粮食是同一批人种的。**扩军和扩产抢的是同一口锅。**

**装备这条线里有一半是"买不来"的**：市场能买到稀缺的成品，**但买不到你还没掌握的技术**。渗碳、淬火、高炉——**有些技术只能自己研发打造**，这半边不依赖市场也能成立。

### 4.4 为什么必须一起看

**单独推任何一条都会撞墙：**

- **只有拓展**：铺出去的是空架子——你叫不出兵，也收不上东西。
- **只有征兵**：你能点出很多人，但只能点到你走得到的地方；而且他们没有装备。
- **只有装备**：兵器堆在库里，而你没有足够的人去拿。
- **只有改革**：制度换了，但换来的能力没有地方用。
- **只有强化统治**：地盘稳，但你永远停在原地，而邻国在长。
- **只有市场**：你有钱买稀缺成品，但买不来一个国家还没掌握的技术。

**一起推，你才第一次能把一片网络变成一支军队。**

### 4.5 它们抢的是同一批东西

**粮食、人口、期数——每个方向都要吃这三样。**

- 征兵咬劳动人口 → 种粮的人少了 → 下一轮谁都推不动
- 造装备要铁矿、工匠、粮食 → 又是同一批人
- 打仗要粮 → 改革和修路的粮就没了
- 修路、开垦、建生产建筑也要期数和粮
- 到了后段，**维持**又来抢同一批东西——而它什么都不产出

**这是本时代最实在的取舍：不是"要不要提升国力"，是"先往哪个方向投"。**

**而它们的下限比上限更狠**——哪条线掉得太低，都会先把你拖垮：地盘掉了没产出，凝聚力掉了要独立，动员率掉了打不过，装备跟不上打不赢，改革停滞则所有线的解锁都停。

**注意这一层本身不是核心张力，是取舍。** 它能被算清楚、能被优化，玩家练熟了就能找到配比。**真正解不掉的是第五节的 5.1。**

## 5. 核心张力

**一对。** 三个方向之间抢资源那一层不是张力，是**取舍**——它是这一对的资源面，写在 4.5。本时代真正解不掉的，是下面这一对。

### 5.1 你派出去的手，和你要维持的东西，是同一批人

> **动员要求集权，扩张产生分权。**
>
> 你要打赢邻居，就得把人登记在册、把权力收上来；但你越成功、地盘越大，越只能放权去管——**而你放出去的人正在变成新的邻居。**

| 这一对的两侧 | 拿到什么 | 付出什么 |
| --- | --- | --- |
| **派人 / 放权** | 摊子能撑大，够不着的地方也能管起来 | **放出去的手迟早不听话**——占据度涨、任期累积、上交比例掉，最后长成新的邻国 |
| **回头压 / 收回** | 占据度被压住、任期被断开、凝聚力被买回来、叛乱值被压下去 | **吃粮食、吃期数、吃人**——投给扩张的力气，转过来吃掉扩张的成果，而外面在长 |

**你为打赢而集中起来的力量，会因为打赢而散掉。这一条没有最优解。**

> **不派人也是选法**：手里始终是自己的，代价是摊子就那么大，而外面在长。三条路都通，没有一条不疼。

**形式化：** Boulding 1962 的 Loss of Strength Gradient——**控制每单位面积的总成本随半径增长**。

**历史形状：** 周代分封从春秋初的 **148 国**收敛到战国的 **7 雄**；罗马行省从 1 个涨到 **~100 个**。

### 5.2 同一张力的时间投影：本时代后半段的形状

**前半段，你花出去的力气都是为了让东西变大。后半段，你花出去的力气主要是为了让它不变小。**

到了这个阶段，**维持成本大于你的余力——你只能救火**。往后，政治线逐条解锁、政策叠加起来，开始替你承担一部分维持；同时生产力在涨。**到后段，维持被制度接管，你腾出手。**

**所以本时代后半段的操作量是往下走的。** 开头手忙脚乱，越往后越少——**这不是游戏变简单，是你把维持交出去了。**

**而一旦松手，那些读数就一路往下掉。** 家族占据度、委派任期、上交比例、村落凝聚力、叛乱值——**其中任何一项都不会自己回来**，只能被玩家花力气压下去。

## 6. 核心循环

**三层同时转：外层的竞争压力、内层的分粮、以及下半场那条慢循环。**

```
最外层：邻国的攻击与战力标尺
        ↓  你打不过，必须提升国力 —— 但方向不止一个

三个方向分配同一批粮食、人口、期数
  领地内发展  扩张领地  维稳
        ↓  每个都有下限，哪个掉太低先把你拖垮
     总国力上升 → 战力标尺追上去
        ↓
主循环：打得赢 → 占地 → 地盘变大
        ↓
     地盘变大 → 只能放权去管
        ↓
     代理人坐大 → 诸侯化 → 你的一部分变成新的邻国
        ↓
     回到最外层 —— 而新的邻国比旧的强，因为它是你养出来的

慢循环（本时代很长，只有它跑得完）：
     框架立住 → 维持成本 > 余力，只能救火
        ↓
     沿政治线往前推 → 政策叠加，开始替你承担一部分维持
        ↓
     维持成本被压到余力之下 → 你腾出手
        ↓
     向外看 → 引入新变量 → era 06
```

**正反馈**：多管一块地 → 更多上缴 → 养更多人口与常备暴力 → 能管更远
**刹车**：任期 → 村落凝聚力 → 叛乱值 → 独立；征召 → 劳动人口 → 粮 → 征不动；**三个方向互相抢粮**；**维持一松手，那些读数就一路往下掉**

### 慢变量与中间可见态

| 慢变量 | 中间可见态 |
| --- | --- |
| **三个方向各自的位置** | 每条都有可读的深度——玩家能看出自己偏在了哪一个方向上 |
| **独立小点的进度** | 青铜、铁器、市场、火药……各自在走，先后顺序每个文明不一样 |
| **政治线经验** | 条在涨；**出事的时候会跳一截**——玩家能看出"这次叛乱买到了什么" |
| **村落凝聚力** | 每区块一条。**会随委派者的任期持续往下走**；**它同时决定你从这块地拿到多少** |
| **上交比例** | 每区块一条。**凝聚力往下走的时候，它跟着掉**——玩家能看见"这块地还在产，但我拿得越来越少" |
| **叛乱值** | 每区块一条。涨的时候**同时把该区块的产出折掉** |
| **统治方式** | 地图上能直接看出哪块直辖、哪块委派——**同一个网络里可以有多种管法** |
| **当前动员率** | 每区块一条。**它会滞后于目标值**——玩家能看出"改革还没落地" |
| **家族占据度** | 见政治线。**它只升不降**——玩家能看出"能换的人越来越少" |
| **维持成本** | 全局一条。**它在后半段会第一次超过你的余力**——玩家能看见自己的力气被吃光 |
| **邻国战力** | 每邻国一个数。**它一直在涨**——玩家能看出窗口在关 |

### 乐趣产生在八个位置

1. **国力这个数字第一次能被你自己推动**——改革按钮按下去，标尺真的往上走。
2. **三个方向里挑先推哪一个**——每一次都是在放弃另外两个。
3. **小点一个接一个亮起来**——青铜、铁器、市场、火药……它们不服务时代，它们服务你的三个方向。
4. **追赶一个不断往前跑的邻国标尺**——不是静态的强弱对比，是竞速。
5. **在叛乱值涨满之前压下去**——粮食收买、调政策、修路、派驻军队，各有代价。
6. **看着自己放出去的诸侯变成对手**——压力有一部分是自己造的，而这能被看见。
7. **第一次发现"我花在维持上的比花在发展上的多"**——在此之前的四个时代，从来不是这样。
8. **一条政策解锁之后，某个读数真的不再掉了**——这是「制度接管」第一次变得可见；到**操作量往下走、你腾出手的那一刻**，是本时代的出口情绪。

## 7. 邻国：本时代的压力源

**没有邻国，这个时代的张力不成立。** 每个方向都有代价，如果外面没有人在追你，玩家没有理由付出那些代价。

**邻国不是第二个模拟。** 它的国力是**算出来的**，不是经营出来的：

- 按它占的地盘，乘一个预置的系数（不同邻国有强弱之分，系数不同），**直接得出兵力和粮草**。
- **随时间成长**。成长由它的地盘和系数决定，玩家不参与。
- **它什么时候动手，走配置。**

### 7.1 它的攻击没有任何特殊规则

**邻国打你，就是一支队伍打过来——和玩家调动部队攻击，走的是完全同一套规则。**

**没有预警，也没有"劫掠"这种特殊表单。** 它出现在你的边境上，然后战斗结算开始。

打完之后，那块地受到和任何一块被打的地**一样的损害**——凝聚力跌、建筑损、人口掉。**这是「一块地被打」的通用后果，不是为邻国特设的。**

### 7.2 你打它，也不是灭国

**打邻国是占领它的地区，不是把它抹掉。** 对方的其余地区照旧存在、照旧在发展。

**占领是战争系统的通用行为：打下来是一瞬间，拿住是很多期。** 刚占的地区凝聚力极低、产出接近零、维持成本照付，要靠投入治理逐步消化。

**而且占领有上限——上限是你的消化能力，不是你的军队。**

> **一次占太多地区，产出还没回来，成本已经压上来。** 这条正是本时代扩张的天然刹车：**你能打下来多少，和你养得起多少，是两个数。**

### 7.3 由此产生的三种压力

1. **它是标尺，不是威胁。** 你不想打就永远不打——但你也永远拿不下它的地，而它在长。**机会窗口在关闭。**
2. **它会打你。** 你不能不管——边境地区的凝聚力会一路掉，掉到独立。
3. **你放出去的诸侯会变成新的邻国。** 这是本时代最狠的一条：**压力有一部分是你自己造出来的。**

**第一步只做这些**：邻国按地盘给数值、随时间成长、按配置动手。**不做外交，邻国之间不互相打**——那些留到后续细化。

## 8. 本时代玩家在操作什么

**按三个大方向排。** 每条线的操作细节以它自己挂的系统为准，本表只列玩家实际在动的东西。

| 方向 | 玩家在动什么 |
| --- | --- |
| **领地内发展 · 强化统治** | **粮食收买人心**、**修路**提高邻近度、**派驻军队镇压**、**切换统治方式**、**建生产建筑**、**提科技** |
| **领地内发展 · 市场** | 开市集、修商路、铸币、与邻国通商；**收税**；**用钱买到稀缺的军事产品** |
| **扩张领地 · 拓展统治** | **每区块设统治方式**（直辖 → 委派 → 任期制度 → 分封 → 郡县）、**设任期长度 / 换代理人**、**收上缴** |
| **扩张领地 · 征兵** | **编户齐民**抬高目标动员率、**征召**、**训练**（新兵会摊薄训练度） |
| **扩张领地 · 装备** | **造兵器**——铁压低每套装备的资源消耗；**研发冶金技术**（有些技术只能自己攻） |
| **维稳 · 政治改革** | 沿政治线解锁与切换条目、换资格标准 |
| **（后段新增）维持** | 压住家族占据度、断掉过长的任期、把跌破线的凝聚力买回来、按住叛乱值——**不产出任何东西** |
| **（共用）防守边境** | 应对邻国的攻击。**走统一的战争系统** |

**外加沿用 era 01–04 的全部系统**，规则不变：

| 系统 | 在本时代的形态 |
| --- | --- |
| **任务 / 人口 / 成年存活率 / 教育值** | 规则不变 |
| **科技节点与图鉴** | 规则不变；**本时代能点亮的小点比前几个时代都多** |
| **临近度与道路** | 规则不变；**修路现在是压叛乱的手段之一** |
| **村落凝聚力** | 规则不变；**新增"委派任期"这一下降来源** |
| **叛乱值与独立** | **就是 era 04 那一条**，规则不变。**独立出去的区块在本时代变成邻国** |
| **选育与抗性** | 规则不变，不清零 |

## 9. 这个时代不该有的

**系统上不存在的东西：**

- **地图之外。** 世界有边，边外不生成任何东西——**本时代的地图就是全部世界。**
- **公民权与民族认同。**
- **机械动力。**
- **化学农药**——一直不在。

**属于后续时代的：**

- **远洋航行这件事。** 造船、指南针、舵这些技术在本时代可以一路积累——**本时代的出口条件正是它**——**但「地图之外第一次有地图」这条机制要留给下一个时代**：在它引入之前，无论你的船造得多好，地图始终就是你的世界。

**本时代的禁令：**

- **一个不用花力气就能维持的秩序。** 本时代可以走得很大——那是它的出口——但**维持它是要花力气的，而且它还是会崩**。**不需要管的秩序，本时代不存在。**
- **家族占据度与委派任期不得自己回落。** 它们只能被玩家主动断开——换人、换管法。**破了这一条，玩家就没有理由付出维持的代价。**

## 10. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增机制**。质差体现在新机制把上限提到了哪。

| 时代 | 已有能力 | 新增 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代（era 04） | 裂变、临近度、村落凝聚力、叛乱值 | **裂变：聚落可以增殖** | 上限是**整片区块网络的承载量**——**外延增长** |
| **本时代** | era 04 全部能力 | **代理：把权力交给别人的手** | 从"**你能管多少**"提高到"**你派出去的人能替你管多久**"——**第一次出现内涵增长，而且路不止一条** |
| 下一时代（era 06） | era 05 全部能力 | **大航海：地图之外第一次有地图** | 待定 |

一句话概括：**在一个地方活下去 → 换到有更多种类的地方 → 把资源固定在土地上 → 让聚落增殖成网络 → 让权力既能伸出去、又能落到人头上，还能自己站着 → 让地图之外还有地图 → 待定。**

## 11. 验收要点

1. 玩家能感受到**变强第一次有了第二个来源**——不只靠占地，还能靠改造自己。
2. 玩家能感受到**通往国力的路不止一条**——而且**必须选**，因为每个方向抢同一批粮食和人口。
3. 玩家能感受到**一开始真的打不过邻居**，而且这个差距是能被改革追上的。
4. 玩家能感受到**代理人真的会坐大**——同一个区块管得越久，凝聚力掉得越快。
5. 玩家能感受到**邻国是标尺不是背景板**——它的数值在涨，窗口在关。
6. 玩家能感受到**拓展和征兵互相拉扯**——集权和放权各有代价，不能只要一个。
7. 玩家能观察到**每个区块的统治方式**，并且可以随时重画这张图。
8. 玩家能感知**政治线经验是被麻烦推上去的**——叛乱之后，能解锁的东西明显多了一截。
9. 玩家能理解**压力有一部分是自己造的**——独立出去的区块回来了，以邻国的身份。
10. 玩家能感受到**时代中段有一次转向**——前半段力气花出去东西变大，后半段力气花出去只是让它不变小；而且**操作量在减少，这不是游戏变简单**。
11. 玩家能感受到**有些读数不会自己回来**——家族占据度与委派任期只能靠主动换人、换管法断开；松一次手，读数就掉一截。
12. 玩家在本时代**始终有解不掉的压力**——集权与放权是同一件事的两面，只能平衡不能取消。
13. 玩家能感受到**出口不是"你撑不住了"，而是"你终于有余力往外看"**。
14. 崩溃后玩家仍在同一时代，**图鉴、选育与抗性、政治线经验都还在**，丢的是区块、产能和已编户的登记。
