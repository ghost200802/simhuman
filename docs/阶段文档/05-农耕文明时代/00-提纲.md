# era 05 · 提纲：农耕文明时代

## 1. 阶段定义

**这是最长的时代，也是第一个拥有多条成长线的时代。**

**它不再是一个出口、一条线，而是一个主目标下面的三个大方向。** 原有的六条线没有消失，它们被归进三个方向里。

**主目标：提升国力**（经济实力、军事实力、稳定）。

```
领地内发展 ── 强化统治 · 市场
扩张领地   ── 拓展统治 · 征兵 · 军事装备
维稳       ── 政治改革
```

**线 2、3、4 是贯穿始终的**——每个时代都要回答"这块地产多少、给我多少""我能点出多少人""这些人拿什么打仗"。**贯穿始终不等于不属于本时代：它们两样都是。**

**三个方向抢同一批粮食、同一批人、同一个期数，而且互相拆台**——往领地内投，扩张就慢；往外扩，已占地的统治力就掉；力气花在维稳上，另外两边都推不动。**真正的决策不是"要不要提升国力"，是"先往哪个方向投、放弃哪一个"。**

外面还有邻居：一开始比你强得多，而且在长。**你为打赢而集中起来的力量，会因为打赢而散掉。**

**方向之外还有一批独立的小点**——青铜炼制、铁器炼制、市场建立、火药使用……它们各自有独立的解锁条件与效果，彼此**不直接依赖、不互相阻塞**，先后顺序纯看它们在这个文明里怎么发生。**它们不绑在本时代上**：本时代没走完的，下一个时代可以接着走。**本时代特殊的地方只是它很长**，所以玩家在这里能走完的变化比别的时代多。

## 2. 地理与物理约束

- **区块仍是唯一的核心空间单位**，本时代不解锁新的空间概念。
- **临近度仍是硬约束**——它决定直辖的边界，也决定委派的维护成本。
- 新聚落只能建在相邻区块上（沿用 era 04）。
- 委派与分封**只能覆盖与网络相连的区块**；飞地不在本时代。
- **邻国占据网络之外的区块**，玩家打不到的地方也有主。
- 认知受停留与使用限制：**经过不等于认识**（沿用 era 01/02）。

## 3. 关键计量

**三个方向各自的读数由它们挂的系统提供**，本表只列名，不重复定义：

| 方向 | 小点 | 读数 |
| --- | --- | --- |
| **领地内发展** | 强化统治 | 每区块的**区块产出**、**上交比例**、**实际收益**；它用到的**资源配额 / 资源品味**与**当前生产效率**；沿用**村落凝聚力**、**叛乱值** |
| | 市场 | 每区块 / 每地区的**库存**、各种产品的**物价**、区域的**税收**、区域之间的**贸易流** |
| **扩张领地** | 拓展统治 | 政治线经验、每区块的**统治方式**、**委派任期**、上缴量 |
| | 征兵 | 基础动员率、目标动员率、当前动员率、可动员兵力、训练度 |
| | 军事装备 | **兵器库存**（按类型）、**可装备兵力**、移动力、冶金的科技节点进度 |
| **维稳** | 政治改革 | 政治线经验、官位、候选人池、家族占据度 |

**另有**：每邻国一个**战力标尺**、它的地盘、它与玩家的关系状态。

外加沿用 era 01–04 的全部计量（成年存活率、营养、体力、脑力、成年率、可投入劳动人口、教育值、各科技节点进度、图鉴、区块探索度、单位面积产量、选育进度、各病害抗性线、储粮容量、地力、**临近度**、**村落凝聚力**、**叛乱值**、可耕地占用度、网络聚落数、网络总人口）。

## 4. 核心玩法

**三个方向共用同一批粮食、人口、期数，玩家必须选先推哪个。** 给每个区块设统治方式与任期、收上缴（拓展统治）；粮食收买、修路、派驻军队镇压、建生产建筑、提科技（强化统治）；编户齐民、征召、训练（征兵）；造兵器、研发冶金（装备）；沿政治线改革（改革）；开市集、修商路、铸币、收税、买物资（市场）；防守边境；继续选育与抗性、应对灾害与饥荒；以及点亮那些独立的小点。

**前段与后段的玩法不一样，这是本时代最特殊的地方。**

- **前段：摊子撑大。** 力气花出去，东西变大——扩张、发展、点亮小点。
- **后段：维持成本开始超过余力。** 你花出去的力气，主要变成"让它不变小"——压住家族占据度、断掉过长的任期、把跌破线的凝聚力买回来、按住叛乱值。**这些不产出任何东西。**
- **再往后：政治线逐条解锁，条文替人记事、常规替人决断，一部分维持被制度接管。** 你腾出手，**操作量往下走**——这不是游戏变简单，是你把维持交出去了。

## 5. 政体与文化

**本时代很长，政体从委托一路走到官僚。**

开头是**委托**——权力越过邻近度那面墙，靠的是把事交给别人，不是靠一套常设机构。文字与会计的用途首先是记账与征收，其次才是别的。**常备暴力在本时代出现**，规模受制于财政。

往后，政治线逐条解锁、政策叠加起来，**制度开始接管一部分维持**。

**本时代的体制是玩家自己选的，不是时代替你定的。** 奴隶制、封建、郡县等等都在菜单上，各自有各自的优点与问题。**它们之间的关系是"共存"不是"取代"**——奴隶制不是封建之前的一格，它是一类生产关系，可以和封建、郡县同时存在，也可以跨时代一直用下去。中国历史上没走过某条路，不等于玩家不能选。

**「帝国」在本时代是玩家可以创建出来的一个结果，不是时代的前提。** 它被创建出来之后，还得证明自己能维持——而本时代的回答是：**能维持，但要一直花力气，而且它还是会崩。**

## 6. 进入与倒退

进入 era 06 需要：

| 组 | 条件 |
| --- | --- |
| 科技 | **远洋航海**已解锁——船能连续航行而不用看见陆地 |
| 状态 | 已建立**规定数量的海外据点或贸易路线** |
| 状态 | **至少一片「地图之外」的区域已被探明并标记**——你第一次知道，你的世界不是全部 |

全部满足后由玩家手动确认进入。

**这一条不再是"你自己撑不住了"，而是"你看向外面"。** 前面每一个出口都是内部的压力把你推出去；本时代第一次，是**你自己有余力往外看**——这正是"维持被制度接管、你腾出手"跑完的标志。

**文献参照**（详见本时代的依据文档）：

- **魏徵**（《贞观政要》卷一《论君道》贞观十年条）：「既得天下之后，志趣骄逸，百姓欲静而徭役不休……故**守文则难**。」
- **嘉庆**：「本朝**承平日久，生齿日繁**……中外已成**痼疾**」
- **孙明《论中国王朝周期的「中叶困境」》（《学术月刊》2024 年第 7 期，56 卷 7 期，173–189 页）**：中叶困境是「**制度丛脞、行政低效、风俗颓坏、国势衰微**」——**总体性的、多领域的**，动力机制是「**积弊**」

倒退表现为人口崩塌、区块独立、部分技能与匠人失传。

- **损失**：人口、储存、脱离控制的区块及其上的产能、部分科技节点与传承它们的匠人、已编户区块的登记。
- **保留**：时代标签、图鉴、区块探索度、**选育与抗性**、**政治线经验（不清零）**、以及仍然握着的区块。
- **恢复到**：仍在本时代，可以从留着的区块重新铺出去。**制度还在，所以恢复比第一次快**——**这是本时代的循环，不是时代的回退。**

## 7. 事件主题

洪水、干旱、蝗灾、牲畜疫病、饥荒、**代理人叛乱**、**边境被攻击**、**邻国战力跃升**、**邻国君主的继承纠纷**、迁入人口、贡赋纠纷、继承纠纷、**变法阻力**。

## 8. 科技文档展开方向

按「冶铜与青铜 — 冶铁与块炼/生铁分岔 — 文字与会计 — 税收与贡赋 — 常备暴力 — 道路与驿传 — 统治方式 — 编户与军功爵 — 市场与货币 — 土地制度与法典 — 火药与火器 — 印刷」展开。

## 9. 历史参照与验证问题

参照周代分封的收敛曲线（春秋初 148 国 → 战国 7 雄）、罗马行省数从 1 涨到 ~100、唐藩镇的世袭化、新亚述的常备军与强制迁移、以及**罗马与战国在动员上的分岔**（中国走大规模征兵 + 官僚集权，罗马靠地方精英合作、征兵基于服役意愿）。

验证五件事：**"代理人坐大"是否真的由任期累积造成**，而不是被规则禁止；**政治线经验是否真的被叛乱推着走**；**"远处成本大于收益"是否算出来的**，而不是一条硬规则；**邻国标尺的成长速度是否真的构成"窗口在关"**——玩家追得上但不轻松；以及**三个方向是否真的互相抢资源**——玩家能不能找到"只推一条就能通吃"的无脑解。

## 10. 本时代的战斗形态

**战斗走统一的战争系统。**

- **战斗形态分两截**：早期沿用单排，**远程支援装备出现后才有后排**（本时代跨过了这条线）。
- **"派驻军队镇压"是一次战斗**——派驻的兵与叛乱区块的兵走同一套结算。
- **邻国的攻击也是一次战斗**，走完全同一套结算。**它没有任何特殊规则，也没有预警。** 打完之后那块地照样损凝聚度、损建筑、掉人口。
- **装备从青铜走到铁器**：铁不提升单兵战斗力，但**压低每套装备的资源消耗**——同样的资源能武装更多人。
- **本时代末期战线宽度开始构成约束**——规模第一次跨过那个门槛。这是与 era 04 的分界。

## 11. 待办

- **每区块一种统治方式**——若网络有 20 个区块，玩家要维护 20 个设置。**详案里要给"默认统治方式"或批量套用**，否则后期会变成设置面板的清扫。
- **邻国系统只做了骨架**：按地盘 × 系数给兵力粮草、随时间成长、按配置动手、**不做外交**、邻国之间不互打。
- **打邻国是占领地区，不是灭国**——占领、消化、入不敷出都走战争系统的通用规则。**一次占太多会入不敷出**，这是扩张的天然刹车。
- **邻国动手的频率与条件**——走配置表。
- **各读数的下降速率与压下成本**——村落凝聚力、上交比例、家族占据度、委派任期、叛乱值各自的速率都是配置值。
- **本时代跨了青铜、铁器、以及火药与印刷等多截**，**时间是配置**，各截的时间压缩比后续再定。
