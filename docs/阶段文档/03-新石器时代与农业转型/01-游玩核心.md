# 阶段三 · 游玩核心：新石器时代与农业转型

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、科技节点清单、界面方案。阅读可脱离其他文档。

**一句话：** 农业不是因为更划算才赢的，是因为它能养活更多人、部落更强、能占到更大的地方——而同一批人口也是玩家唯一的死法。

---

## 1. 时代的叠加原则

这一条先于本文其余全部内容，它决定所有表述的方式。

> **时代推进是叠加，不是替换。**

```
本时代 = 已有能力的全集 + 一条新增的成长线
```

- 新增的那条线**更陡、上限更高**。
- 旧的那些线**一直可用，上限不变**。本时代仍然可以采集、狩猎、迁徙。
- 玩家的行为变化不是能力被替换，而是**因为新线更划算，越来越多地依赖它**。

由此推出两条贯穿全篇的结论：

**① 迁徙没有被禁止，只是变贵了。**

定居之后有储存，走一趟丢一堆。强行迁移仍然可行，代价是把攒下的东西留下。**攒得越多越舍不得走**——定居的锁定效应是自然涌现的，不需要额外设一条禁止迁徙的规则。

**② 倒退通过失传发生，不通过时代回退。**

时代标签与能力框架保留。崩溃表现为人口崩塌、储存丢失、部分技能与匠人失传；**选育与抗性不清零**。玩家仍然在本时代，只是回到了很弱的起点。

只有文明整体灭绝时本局才结束。**时代标签不退。**

---

## 2. 第一次出现的东西：剩余

这个时代真正第一次出现的不是农业，是**剩余**。

采集是"取走现成的"，拿到手就吃掉。农业是**投入后延迟回报**，产出第一次可能超过当下所需。

但剩余真正的后果是：**人口第一次可以突破野生资源的天花板**。

在此之前，人口上限由野生资源量决定，达到上限后无法继续增长。定居之后这个上限被抬高，而且**人口第一次能直接换成地盘**：开更多地、建新定居点、修水利、防守。这个兑换关系在采集时代不存在——采集时代既没有定居点，也没有可以占住不走的土地。

**历史依据。** 早期种植的回报并不高于采集。Bowles 2011 年在 PNAS 上的研究结论是：现有证据不支持"最早农民的生产率超过早期全新世采集者"。同一研究指出早期栽培种产量低到"远超现代作物的收获比"程度，而农民劳动更重。农业之所以扩散，按该研究的解释，是**社会与人口因素**——定居使生育更安全、人口增长更快，且储粮可防御。Weisdorf 的补充是：额外产出最初吸引人进入，随后的人口增长把好处吃掉，早期农民被锁进"做更多工"的状态。

> 这一条决定了整个时代的基调：**农业是一个玩家主动选择的、当下不划算但上限更高的方案。**

---

## 3. 独有体验：既是力量的主人，也是风险的制造者

采集时代的人口上限由自然决定，玩家没什么可选的。定居时代的人口是玩家主动推上去的，所以每一次灾害损失的都是**玩家自己攒下来的东西**。

变强和变脆是同一个动作。这是这个时代独有的体验，前后两个时代都不具备。

---

## 4. 核心张力

> **人口是扩张的唯一燃料，也是崩溃的主要来源。**

**燃料侧：**

```
人口多 → 能开更多地 / 能建新定居点 / 能修水利粮仓 / 能防守
       → 扩张 → 更多土地与资源 → 养活更多人口        （正反馈）
```

**风险侧：**

```
同一批人口 → 病疫载体 / 分配矛盾来源 / 歉收时缺口更大
```

灾害则同时具备双重身份：

```
灾害 → 人口损失        （主要的损失来源）
     → 抗性提升        （唯一的抗性来源）
```

玩家全程在把人口往上推，同时想办法让这次推高不至于在下一次灾害里全折掉。**没有正确答案，只有对当前地理与技术条件的暂时解。**

退路始终存在：采集与游耕一直可用，只是上限低。所以崩溃不是死局，而是**回到一条上限更低的线上重来**。

---

## 5. 核心循环

```
定居农业  →  单位土地能养活更多人
     ↓
人口积累  →  换成：开更多地 / 建定居点 / 修水利 / 防守
     ↓
扩张  →  更多土地与资源  →  养活更多人口          ← 正反馈
     ↓
同一批人口也是：病疫载体 / 分配矛盾 / 歉收缺口
     ↓
灾害  →  人口大降、储存丢失、部分技能失传
     ↓
选育与抗性（自动累积，不清零）  →  恢复更快、上限更高
```

这是一个**正反馈循环，灾害是它的刹车**。玩家想一直踩油门，每次灾害则在提醒该修刹车了。

### 乐趣产生在四个位置

1. **选育的自动复利**——不需要玩家操作，它自己在涨。隔一段回头看，同样一块地能养活的人比之前多了。纯粹的积累快感。
2. **扩张的可见回报**——人口换成新定居点，地图上多一个点。最直观的进度感。
3. **灾难是有回报的**——玩家会逐渐建立"这次洪水虽然淹了粮仓，但麦子的抗性上去了"的认知。对灾害的态度从"纯损失"变成"损失中带收益"。这是本时代很特别的一种心态。
4. **退路的代价随积累上升**——采集一直可用，但攒得越多越舍不得走。玩家会亲身感受到"定居把自己锁住了"，而这个锁定不是规则强加的，是自己攒出来的。

### 崩溃的定义

**崩溃的主要代价是人口、储存和部分技能，不是时代标签。**

| | |
| --- | --- |
| 损失 | 人口崩塌、储存丢失、部分技能与匠人失传 |
| **保留** | 时代标签、能力框架、**选育与抗性** |
| 结果 | 玩家仍在本时代，回到一个比上次更高的起点 |

这让本时代有一个"无论如何都在前进"的底色：玩家不会真正卡死，崩溃后恢复得比上次快。

---

## 6. 核心机制清单

以下机制服务于第 4 节的张力。凡不能映射到"燃料侧"或"风险侧"的机制，不应进入本时代。

### 6.1 选育

- **自动进行**，通过农业生产本身推进，不需要玩家手动操作。"持续执行对应操作"中的对应操作就是**种地**。
- **不清零**，崩溃后保留。
- 表现：作物性状逐代漂移并累积，单位面积产量与抗异常能力的上限逐步抬高。

历史依据：驯化性状（不落粒、籽粒变大、休眠性丧失）是通过长期选择累积的。Fuller 与 Denham 给出发育阶梯——栽培野生型（不落粒 < 25%，籽粒增大 < 10%）、半驯化（25–75%，10–30%）、驯化（≥ 75%，> 30%）。二粒小麦粒厚从约 1.7 mm 增至 2.5 mm 以上，用了约 9000 BC 到 5000 BC 四千年。

**游戏内时间尺度需要压缩**，压缩比在详案中定。

### 6.2 抗性

- **每种病害一条独立的抗性线**，各自**上限 50%**。
- 未经历过的病害，抗性停在起点——**抗性只能通过经历相应病害获得**。
- 抗性生效方式（依据部分抗性的成分研究）：

```
减产幅度降低 = 抗性值 R          （R = 50% 时减产减半）
发病概率降低 = R / 4            （R = 50% 时概率降 12.5%）
```

依据：潜育期延长是部分抗性的主导成分，其权重约为感染频率的 4 倍（田间评估回归系数 0.67 对 0.17）。且两者非独立机制——延长潜育期的基因会多效性地降低感染频率。**部分抗性主要作用于"发病后发展多快、损失多大"，而不是"能否感染"。**

保留：该比例来自单一病理系统的一次回归，是设计取值，不是普适常数。

- **不单独设置"耐受性"属性。** 减产侧的全额生效已隐含耐受成分；文献亦指出耐受性与抗性极难区分，单独拆分只会增加玩家无法验证的属性。

### 6.3 病害

首版**两种作物**：小麦、水稻。分别代表西亚旱作与东亚水田两个起源中心，病害谱差异最大。

**触发模型：**

```
病害发生 = 环境窗口成立（前置条件）
         × 窗口内概率触发
         × (1 − 抗性带来的概率削减)
```

**小麦 · 条锈病**

| 项 | 内容 |
| --- | --- |
| 温度 | 侵染最适 7–13℃，发展最适 13–16℃ |
| 水分 | 叶面水膜、结露、雾、雨；**结露最有利** |
| 特殊性 | 三种锈病中唯一喜冷的，发病最早 |

**小麦 · 秆锈病**

| 项 | 内容 |
| --- | --- |
| 温度 | 最适 18–22℃ |
| 水分 | 同样需要叶面水膜 |
| 特殊性 | 适温偏高、发病最迟、爆发力最强 |

**小麦 · 赤霉病**

| 项 | 内容 |
| --- | --- |
| 温度 | 病菌最适 24–28℃ |
| 水分 | **扬花期连续 3 天以上降雨**即流行 |
| 特殊性 | 窗口极窄（仅扬花初期）；后果是毒素，影响食用与储存 |

**水稻 · 稻瘟病**

| 项 | 内容 |
| --- | --- |
| 温度 | 20–30℃，尤其 24–28℃ |
| 水分 | 相对湿度 ≥ 90%，稻株水膜 6–10 小时；**低于 90% 即不能萌发** |
| 特殊性 | 阴雨寡照加重；湿度阈值极干净，可作开关 |

### 6.4 干旱与多雨是两种不同的伤害

```
干旱  →  抑制病害（锈病扩展中断）   但  直接减产
多雨  →  促发病害（赤霉、稻瘟、锈病）也  直接影响收成
```

**玩家面对的不是"天气好不好"，而是"要哪种坏天气"。**

天气系统至少需要四个轴：温度（决定哪种锈病）、降雨、相对湿度与结露、日照。

### 6.5 虫害

- **本时代无法根治**，是永久的、解不掉的压力源。
- 抗虫性可以缓慢提升，但**更慢、上限更低**。
- 主要手段只有轮作、人工捕虫、焚烧、防护。
- **化学农药不在本时代。** 波尔多液（1885）、巴黎绿（1860s）属工业革命前后，DDT（1940）、有机磷（1946）属化工时代。

虫害与病害共享同一个模式——**抗性军备竞赛**：过度依赖寄主抗性会加剧选择压力，使害虫或病原体克服它。这条模式贯穿后续所有时代。

### 6.6 养殖

> **可用性由地图决定，不是玩家的偏好。**

```
可驯化 = 对人类有好处
       × 该物种满足全部条件（食性 / 生长速度 / 圈养繁殖 / 性情 / 社会结构）
       × 该物种在可达范围内
```

- 地图上存在可驯化野生候选物种 → 养殖线开启
- 不存在 → 这条线不存在，只能走纯人力路线

**依据：** 148 种大型陆生哺乳动物候选（>45 kg 的野生食草/杂食动物）中，古代仅驯化 14 种，且分布极不均——欧亚 72 种候选驯化 13 种（18%），撒哈拉以南非洲 51 种驯化 0 种（0%），美洲 24 种驯化 1 种（4%，羊驼/骆马），澳大利亚 1 种驯化 0 种。**13 种的野生祖先只原产于欧亚**。美洲与澳大利亚在晚更新世大灭绝中丢掉了大部分候选。

这是**资源分布差异，不是文化差异**——欧亚家畜一旦传入，其他地区立刻采用。

注意区分：**能驯服 ≠ 能驯化**。斑马、非洲水牛、大象可以驯服，但圈养下不繁殖，不构成驯化候选。

| | |
| --- | --- |
| 产出 | 肉、奶、皮、**畜力**、**肥料** |
| 代价 | 饲料需求 + **牲畜疫病**（一条新的风险轴） |

**玩家决定的是投入多少资源推进这条线，不是"要不要有"。** 有候选物种时它明显占优；没有时这条线在界面上直接不存在。

### 6.7 分工

**人口积累的必然产物，属于燃料侧。**

- 人口达到一定规模后出现脱离食物生产的角色：陶工、工具匠、织工、后来的书记员。
- 分工提升产能，也让"人口多"从纯负担变成纯收益的一部分。
- 分工的人依赖剩余供养，所以**分工越深，对剩余稳定性的依赖越强**——风险侧的暴露同时变大。

**这是进入下一时代的门槛条件之一。**

### 6.8 跨村落交换

**同时服务两侧。**

| 侧 | 作用 |
| --- | --- |
| 燃料侧 | 技术传播、资源互补、专业化收益放大 |
| 风险侧 | 邻村余粮可调剂，歉收时多一条缓冲 |

- 交换的前提是剩余。
- 交换网络本身是脆弱的：中断会同时打击产能与抗风险能力。

**这是进入下一时代的门槛条件之一。**

### 6.9 记账雏形

**让治理规模超越村落的技术，本时代尾声解锁。**

- 剩余、交换、公共工程累积到一定规模后，口头与记忆无法继续支撑管理。
- 记账出现后，税收、仓储、工程调度第一次可以跨村统计。
- **这是从"村落"跨到"国家"的关键一跃**——没有它，下一时代的行政无从谈起。

**这是进入下一时代的门槛条件之一。**

---

## 7. 这个时代不该有的

- 货币、成文法律、常备军、税收体系、跨区域行政——均属下一时代。**不做这条边界，本时代会把下一时代的乐趣提前吃掉。**
- **化学农药。**
- **选育与抗性不得需要玩家手动操作。**
- **不得把养殖做成玩家可自由取舍的偏好**——它的可用性由地图决定。

---

## 8. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增一条成长线**。质差体现在新线的上限提高了多少。

| 时代 | 已有能力 | 新增的成长线 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代 | 采集、狩猎、火、储存、迁徙网络 | 储存与远距离交换 | 人口受野生资源上限约束 |
| **本时代** | 上一时代全部能力 | **定居农业 + 选育 + 抗性** | **人口可突破野生资源上限，且能换成地盘** |
| 下一时代 | 本时代全部能力 | 超越村落的权力（分工、税收、常备暴力） | 治理半径可超出村落 |

一句话概括三个时代：**跟着资源走 → 把资源固定在土地上 → 让权力超越村落。**

---

## 9. 验收要点

判定本时代的游玩核心是否被正确实现，看这六条：

1. 玩家能感受到"扩大产出"和"增加脆弱"是同一个动作。
2. 玩家能观察到选育在自动推进，且崩溃后不归零。
3. 玩家能意识到灾难同时带来损失和抗性。
4. 玩家在本时代**始终有解不掉的压力**（虫害、以及 50% 上限之下的病害残留）。
5. 玩家能感受到**退路的代价随积累上升**，而不是被规则禁止退路。
6. 崩溃后玩家仍在同一时代，但需要更长时间恢复——**时代标签从不回退**。
