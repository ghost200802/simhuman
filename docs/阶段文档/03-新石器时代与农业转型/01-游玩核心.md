# era 03 · 游玩核心：新石器时代与农业转型

**定位：** 定义这个时代玩家在玩什么、反复权衡什么、乐趣产生在哪里。后续所有计量、决策、节点、事件都必须服务于本文确定的张力。
**边界：** 不含具体数值、节点清单、界面方案。阅读可脱离其他文档。

**一句话：** 你把人口推上去，然后就走不掉了——粮食、粮仓、水渠全在原处，而下一场灾害冲的正是这些东西。

---

## 1. 时代的叠加原则

> **时代推进是叠加，不是替换。**

```
本时代 = 已有能力的全集 + 一条新增的成长线
```

- 新增的那条线**更陡、上限更高**。
- 旧的那些线**一直可用，上限不变**。本时代仍然可以采集、狩猎、迁徙。
- 玩家的行为变化来自"新线更划算"，不是旧能力被拿走。

由此推出两条贯穿全篇的结论：

**① 退路没有被禁止，只是变贵了。**

采集与游耕一直可用，迁徙也没有被关掉。但定居之后有储存、有开熟的地、有水利——**走一趟，丢一堆**。攒得越多越舍不得走。这个锁定是自然涌现的，不需要额外设一条禁止迁徙的规则。

**② 倒退通过失传发生，不通过时代回退。**

时代标签与能力框架保留。崩溃表现为人口崩塌、储存丢失、部分技能与匠人失传；**选育与抗性不清零**。玩家仍在本时代，只是回到了一个很弱的起点。

只有文明整体灭绝时本局才结束。**时代标签不退。**

---

## 2. 第一次出现的东西：剩余

这个时代真正第一次出现的不是农业，是**剩余**。

采集是"取走现成的"，拿到手就吃掉；农业是**投入后延迟回报**，于是产出第一次可能超过当下所需——**人第一次不必再跟着资源走**。

但剩余真正的后果是：**人口第一次可以突破野生资源的天花板**。在此之前上限由野生资源量决定，到顶就停。定居之后这个上限被抬高，而且**人口第一次能直接换成别的投入**：开更多地、修水利粮仓、防守、分出不用种地的角色。

这个兑换关系在 era 02 不存在——那时既没有能占住不走的土地，也没有值得留在原地的投入。

---

## 3. 独有体验：第一次有东西可以失去，也第一次被土地锁住

**这两件事是同一个动作。**

era 02 每要一样新东西，先扔掉一次窝——那时"失去"是自己选的，代价明码标价。本时代反过来：**你攒下的东西开始替你决定你能去哪。** 危机来的时候，采集者可以走（era 02 的核心机制），定居者不能——粮仓、水渠、开熟的地，全在原地。

变强和变脆是同一个动作，而这一次**没有地方可退**。

---

## 4. 核心张力

> **人口既是唯一的燃料，也是唯一的压力源；而本时代新增的这条线没有出口。**

**燃料侧：**

```
人口多 → 能开更多地 / 修水利粮仓 / 分工 / 防守 / 记账
       → 更多剩余 → 养活更多人口                    （正反馈）
```

**压力侧**——同一批人口同时在三个来源上累积压力：

| 来源 | 内容 |
| --- | --- |
| **自然** | 旱涝、病害、虫害、地力 |
| **社会** | **村落凝聚力**下降——村落规模超过凝聚上限；分工越深，对剩余稳定性的依赖越强 |
| **跑不掉** | 上述压力都必须在原地解决，而本时代**新增的这条线没有出口** |

**出口这一侧是要害：**

```
采集与游耕一直可用，迁徙也没有被禁止     ← 旧退路还在（叠加原则）
但储存、开熟的地、水利粮仓全在原地
→ 攒得越多，走一次的代价越大              ← 锁定随积累上升
```

灾害则同时具备双重身份：

```
灾害 → 人口损失、储存丢失        （主要的损失来源）
     → 抗性提升                  （唯一的抗性来源）
```

玩家全程在把人口往上推，同时想办法让这次推高不至于在下一次灾害里全折掉。**没有正确答案，只有对当前地理与技术条件的暂时解。**

---

## 5. 核心循环

```
定居农业  →  单位土地能养活更多人
     ↓
剩余积累  →  人口增长  →  更多剩余               ← 正反馈
     ↓
人口换成：更多地 / 粮仓水利 / 分工 / 防守 / 记账
     ↓
同一批人口也是：病疫载体 / 分配矛盾 / 歉收缺口
自然侧：旱涝、病害、虫害、地力
     ↓
压力只能在原地累积 —— 退路还在，但代价随积累上升
     ↓
灾害  →  人口大降、储存丢失、部分技能失传
     ↓
选育与抗性（自动累积，不清零）  →  恢复更快、上限更高
```

这是一个**正反馈循环，"无处可去"是它的刹车**。玩家想一直踩油门，而本时代没有泄压阀——**泄压阀要到 era 04 的裂变才出现**。

### 慢变量与中间可见态

| 慢变量 | 中间可见态 |
| --- | --- |
| 选育 | 同一块地的单产**逐代往上爬**——不需要操作，回头才看得见 |
| 抗性 | 每条病害一条线，**只在经历过后才涨**，涨了不掉 |
| 储存 | 粮仓的存量与容量在变 |
| 人口构成 | 成年 / 未成年两段，以及**脱离食物生产的角色**在变多 |
| **村落凝聚力** | 人越多、分工越深，凝聚力条越低。**这是与 era 04 共用的同一个计量**——本时代只有一个区块，**没有临近度这一项** |

### 乐趣产生在四个位置

1. **选育的自动复利**——不需要玩家操作，它自己在涨。隔一段回头看，同样一块地能养活的人比之前多了。纯粹的积累快感。
2. **扩张的可见回报**——人口换成粮仓、水渠、工匠。最直观的进度感。
3. **灾难是有回报的**——玩家会逐渐建立"这次洪水虽然淹了粮仓，但麦子的抗性上去了"的认知。对灾害的态度从"纯损失"变成"损失中带收益"。
4. **退路的代价随积累上升**——采集一直可用，但攒得越多越舍不得走。玩家亲身感受到"定居把自己锁住了"，而这个锁定不是规则强加的，是自己攒出来的。

## 6. 核心机制清单

以下机制服务于第 4 节的张力。凡不能映射到"燃料侧"或"压力侧"的机制，不应进入本时代。

### 6.1 选育

- **自动进行**，由农业生产本身推进，不需要玩家手动操作。"持续执行对应操作"中的对应操作就是**种地**。
- **不清零**，崩溃后保留。
- 表现：作物性状逐代漂移并累积，单位面积产量与抗异常能力的上限逐步抬高。

**接口：** 是燃料侧上限的唯一发动机；推进速度受 6.4 的天气约束；上限抬高后 6.7 分工能养的人随之变多。

### 6.2 抗性

- **每种病害一条独立的抗性线**，各自上限固定。
- 未经历过的病害，抗性停在起点——**抗性只能通过经历相应病害获得**。
- 抗性主要作用于**发病后发展多快、损失多大**，而不是"能否感染"。
- **不单独设置"耐受性"属性。** 减产侧的全额生效已隐含耐受成分；文献亦指出耐受性与抗性极难区分，单独拆分只会增加玩家无法验证的属性。

**接口：** 唯一的上游是 6.3 与 6.5；唯一的用途是削减这两者的实际损失。

### 6.3 病害

首版**两种作物**：小麦、水稻。分别代表西亚旱作与东亚水田两个起源中心，病害谱差异最大。

```
病害发生 = 环境窗口成立（前置条件）
         × 窗口内概率触发
         × (1 − 抗性带来的概率削减)
```

- 每种病害有**自己的窗口**：温度带、需不需要叶面水膜、窗口有多宽。
- 窗口是**可被玩家看见的**——玩家能学会"这种天气会出事"，这是 6.4 与 6.3 之间的可见连接。
- 有的病害窗口极窄（只在某个生育阶段的几天内），有的宽。

**接口：** 上游是 6.4 提供的窗口；下游的损失由 6.2 削减；病害造成的减产直接打在 6.1 的产出上。

### 6.4 干旱与多雨是两种不同的伤害

```
干旱  →  抑制病害（锈病扩展中断）   但  直接减产
多雨  →  促发病害（赤霉、稻瘟、锈病）也  直接影响收成
```

**玩家面对的不是"天气好不好"，而是"要哪种坏天气"。**

**接口：** 上游是事件；下游同时作用于 6.1（减产）、6.3 与 6.5（促发），是压力侧"自然面"的总闸。

### 6.5 虫害

- **本时代无法根治**，是永久的、解不掉的压力源。
- 抗虫性可以缓慢提升，但**更慢、上限更低**。
- 主要手段只有轮作、人工捕虫、焚烧、防护。
- **化学农药不在本时代。**

**接口：** 与 6.3 共享 6.4 的天气窗口；两者共同构成 6.2 的唯一推进源。

### 6.6 养殖

> **可用性由地图决定，不是玩家的偏好。**

```
可驯化 = 对人类有好处
       × 该物种满足条件（食性 / 生长速度 / 圈养繁殖 / 性情 / 社会结构）
       × 该物种在可达范围内
```

- 地图上存在可驯化野生候选物种 → 养殖线开启
- 不存在 → 这条线不存在，只能走纯人力路线

| | |
| --- | --- |
| 产出 | 肉、奶、皮、**畜力**、**肥料** |
| 代价 | 饲料需求 + **牲畜疫病**（一条新的风险轴） |

**玩家决定的是投入多少资源推进这条线，不是"要不要有"。** 有候选物种时它明显占优；没有时这条线在界面上直接不存在。

**接口：** 上游是地图资源；下游给 6.1 提供肥料（抬高单产）、给 6.7 提供不必占用耕地的口粮。

### 6.7 分工

**人口积累的必然产物，属于燃料侧。**

- 人口达到一定规模后出现脱离食物生产的角色：陶工、工具匠、织工、后来的书记员。
- 分工提升产能，也让"人口多"从纯负担变成纯收益的一部分。
- 分工的人依赖剩余供养，所以**分工越深，对剩余稳定性的依赖越强**——压力侧的暴露同时变大。

**接口：** 上游是 6.1 与 6.6 提供的剩余；下游抬高 6.1 与 6.8 的产出；它同时是 era 04 转换条件的承载机制之一。

### 6.8 跨村落交换

**同时服务两侧。**

| 侧 | 作用 |
| --- | --- |
| 燃料侧 | 技术传播、资源互补、专业化收益放大 |
| 压力侧 | 邻村余粮可调剂，歉收时多一条缓冲 |

- 交换的前提是剩余。
- 交换网络本身是脆弱的：中断会同时打击产能与抗风险能力。

**接口：** 上游是 6.1 与 6.7 的剩余；下游给 6.2 提供外来的品种与做法；它是 era 04 转换条件的承载机制之一。

### 6.9 记账雏形

**让治理规模超越村落的技术，本时代尾声解锁。**

- 剩余、交换、公共工程累积到一定规模后，口头与记忆无法继续支撑管理。
- 记账出现后，税收、仓储、工程调度第一次可以跨村统计。

**接口：** 上游是 6.7 与 6.8 累积出的规模；它是 era 04 转换条件的承载机制之一。

## 7. 这个时代不该有的

**系统上不存在的东西：**

- **多聚落。** 本时代地图上属于你的只有一个点——本时代只能控制一个区块。
- **可自由取舍的养殖。** 有没有候选物种由地图决定，玩家没有"要不要"这一项。

**属于后续时代的：**

- **走出本区块建立新聚落**——era 04。本时代聚落只会**解体**，不会**增殖**。
- 分封、货币、成文法律、常备军、税收体系、跨区域行政——era 05
- 化学农药——一直不在

**四条针对本时代的禁令：**

- **不得让选育与抗性需要玩家手动操作。** 自动累积是本时代的机制核心。
- **不得让灾害只损失、不给抗性。** 灾害的双重身份是本时代张力的支点。
- **不得禁止玩家退回避难路线。** 退路的代价随积累上升，不是规则禁止。
- **不得让"没有出口"变成规则硬锁。** 它是积累出来的代价，不是一条禁止规则。

## 8. 与相邻时代的成长线对比

不是"能力被换掉了"，而是每个时代各**新增一条成长线**。质差体现在新线的上限提高了多少。

| 时代 | 已有能力 | 新增的成长线 | 上限变化 |
| --- | --- | --- | --- |
| 上一时代（era 02） | 任务、科技节点、图鉴、迁徙、区块探索度 | **换地方 + 探索 → 换种类** | 从"一个区块"到"你能到达的最好的那个区块"。**天花板仍是野生资源** |
| **本时代** | era 02 全部能力 | **定居农业 + 选育 + 抗性** | **突破野生资源天花板**——上限从"一个采集群体能覆盖的野生资源量"变成"一块地的农业承载力"，且人口第一次能换成别的投入 |
| 下一时代（era 04） | era 03 全部能力 | **裂变：聚落可以增殖** | 从"一个聚落的承载量"变成"**整片区块网络的承载量**" |

一句话概括四个时代：**在一个地方活下去 → 换到有更多种类的地方 → 把资源固定在土地上 → 让聚落增殖成网络。**

---

## 9. 验收要点

1. 玩家能感受到**"扩大产出"和"增加脆弱"是同一个动作**。
2. 玩家能感受到**退路还在，但代价随积累上升**——不是被规则禁止退路。
3. 玩家能观察到**选育在自动推进**，且崩溃后不归零。
4. 玩家能意识到**灾难同时带来损失和抗性**。
5. 玩家在本时代**始终有解不掉的压力**（虫害、病害残留、以及"无处可去"本身）。
6. 崩溃后玩家仍在同一时代，但恢复需要更长时间——**时代标签从不回退**。
