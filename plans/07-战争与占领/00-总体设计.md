# 战争与占领 · 总体设计（初稿）

**目标：** 让 era03/era04 Demo 能以统一接口接入战争、占领、兵力、装备、运输和治理结果，同时不为 Demo 编写临时战争规则。

## 1. 领域边界

战争系统负责动员、装备、战斗、占领和占领后的控制变化。生产消费系统提供粮食、工具和装备库存；运输系统提供军队移动和补给路径；治理系统承接占领后的凝聚与消化。

## 2. 统一区块图

军队移动、补给、占领和治理都读取 50 km 区块图与边状态。战争系统不修改地图结构，只改变控制、损害、驻军和运输状态。

## 3. Demo 接入范围

首个 era03/era04 切片只需验证：

- 少量人口动员；
- 基础装备库存；
- 军粮消耗；
- 区块间移动；
- 简化战斗结果接入；
- 占领后的产出下降与治理压力。

完整战斗编队、侧翼、补给线和占领消化沿最终数据契约接入，不用 Demo 专用实体模型。

## 4. 性能结构

军队、装备、补给和战斗记录使用整数 ID 与稀疏状态。无战斗的区块不创建战斗对象；有战斗的区块沿统一 tick 阶段推进。移动和补给使用运输状态格式，结果可回放和序列化。

## 5. 约束

战争不能直接凭空生成粮食、装备或运输能力；所有军事能力必须读取生产、库存、人口、运输和治理状态。战争系统不把玩家命令分支写入 tick。
