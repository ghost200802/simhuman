**状态：** 已实现，待编辑器验收

如果编辑器仍显示旧 UUID，关闭当前预览并重新打开项目，让 Asset DB 重新导入脚本和场景，再打开本场景。

## 目标

将第一步的纯模拟核心接入 Cocos Creator 3.8，形成一个可以在编辑器预览和运行的 2D 初步 Demo。

## 本步骤包含

- Cocos 2D 场景 `assets/scenes/SimHumanDemo.scene`；
- `SimHumanDemo` 运行组件；
- 通过 `resources.load` 加载三个 JSON 配置资源；
- 绘制 4×4 区块网格；
- 显示世界 ID、日期、tick、区块数和图边数；
- 点击区块查看网格坐标和地形 ID；
- 推进 1 月、推进 12 月、重置世界；
- 显示配置加载错误；
- 为场景、脚本和 JSON 资源提供 Cocos `.meta` 文件。

## 系统边界

本步骤不实现人口、生产、消费、库存、运输、市场、战争或 UI 美术资源。右侧状态区明确显示这些系统尚未接入，避免把空数据误认为已经模拟。

## 运行方式

1. 使用 Cocos Creator 3.8.8 打开项目根目录。
2. 等待资源导入完成。
3. 打开 `assets/scenes/SimHumanDemo.scene`。
4. 点击编辑器顶部预览按钮。
5. 验证区块网格、区块点击、1 月推进、12 月推进和重置按钮。

## 验收标准

- 场景可以被 Cocos 打开，不出现脚本编译错误；
- 初始显示 16 个区块和 48 条图边；
- 配置加载完成后显示 `era03_04_demo`；
- 推进 1 月后月份增加 1；
- 推进 12 月后年份增加 1；
- 重置后 tick 回到 0、日期回到 1 年 1 月；
- 点击区块后显示区块 ID、网格坐标和地形 ID；
- 核心脚本不导入 `cc`，只有 Cocos 适配层和 Demo 表现层导入 `cc`。
